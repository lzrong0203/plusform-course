# showcase：課程準備的 agent 版帳本（情境重現）

`ledger_app.py` 是一支記帳小程式：記一筆、列出、分類加總、分帳、存檔讀檔。它是**課程準備的示範版**，用來重現「agent 照一段需求交出來的程式」常見的樣子：看起來很完整，卻藏著一個沒想到的情況。影片畫面上會標「情境重現」。

它只用到 Lv1（1-1 到 1-24）教過的東西，所以學完 Lv1，每一行你都看得懂。

這支程式**凍結**了，之後不會改。它是整門課的對照組：

- 0-1：看它跑起來，輸入「一百元」就當掉。請 AI 解釋其中一行，你還分不出對錯，看得懂進度條是 0%。
- 每通過一課，`uv run check.py status` 的看得懂進度條就往上加。
- 1-27（Lv1 下關卡）：進度條到 100%，你要能逐行講解它，也能說出它為什麼會當掉。

## 跑跑看（選做）

它會把帳存成家目錄裡的一個文字檔 `.pypy_ledger.txt`（一行一筆）。

```bash
cd ~/code/plusform-course
uv run showcase/ledger_app.py
```

選 1 記一筆，金額打「一百元」，就會看到它當掉的錯誤訊息。

## 看得懂進度條

```bash
uv run concept_map.py            # 照你帳本裡通過的課算
uv run concept_map.py --lines    # 每一行標了什麼概念、你看不看得懂
```

## 為什麼刻意留一個問題

它看起來寫得很完整：有型別提示、有說明、也處理了「金額是負數」。可是它沒想到有人會打中文數字。agent 說「做完了」，不代表「做對了」；這門課要練的，就是自己抓得到這種問題。
