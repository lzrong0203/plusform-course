# 0-C 用到的概念

Lv0 關卡只用到 Lv0 教過的東西，下面標「例外」的除外。

第一關的 main.py 是 `uv init` 建出來的樣子（外殼照抄、不用懂），只多了幾行 print。學員只改兩個錯字（少了一個引號、print 拼錯），不用懂 Python 語法；這些概念都比 0-C 晚才教，所以標成例外。
第三關的正確版（`reference/make_v0.sh`）和壞版本（`mutants/`）是終端機指令，只能用 0-4 教過的指令。

## 可以用的概念

- 註解（例外：只出現在說明）
- print（例外：只改錯字，1-1 才正式教）
- 資料型別（例外：只有字串，照抄）
- 比較與邏輯（例外：只出現在外殼的 if __name__ == "__main__"，照抄）
- if（例外：同上，外殼照抄）
- 函式外殼（例外：def main() 是 uv init 建的，照抄）
- 函式呼叫（例外：只有外殼最後那行 main()，照抄）
- 模組與 import（例外：只有 __name__，外殼照抄）
