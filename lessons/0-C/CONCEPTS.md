# 0-C 用到的概念

Lv0 關卡只考 Lv0 教過的東西，下面標「例外」的除外。

第一關的 main.py 是 `uv init` 建出來的樣子（外殼照抄、不用懂），只多了幾行 print。壞掉的地方只有兩種，都是 Lv0 看過的：
一行少了右括號（0-7 故意刪掉右括號、讀「'(' was never closed」那一段），和一筆金額打錯（0-5 第③圈「先寫下應該印出什麼，再跑、對不上就退回」）。
學員不用懂 Python 語法，Python 的概念都比 0-C 晚才教，所以標成例外。
第二關的錯誤訊息是 0-5 第②圈看過的那一種（新開的視窗在家目錄，uv run main.py 找不到檔案），錯的那一則跟 0-5 學的「command not found＝找不到指令」對不上。
第三關的正確版（`reference/make_v0.sh`）和壞版本（`mutants/`）只用 0-4 教過的指令。用 `bash 檔名` 跑一支腳本，是 0-C 影片裡第一次教的操作（只是跑起來的方法，不是這一關考的東西）。

## 可以用的概念

- 註解（例外：只出現在說明）
- print（例外：只補一個右括號、改一個數字，1-1 才正式教）
- 資料型別（例外：只有字串，照抄）
- 比較與邏輯（例外：只出現在外殼的 if __name__ == "__main__"，照抄）
- if（例外：同上，外殼照抄）
- 函式外殼（例外：def main() 是 uv init 建的，照抄）
- 函式呼叫（例外：只有外殼最後那行 main()，照抄）
- 模組與 import（例外：只有 __name__，外殼照抄）
