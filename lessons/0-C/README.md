# 0-C　Lv0 關卡：帳本 v0

這一關大約 45 分鐘。**全程關掉 AI。** 三關都過、而且練習滿 3 天（跑課號檢查或答回顧題，不同天都算），才升級到 Lv1。

做完這一關，你的帳本就是 v0：建好資料夾，程式印出寫死的三筆花費，有兩個存檔點。

## 1. 題目

開始前先寫下預測分數（`uv run check.py start lv0` 會問你），做完再估一次。

**第一關：自己來。**

- 不看筆記，在帳本的 `lessons/0-C/rebuild/` 裡，只用終端機重建 0-4 的資料夾結構。Lv0 的標準是 10 分鐘內做完；check.py 會照檔案的時間算你大約花了多久（只是記下來，不擋你過關）。
- 預測 5 組 `cd` 之後 `pwd` 會印出什麼（`pwd.txt`）。
- 修好壞掉的 `lessons/0-C/main.py`，讓它印出帳本 v0 的四行。修好以後，把它複製到帳本最上層，取代 uv init 建的那支 `main.py`，再按一次存檔點（0-7 教過）。

**第二關：判讀 AI。** 熊打錯資料夾名稱，四個 AI 給了四則解釋，找出錯的那一則（`ai_explain.txt`）。

**第三關：先讀再跑。** AI 給了一支建資料夾的腳本 `make_v0.sh`，裡面有一行危險的指令。找到它、刪掉那一行、存檔，然後才跑。再寫出「跑完之後應該是什麼樣子」的檢查（`checks.txt`），要把 AI 給過的其他壞版本都抓出來。

`start lv0` 會在帳本的 `lessons/0-C-保險箱/` 放一份收據，那是第三關的「原本就在的東西」。危險那一行刪的就是它，所以就算不小心跑了，掉的也只是這份練習用的收據。

## 2. 提示

- 錯誤訊息從最下面一行看起：它說的是哪一行、哪一類錯？
- `../` 是上一層，`../..` 是上兩層，`~` 是家目錄。
- 看到 `rm -rf`，先想清楚它刪的是哪裡。
- 第三關的檢查，路徑從 `lessons/0-C` 算起；除了 `v0/` 裡該有的東西，也想想「原本就在的東西，跑完還在嗎？」。

## 3. 開始前要打的指令

```bash
cd ~/code/plusform-course
uv run check.py start lv0
```

第一關重建結構，從這裡開始（計時從建出 `rebuild` 資料夾那一刻算起）：

```bash
cd ~/code/ledger/lessons/0-C
mkdir -p rebuild
cd rebuild
```

第一關修好 main.py 之後，換掉帳本的 main.py，再按存檔點：

```bash
cd ~/code/ledger
uv run lessons/0-C/main.py
cp lessons/0-C/main.py main.py
uv run main.py
```

然後在 VS Code 的「原始碼控制」面板寫一句說明（例如「帳本 v0」），按存檔點。

第三關刪掉危險那一行、存檔之後：

```bash
cd ~/code/ledger/lessons/0-C
bash make_v0.sh
```

## 5. 怎麼測

在課程資料夾裡打 `uv run check.py lv0`（也可以打 `0-C`）。它會分三關檢查：

- 第一關：`rebuild/` 的結構、5 題 pwd（對答）、帳本最上層的 `main.py` 印出 v0 的四行、帳本有至少兩個存檔點而且 v0 的 main.py 已經存起來
- 第二關：錯的那一則（對答）
- 第三關：你改過的 `make_v0.sh` 在假的資料夾裡模擬起來跟安全版一樣；你真的跑過了（`v0/` 建好了、隔壁的 `lessons/0-C-保險箱` 還在）；你寫的檢查把 3 個壞版本都抓到

每一關第一次全部通過的日期會記下來。做太快（5 分鐘內全對）會跳出警訊。

## 6. 怎麼交

不用交給任何人。作答都在帳本裡：`lessons/0-C/` 的 `rebuild/`、`pwd.txt`、`ai_explain.txt`、`make_v0.sh`、`checks.txt`，還有帳本最上層的 `main.py` 和存檔點。三關都過、練習滿 3 天，`uv run check.py status` 會顯示「已升級」。
