# 0-C　Lv0 關卡：帳本 v0

這一關大約 45 分鐘。**全程關掉 AI**（VS Code 的 AI 功能 0-6 已經關了；聊天的 AI 和 0-8 設好的家教，這一關也先不開）。三關都過、而且練習滿 3 天，才升上 Lv1。卡住時回哪一課看、預測分數和升級怎麼算、跑錯了怎麼補救、Windows 的做法，寫在 [補充.md](補充.md)。

做完這一關，你的帳本就是 v0：0-4 的資料夾你自己蓋得出來，`main.py` 印出寫死的三筆花費，而且存進了存檔點。

## 1. 題目

開始前先寫下預測分數（`uv run check.py start lv0` 會問你：一共 16 題，你覺得會過幾題）。三關做完、對答案之前，它會再問你一次。

**第一關：自己來。**

- 不看筆記，在帳本的 `lessons/0-C/rebuild/` 裡，只用終端機重建 0-4 的帳本資料夾。Lv0 的標準是 10 分鐘內；check.py 會照檔案的時間算你大約花了多久（只是記下來，不擋你過關）。
- 預測 5 組 `cd` 之後，`pwd` 會印出什麼（`pwd.txt`）。
- 修好壞掉的 `lessons/0-C/main.py`，讓它印出第 4 節那四行。先跑跑看，錯誤訊息從最下面一行看起（0-7 看過）；跑得起來以後，跟那四行一行一行比，每個字都要一樣（0-5 第③圈：先寫下應該印出什麼，再跑）。都對了，把它複製到帳本最上層、換掉 uv init 建的那支 `main.py`，再按一個存檔點（0-7）。

**第二關：判讀 AI。** 熊開了一個新的終端機視窗，打 `uv run main.py`，看到一段錯誤訊息。四個 AI 給了四則解釋，其中一則是錯的，找出來（`ai_explain.txt`）。每一則都回去錯誤訊息裡找證據。

**第三關：先讀再跑。** AI 給了一支建資料夾的腳本 `make_v0.sh`，裡面藏了一行危險的指令。先讀，找到它、刪掉那一行、存檔，然後才跑。再寫出「跑完之後應該是什麼樣子」的檢查（`checks.txt`），要把 AI 給過的其他壞版本都抓出來。

`start lv0` 會在帳本的 `lessons/0-C-保險箱/` 放一份練習用的收據，那是第三關「原本就在的東西」，不要動它。這支腳本動到的，只有帳本 `lessons/` 裡練習用的東西。

## 2. 提示

- 錯誤訊息從最下面一行看起：它說是哪一種錯？上面寫著是第幾行？修好一個，再跑一次。
- `..` 是上一層，`../..` 是上兩層，`~` 是家目錄。`pwd` 印出來的是從 `/` 開始的完整路徑。
- 判斷 AI 的解釋：它說的事，錯誤訊息裡找得到證據嗎？跟你學過的對得上嗎？
- 看到刪除（`rm`）和搬家（`mv`）的指令，先想清楚它動到哪裡。
- 第三關的檢查，路徑從 `lessons/0-C` 算起（`../` 是上一層）；除了新建好的東西，也寫「原本就在的東西，跑完還在嗎？」。
- 卡住了不問 AI：回到那一課的章節再看一次（[補充.md](補充.md) 有對照表），或先跑一次 `uv run check.py lv0` 看提示。

## 3. 開始前要打的指令

> 起點：0-7 的帳本（`~/code/ledger`，已經按過存檔點）和用 `git clone` 下載的課程資料夾。Windows：指令都在 Git Bash 照打，VS Code 裡 ⌘ 換成 Ctrl。

先把課程資料夾更新到最新，再開始關卡：

```bash
cd ~/code/plusform-course
git pull
uv run check.py start lv0
```

第一關重建資料夾，從這裡開始（計時從建出 `rebuild` 資料夾那一刻算起）：

```bash
cd ~/code/ledger/lessons/0-C
mkdir -p rebuild
cd rebuild
```

第一關修 main.py（在帳本資料夾裡）：

```bash
cd ~/code/ledger
uv run lessons/0-C/main.py
```

修好、跟第 4 節的四行比對過之後，換掉帳本的 main.py：

```bash
cp lessons/0-C/main.py main.py
uv run main.py
```

然後在 VS Code 的「原始碼控制」面板寫一句說明（例如「帳本 v0」），按存檔點（Commit）。

第三關刪掉危險那一行、存檔之後，才跑：

```bash
cd ~/code/ledger/lessons/0-C
bash make_v0.sh
```

`bash 檔名` 會從第一行開始，一行一行照著跑那支腳本。

## 5. 怎麼測

在課程資料夾裡打 `uv run check.py lv0`（也可以打 `0-C`）。它會先問你猜會過幾題，再分三關檢查，只顯示第一個沒過的：

- 第一關：`rebuild/` 的結構、5 題 pwd（對答）、帳本最上層的 `main.py` 印出那四行、帳本有至少兩個存檔點而且 v0 的 main.py 已經存起來
- 第二關：錯的那一則（對答）
- 第三關：你改過的 `make_v0.sh` 在假的資料夾裡模擬起來跟安全版一樣；你真的跑過了（`v0/` 建好了、隔壁的 `lessons/0-C-保險箱` 還在）；你寫的檢查把 3 個壞版本都抓到

每一關第一次全部通過的日期會記下來。開始前猜的、做完猜的、實際過了幾題，都記進校準曲線；打 `uv run check.py status` 看得到。猜的跟實際差太多，它會請你寫一句「下次我會怎麼估」。不到 5 分鐘就全部做對，會跳出警訊（只是提醒，不扣分）。

## 6. 怎麼交

不用交給任何人。作答都在帳本裡：`lessons/0-C/` 的 `rebuild/`、`pwd.txt`、`ai_explain.txt`、`make_v0.sh`、`checks.txt`，還有帳本最上層的 `main.py` 和存檔點。

三關都過、練習滿 3 天，`uv run check.py status` 會顯示「已升級」。練習天數＝跑課號檢查或答回顧題的不同日子，同一天做再多也只算一天。
