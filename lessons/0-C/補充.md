# 0-C 補充：Lv0 關卡，帳本 v0

影片說明欄放不下的參考資料。三關的完整步驟在同一個資料夾的 [README.md](README.md)。

## 這一關跟一般的課差在哪

一般的課是邊看邊學、跟著做。關卡是你自己做：影片只說怎麼開始、每一關在考什麼、怎麼對答案，示範題都跟作答檔裡的題目不一樣。題目只用到新手村教過的東西（0-3 到 0-8），全程關掉 AI。

## 預測分數和校準曲線

- 開始前（`uv run check.py start lv0`）先猜一次會過幾題，三關做完、對答案前（`uv run check.py lv0`）再猜一次。這兩個數字不算成績，只是記下來，跟實際過了幾題比。
- 每次檢查猜的跟實際差多少，都記在你帳本的 `.check/` 裡；打 `uv run check.py status`，「校準曲線」那一段會一次一行畫出來（右邊是高估、左邊是低估），關卡另外列出「開始前猜、做完猜、實際過了幾題」。
- 猜的跟實際差 30 個百分點以上，它會請你寫一句「下次我會怎麼估」（也可以自己打 `uv run check.py note "下次我會……"`）。
- 為什麼要先猜：有一個研究請 246 個人用 AI 解 20 題邏輯題（美國法學院入學考試的題目），大家估自己的表現，平均比實際高了 4 分（Fernandes 等人，Computers in Human Behavior 第 175 卷；原文：participants overestimated their performance by four points）。用 AI 做完，不等於自己會；所以關卡先關掉 AI，自己做、自己估，再對答案。
- 這門課不保證「越估越準」，曲線只是讓你看得到自己估得準不準。

## 升級怎麼算

- 三關各自第一次全部通過，check.py 會記下日期（`status` 看得到，例如「第一關✓11/20」）。
- 三關都過，再加上練習天數滿 3 天，就升上 Lv1。練習天數＝你跑課號檢查（例如 `uv run check.py 0-7`、`uv run check.py lv0`）或答回顧題的不同日子，從你第一次用 check.py 算起；同一天做再多，也只算一天。
- 這跟每一課的葉子是同一個想法：葉子要過兩課以後、改天再答對回顧題才長；升級也要分成不同天回來練。
- 不到 5 分鐘就全部做對，會跳出警訊（0-8 講過的時間規則）。只是提醒，不扣分、不擋升級。

## 跑錯了怎麼辦

- **第三關沒刪危險那一行就跑了：** 會刪掉 `lessons/0-C-保險箱/`（練習用的收據，不是你真的東西）。在課程資料夾再打一次 `uv run check.py start lv0`，它會把不見的練習檔補回來（已經有的不會蓋掉），找出危險那一行、刪掉再跑。
- **第一關把帳本的 main.py 換錯了：** 0-7 按過存檔點，在 VS Code 的原始碼控制，滑到 main.py 那一列按往回轉的箭頭（Discard Changes），就回到上一個存檔點。
- **想整關重來：** 刪掉帳本裡的 `lessons/0-C/`，再打一次 `uv run check.py start lv0`。進度和預測紀錄不會不見（記在帳本的 `.check/`）。

## 你的畫面跟影片不一樣？

- 提示字元前面是你自己的帳號和電腦名稱（影片是示範用的 `bear@MacBook-Air`）。`pwd.txt` 寫的是熊的電腦（家目錄 `/Users/bear`），照題目寫就好，不是寫你自己的路徑。
- `start lv0` 列出的檔案順序、`check.py` 印的字可能比影片新一點，看意思就好。
- `git pull` 沒有說 `Already up to date.`，而是列出一些更新的檔案：代表課程資料夾剛好有新的內容，沒關係。

## Windows

- 全部在 Git Bash 裡打，指令一樣（`bash make_v0.sh` 也一樣）。VS Code 裡 ⌘ 換成 Ctrl，存檔點的按法跟 Mac 一樣（0-7）。
- `pwd.txt` 一樣寫熊的 Mac 路徑（從 `/Users/bear` 開始），不用改成 `/c/Users/…`。
- check.py 複製 `make_v0.sh` 時會把換行改成 Linux 的樣子；你用 VS Code 改完存檔，右下角如果寫 CRLF，點一下改成 LF 再存（不然 bash 可能會建出名字怪怪的資料夾）。

## 名詞小抄

- **關卡**：每一級最後的檢查，關掉 AI 自己做。三關都過、練習滿 3 天才升級。
- **預測分數**：做之前先猜自己會過幾題。
- **校準曲線**：每次猜的跟實際差多少，排成一條線。
- **腳本**：把好幾行指令寫在同一個檔案裡；`bash 檔名` 會從第一行開始一行一行照跑。
