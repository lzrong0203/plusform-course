## 1. 這一課的三條規矩

1. **裝之前先查**：到 PyPI 看名字拼對了沒、誰在維護、最近一次發布、原始碼在哪裡。AI 給你的套件名一樣要查。
2. **套件一律用 `uv add`**：它會寫進 pyproject.toml、記進 uv.lock，再裝進 .venv。不要用 `pip install`，也不要用 `uv pip install`。
3. **交給 AI 裝的，在乾淨複本上跑過才收**：check 2-2 會把 pyproject.toml、uv.lock、report.py 複製到沒有 .venv 的地方，打 `uv sync --locked` 重新裝、再跑。

## 2. PyPI 是什麼、怎麼查一個套件（PyPI 官方文件 docs.pypi.org，2026-11-19 擷取）

- 念法：`The Python Package Index (PyPI), pronounced "pie-pea-eye", is the official package repository for Python.` 註腳：`"PyPI" should be pronounced like "pie pea eye", specifically with the "PI" pronounced as individual letters, rather than a single sound. This minimizes confusion with the PyPy project, which is a popular alternative implementation of the Python language.`
  - 所以 **PyPI ≠ PyPy ≠ PyPy 熊**：PyPI 是套件倉庫；PyPy 是另一種跑 Python 的程式；PyPy 熊是這門課的熊。
- 誰都可以放：`PyPI is a public repository where anyone can upload projects of any quality. Because PyPI does not pre-screen or review projects before they are published, most of the information you see is provided by the project maintainers rather than PyPI itself.`
- 哪些資料可信：`Unless a piece of information is explicitly labeled as "PyPI data" or "Verified," assume it is unverified.` rich 的頁面上，維護者（1 maintainer）和發布日期（Key dates）標著 PyPI data；Project links 是作者自己填的，沒有 Verified 標記。
- 有在維護嗎：`An active commit history and recent releases indicate the project is maintained`（Assessing Source Code Security）。
- 拼錯名字：`Typosquatting … An attacker publishes a malicious project with a name that is a common misspelling of a popular, legitimate project` ／ `Your best defense is to always double check the spelling of a package you are installing`。
- AI 給的名字：`Always check package names from LLM output, as an attacker could register a malicious package that an LLM may hallucinate (this is known as slopsquatting).`
- 2026-11-19 的 rich：最新版 15.0.0（2026-04-12 發布），1 位維護者，Homepage 連到 https://github.com/Textualize/rich ，需要 markdown-it-py、pygments（markdown-it-py 再需要 mdurl）。

## 3. uv add、pyproject.toml、uv.lock、.venv（uv 官方文件 docs.astral.sh/uv，2026-11-19 擷取）

- uv add：`You can add dependencies to your pyproject.toml with the uv add command. This will also update the lockfile and project environment`；`The dependency will include a constraint, e.g., >=0.27.2, for the most recent, compatible version of the package.`
- pyproject.toml 和 uv.lock：`Unlike the pyproject.toml, which is used to specify the broad requirements of your project, the lockfile contains the exact resolved versions that are installed in the project environment. This file should be checked into version control, allowing for consistent and reproducible installations across machines.`
- uv.lock 不要手改：`uv.lock is a human-readable TOML file but is managed by uv and should not be edited manually.`
- .venv：`The .venv folder contains your project's virtual environment, a Python environment that is isolated from the rest of your system. This is where uv will install your project's dependencies.`；`It is not recommended to include the .venv directory in version control; it is automatically excluded from git with an internal .gitignore file.`
- uv sync：`uv sync performs "exact" syncing by default, which means it will remove any packages that are not selected for installation.`；`--locked`：`If the lockfile is not up-to-date, uv will raise an error instead of updating the lockfile.`
- uv pip install：`It is not recommended to modify the project environment manually, e.g., with uv pip install. For project dependencies, use uv add to add a package to the environment.`

## 7. 對答題的說明（作業做完再看）

**第 1 題（哪一份少了依賴）答案 C。** report.py 要的是 rich。C 寫了 markdown-it-py、pygments（rich 自己需要的套件，uv.lock 裡會看到），卻沒寫 rich 本身，換一台電腦 uv sync 就不會裝 rich。B 多寫了 pygments，多但不少，跑得起來。pyproject.toml 寫你直接要用的套件，它們再需要什麼，由 uv 記在 uv.lock。

**第 2 題（同學裝到的版本）答案 A。** uv 官方文件：pyproject.toml 寫的是大概的需求（rich>=15.0.0），uv.lock 記的是確切裝了哪個版本；uv.lock 要進版本控制，換一台電腦也裝得一模一樣。C 不對：.venv 裡面有 uv 放的 .gitignore，不會進存檔點（官方也不建議放）。

**第 3 題（uv pip install 的套件）答案 B。** uv pip install 只把套件裝進現在這個 .venv，不寫進 pyproject.toml、uv.lock（uv 官方文件：不建議用 uv pip install 改專案環境，專案要用的套件用 uv add）。乾淨複本照 pyproject.toml、uv.lock 裝，沒有 prettytable，一跑就 ModuleNotFoundError。熊自己的帳本打 uv sync，它也會被拿掉（uv sync 預設會移除 uv.lock 裡沒有的套件）。
