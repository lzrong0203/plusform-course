# 1-C4　檢核站 4　卷 B（關掉 AI，30 分鐘）

卷 A 交卷沒過的同學，照矯正包練完以後，**隔天以後**考這一份。題目跟卷 A 不一樣，每一題考的東西跟卷 A 同一題一樣（1-18～1-23：函式、預設值與範圍、型別提示、模組與 import、錯誤處理、檔案讀寫）。全程關掉 AI；參考時間 30 分鐘，只記錄、不擋你。說明照卷 A 的 [README](../README.md)，這裡只寫不一樣的地方。

## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-C4B` 會問你），交卷時再問一次。

**第一部分：追蹤（`trace.txt`，6 題）。** 三段程式，每一段都有函式；先不要跑，用眼睛追、在紙上畫小框，在「答：」後面寫答案。

**第二部分：找問題（`except.txt`，3 題）。** 一段用 try／except 把錯接住的程式：它印出什麼、打錯一個字會怎樣、要怎麼改。

**第三部分：手寫（`write.py`，4 題）。** 寫好 `pay_total(path)`：打開一個付款紀錄檔（每一行是 `日期,付款方式,金額`），把每一筆的金額加起來，用 return 交回。check 會自己寫三個檔案交給它：三筆的、最後一行後面沒有換行的、空的，每一個檔各算一題（交回整數）；另外一題看寫法：`with open(…, encoding="utf-8")` 和 return。

## 2. 提示

跟卷 A 一樣：呼叫函式就畫一個小框，框裡給值的名字是框自己的，沒有 return 交回 None；預設值 `[]` 只做一次；list 交進函式會被改；import 會把那個檔從頭跑一遍，`if __name__ == "__main__":` 底下的只有直接跑才跑；型別提示不檢查；光禿禿的 except 什麼錯都接；讀檔用 `with open(…, encoding="utf-8")`、`rstrip("\n")`、`split(",")`、`int()`。卡住了回矯正包寫的那幾段影片，不問 AI。
