# 1-C4 檢核站 4：補充

影片和 [README](README.md) 放不下的細節：這一站怎麼判分、check 怎麼測你的函式、卡住了回哪一課看、矯正包和卷 B 怎麼用、為什麼考前要先猜分數、Windows 的做法。

## 1. 這一站怎麼運作

- **考什麼**：只考 1-18～1-23（函式、預設值與範圍、型別提示、模組與 import、錯誤處理、檔案讀寫），三部分一共 13 題：追蹤 6 題（`trace.txt`）、找問題 3 題（`except.txt`）、手寫 4 題（`write.py`）。
- **全程關掉 AI**：VS Code 的 AI 功能 0-6 關了；聊天的 AI 和 0-8 設好的家教，這一站也先不開。
- **開始**：`uv run check.py start 1-C4`。它把三個作答檔和 `sample.txt` 複製到帳本的 `lessons/1-C4/`，再問你「一共 13 題，你覺得會過幾題」。
- **交卷**：三部分都寫好，打 `uv run check.py 1-C4`。它會再問你一次猜幾題，然後對答案。**第一次交卷就過 11 題以上，這一站就過了。**
- **還沒寫完不算交卷**：還有「答：」空著、`write.py` 沒動，check 會列出來，這次不算交卷。不會的也寫一個你覺得最可能的答案；真的寫不出來，加 `--submit` 照樣交卷。
- **交卷以後再打是訂正**：可以看自己改對了沒（平常只顯示第一個沒過的，加 `--all` 看全部），成績還是照第一次交卷算。
- **30 分鐘只記錄**：check 照「打 start 的時間」到「三個作答檔最後一次存檔的時間」算你花了多久，印出來給你參考，超過也不扣分、不擋你。
- **不擋你往下上課**：過了沒過，都可以接著上 1-24。

## 2. 三部分怎麼判

- **追蹤**：在「答：」後面寫印出來的樣子。印 list 的照印出來的寫，方括號、逗號都要（空格多少不算）；一行印好幾個值的（例如 `1 2 2`），值和值中間要空一格，`122` 不算對。選擇題只寫一個字母，寫兩個（例如「A 或 C」）不算。
- **找問題**：第 1 題寫印出來的那一行，第 2、3 題選一個字母。三題各看一件事：錯有沒有被吞掉（變成一個看起來正常的數字，合計看不出哪裡錯）、接的是不是太多（光禿禿的 except 連打錯字的 NameError 也接住）、哪一種改法兩個問題都解決。
- **手寫**：四題。第一題只看寫法：`file_total` 裡面打開檔案要用 `with open(…)`，每一個 open 都寫 `encoding="utf-8"`，而且要用 return 交回一個值。另外三題真的呼叫你的函式，一個檔一題，交回的值要一模一樣、而且是整數（315，不是字串 "315"、也不是小數 315.0）。

## 3. check 怎麼測你的函式

對答案的時候，check 在系統的暫存資料夾寫好三個帳本檔案（你帳本裡的檔一個都不動），把檔案的位置交給 `file_total`，在同一個程式裡照順序呼叫三次：

- 三筆的帳本，交回 315：`11/03,午餐,120`、`11/04,公車,15`、`11/05,晚餐,180`（每一行後面都有換行）
- 兩筆、最後一行後面沒有換行的帳本，交回 510：`12/01,書,450`、`12/02,咖啡,60`（最後一行後面沒有換行）
- 空的檔案，交回 0。

為什麼要三種？用 `line[:-1]` 拿掉換行，前兩行都對，可是最後一行後面沒有換行時，切掉的是金額的最後一個字（60 變成 6）；一次把整個檔讀進來、用換行切開的寫法，最後多一個空字串，三筆和空的檔就拆不開；只讀第一行的，三種都錯。三次在同一個程式裡呼叫，所以把金額存在函式外面（例如預設值用 `[]`）、第二次就錯的，也抓得到。

寫法那一題為什麼要看 `encoding="utf-8"`？在 Mac 上沒寫也讀得出來；很多 Windows 電腦會用系統預設的編碼讀（台灣常見的是 cp950；自己開了 UTF-8 模式的例外），UTF-8 存的中文可能讀成亂碼或跳出 UnicodeDecodeError（1-23 的 Windows 小卡）。check 在每台電腦上判的要一樣，所以看寫法：要直接寫 `encoding="utf-8"`，沒寫、或用變數交進去，都不算。

## 5. 矯正包怎麼用

交卷沒過（或過了但有錯的題目），check 會寫一份 `矯正包.md` 到帳本的 `lessons/1-C4/`（卷 B 的寫在 `lessons/1-C4B/`）。照順序做：

1. **錯在哪裡**：每一題你寫了什麼、正確答案和為什麼；程式題附 check 的說明（交給它哪一個檔、應該交回什麼、你的交回）。
2. **回原課看那一段**：照上面那張表的時間碼，看那一章。
3. **做練習**：每個練習檔最上面寫著怎麼做。追蹤的先在紙上畫小框、寫下答案，再用 `uv run` 跑一次對答案；要改、要寫的，改好、寫好再跑。
4. **隔天以後考卷 B**：`uv run check.py start 1-C4B`。

練習的時候一樣關掉 AI。

## 6. 卷 B

- 卷 A 交卷的**隔天以後**才能開始（同一天打 `start 1-C4B`，它會請你明天再來）。
- 題目不一樣，每一題考的東西跟卷 A 同一題一樣（例如第 3 題都是「預設值 [] 共用同一個盒子」；手寫都是讀檔加總，卷 B 是付款紀錄 `日期,付款方式,金額`）。
- 作答檔在帳本的 `lessons/1-C4B/`，交卷打 `uv run check.py 1-C4B`。第一次交卷過 11 題以上，檢核站 4 一樣算過。
- 卷 B 也沒過：照它的矯正包把那幾段再看一次、練習做完，再接著上課。卷 A 就過了的人，卷 B 不用考（想多練一次也可以）。
- 卷 B 由 AI 照卷 A 的概念清單出題，答案都用 Python 3.13 實際跑過。

## 7. 為什麼考前要先猜分數

開始時猜一次、交卷時再猜一次，對完答案看猜的跟實際一不一樣。兩次猜的和實際過了幾題，都記進校準曲線（`uv run check.py status`）；不一樣太多時，check 會請你寫一句「下次我會怎麼估」。

有一個研究請 246 個人用 AI 解 20 題邏輯題（美國法學院入學考試的題目），大家估自己的表現，平均比實際高了 4 分（Fernandes 等人，原文：participants overestimated their performance by four points）。做完了，也可能把自己估得太高；所以這一站先關掉 AI，自己做、自己估，再對答案。這門課不保證越估越準，曲線只是讓你看到自己估得準不準。
