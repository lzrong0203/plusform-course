## 2. 提示

- 函式呼叫時開一個小框：參數的值放進框裡；函式裡給了值的名字（`名字 = …`）是框自己的，外面那個不會變；沒有 return，交回 None（1-18、1-19）。
- 沒給的參數用預設值；用名字給的（`tip=2`）交給那個名字。預設值只在 Python 讀到 def 那一行時做一次，預設值是 `[]` 的話，沒給的呼叫都共用同一個盒子（1-19）。
- list 交進函式，函式裡的名字和外面的名字指著同一個盒子，`append` 改的是盒子裡面（1-18）。
- `import` 會把那個檔從頭跑一遍；`if __name__ == "__main__":` 底下的，只有直接跑那個檔才跑（1-21）。
- 型別提示（`n: int`、`-> str`）只是說明，Python 跑的時候不檢查（1-20）。
- try 裡面出錯，那一行後面的跳過，跳到對得上的 except；`except` 後面什麼都不寫（光禿禿的 except），什麼錯都接，連打錯字的 NameError 也接住；`raise ValueError(…)` 把錯丟出去（1-22）。
- 讀檔：`with open(path, encoding="utf-8") as f:`，`for line in f:` 一次一行；`line.rstrip("\n")` 拿掉最後的換行，`split(",")` 用逗號切開，`int()` 變成整數（1-23）。
- 不會的也要寫：空著的題目，check 不讓你交卷（真的寫不出來，加 `--submit` 照樣交卷）。
