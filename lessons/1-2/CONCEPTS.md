# 1-2 用到的概念

這課的示範、起點檔、正確版（`reference/`）和壞版本（`mutants/`），只能用到下面這些概念。
老師端的 `tools/validate_lesson.py` 會用 Python 的 ast 模組粗略檢查，壞版本用到沒列的概念就不能收進題庫。

## 可以用的概念

- 註解
- print（含逗號隔開好幾樣，1-1 教過）
- 變數
- 資料型別（例外：只用引號裡的字和整數，像 "午餐"、120；concept_map 會把它算成資料型別，型別的名字到 1-3 才教）
- 數字運算（例外：只有加和減，1-4 才細講）
- list（例外：只出現在第③圈課程版本的 sum([…])。學員不用寫、也不用看懂方括號，影片只說「sum 是 Python 本來就有的加總功能」；1-13 才教 list）

第③圈的壞版本 `receipt_m1.py` 把合計取名叫 `sum`，蓋掉 Python 本來的加總功能，下一行再用 `sum(...)` 就當掉（TypeError）。學員只要照需求卡寫出完整的預期輸出就抓得到它，不用看懂程式。
