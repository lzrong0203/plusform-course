# 判讀紀錄：量表和範例（自評用）

判讀紀錄是自評，不對答案、不擋過關。寫完照下面的量表給自己打分，跟範例比一比。
1-9 會再寫一張更完整的「AI 建議判讀卡」，這一張先練最基本的四件事：AI 說了什麼、你查了什麼、你的決定、理由。

## 量表（每項 0–2 分）

| 項目 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 查證 | 沒查，或只寫「AI 說的」 | 寫了「學過／沒學過」或「我覺得」，沒說看到什麼 | 寫出自己跑了什麼、看到什麼，或指出哪一課、哪份官方文件 |
| 決定跟證據對得起來 | 決定跟查到的東西對不起來 | 大致對得起來，但中間跳了一步 | 看了查證和理由，就知道為什麼這樣決定 |
| 用自己的話 | 照抄 AI 的話 | 一半是自己的話 | 全部是自己的話，別人看得懂 |

## 範例（6 分）：影片裡熊的第一張判讀紀錄

**AI 說了什麼：** 「Python 3 也可以用中文當名字，例如 早餐 = 45，看起來更直覺，建議你改成中文。」

**我查了什麼：** 自己在 VS Code 打 `早餐 = 45`、`print(早餐)`，跑出來印 45，真的可以。Python 官方文件也寫「蛇」這種中文字可以當名字（PEP 3131，Python 3.0 開始）。接著打 `print（早餐）`，括號在中文輸入法裡打成全形，跑出 `SyntaxError: invalid character '（' (U+FF08)`。

**我的決定：** 先不採用。

**理由：** AI 說的沒錯，中文名字跑得動。可是我打中文要切輸入法，括號很容易變成全形，程式就停住；這門課的作業和檢查程式也都用英文名字。我先練習取看得懂的英文名字，以後寫給只看中文的人用的小程式，再考慮中文名字。
