# 1-2　變數：給資料取名字

這課大約 40 分鐘。三圈比例 70／20／10。Windows 同學：指令在 Git Bash 照打，⌘ 換成 Ctrl（安裝見 0-W）。

## 1. 題目

**第①圈：自己寫（關掉 AI）。**

A. 追蹤表（`trace.txt`）：兩段程式，先不要跑，用眼睛一行一行追，寫出某一行跑完以後名字裡放的是什麼（6 題，每題寫一個數字）。建議先在紙上畫追蹤表：

| 跑完第幾行 | money | juice |
|---|---|---|
| 1 | 300 | |
| 2 | 300 | 50 |
| … | | |

B. 合計（`total.py`）：果凍兔今天花了三筆：果汁 50 元、晚餐 130 元、捷運 25 元。照檔案裡每一步的註解，把三筆各放進一個名字（`juice`、`dinner`、`mrt`），用名字加起來放進 `total`，最後印出：

```
今天花了 205 元
```

影片裡熊的錢包在 `wallet.py`、熊寫的合計在 `today.py`（只有每一步的註解，可以跟著影片打），都可以自己跑跑看，跟你畫的追蹤表對一對。

**第②圈：判斷 AI 的意見（`ai_review.txt`）。** 熊把影片裡的合計程式拿給 AI 看，AI 回了 4 則意見（課程準備的範例示意），其中有的說錯了。每一則判成「採用、不採用、要查證」，寫一句理由，再對答案。最後挑一則寫你的第一張「判讀紀錄」（`record.md`，自評，不檢查）：AI 說了什麼、你查了什麼、你的決定、理由。

想用自己的家教練習（自評，不檢查）：在 0-8 建好的家教專案裡貼上你的 `total.py`，說「我剛學變數，請只指出名字取得好不好，不要給完整答案」。它給的每一條建議，都先查證再決定。

**第③圈：先寫預期輸出，再驗收 AI 的程式（`expected.txt`）。** 需求卡：

| 欄 | 內容 |
|---|---|
| 目標 | 印出果凍兔今天的收據 |
| 背景 | 錢包本來有 300 元；今天果汁 50 元、晚餐 130 元、捷運 25 元 |
| 限制 | 一行印一項：名稱、空一格、金額、空一格、「元」（就是 `print("果汁", juice, "元")` 印出來的樣子） |
| 怎樣算做完 | 先印三筆（果汁、晚餐、捷運），再印「合計」、「飲食」（果汁加晚餐）、「錢包剩下」，一共六行 |

AI 照這張需求卡交出了三個版本（課程準備的，放在 `mutants/`，正確版在 `reference/`）。你**先不要看它們**，照需求卡自己算，把收據「應該印出來的樣子」一行一行寫進 `expected.txt`。check 會拿你寫的，跟正確版和三個版本印出來的一行一行比：正確版要跟你寫的一模一樣，三個版本各要被你抓到。

## 2. 提示

- `money = 100` 的意思是：把 100 放進 `money` 這個名字。等號 `=` 在 Python 裡是「放進去」，不是「等於」。
- `money = money - 35`：**右邊先算**。拿出 money 裡原本的值減 35，再放回 money，原本的值就被換掉了。
- 只寫 `money - 35`、前面沒有 `money =`：有算出結果，可是沒有放進任何名字，money 不會變。
- 一個名字改了，不會回頭改別的名字。`money = money - juice` 算完以後，再改 juice，money 不會跟著變。
- `print(money)` 沒有引號，印的是 money 裡放的值；`print("money")` 有引號，印的是 money 這幾個字。
- 名字的規定：只能用字母、數字、底線 `_`，不能用數字開頭，中間不能有空格。大小寫不一樣就是不同的名字（`Total` 和 `total` 是兩個名字）。
- 這門課的習慣：名字用看得懂的英文小寫，兩個字以上用底線接（例如 `food_total`）；不要用 Python 本來就有的名字（例如 `sum`、`print`、`input`）。
- `expected.txt`：一個字、一個空格都要一樣（全形、半形的冒號都可以）；`#` 開頭的說明行 check 不看。

## 3. 開始前要打的指令

```bash
cd ~/code/plusform-course
git pull
uv run check.py start 1-2
```

它會把起點檔複製到你的帳本 `lessons/1-2/`：`wallet.py`、`today.py`、`trace.txt`、`total.py`、`ai_review.txt`、`record.md`、`expected.txt`。

用 VS Code 打開帳本，寫完存檔，在 VS Code 下面的終端機（帳本資料夾）自己跑跑看：

```bash
uv run lessons/1-2/wallet.py
uv run lessons/1-2/total.py
```

檢查的時候**回到課程資料夾**：

```bash
cd ~/code/plusform-course
uv run check.py 1-2
```

（也可以不切資料夾，直接打完整路徑：`uv run ~/code/plusform-course/check.py 1-2`。課號寫 `1-02` 也可以。）

## 4. 成品示範

```
$ uv run lessons/1-2/total.py
今天花了 205 元
```

全部做完的時候，check 最後會說：

```
你的預期輸出把 3 個壞版本全部抓到了。
```

## 5. 怎麼測

`uv run check.py 1-2` 會先問你：「你覺得會過幾題？」先猜一個數字再按 Enter，它才開始檢查。一共 16 題：

- 對答：`trace.txt` 6 題、`ai_review.txt` 4 題
- 官方測試：`total.py` 印出的那一行
- 第三圈：`expected.txt` 寫滿 6 行、跟正確版一模一樣、抓到 3 個壞版本

`record.md`（判讀紀錄）是自評，check 不看；量表和範例在課程資料夾的 `lessons/1-2/answers/record_example.md`。

沒過的，它只先告訴你第一個沒過的，修好再跑一次（想一次看全部，最後加 `--all`）。不到 8 分鐘就全對，它會印出提醒：只是提醒，不扣分。

## 6. 怎麼交

check 全對就算這課過了，它會記在你帳本的 `.check/` 裡，不用上傳。在 VS Code 按一個存檔點（說明寫「1-2 完成」）。

技能樹上這課的葉子，要過兩課以後、改天答對回顧題才會長出來。補充說明（中文名字的官方說法、sum 為什麼會當掉、名詞小抄）在 `補充.md`。
