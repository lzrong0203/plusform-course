**官方教學 5.3 Tuples 和序列**（https://docs.python.org/zh-tw/3.13/tutorial/datastructures.html#tuples-and-sequences）

```
5.3. Tuples 和序列 (Sequences)¶

我們看到 list 和字串 (string) 有許多共同的特性，像是索引操作 (indexing) 以及切片操作 (slicing) 。他們是序列資料類型中的兩個例子（請參考Sequence Types --- list, tuple, range）。由於 Python 是個持續發展中的語言，未來可能還會有其他的序列資料類型加入。接著要介紹是下一個標準序列資料類型：tuple。

一個 tuple 是由若干個值藉由逗號區隔而組成，例如：

>>> t = 12345, 54321, 'hello!'
>>> t[0]
12345
>>> t
(12345, 54321, 'hello!')
>>> # Tuple 可以為巢狀的：
>>> u = t, (1, 2, 3, 4, 5)
>>> u
((12345, 54321, 'hello!'), (1, 2, 3, 4, 5))
>>> # Tuple 為不可變的：
>>> t[0] = 88888
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'tuple' object does not support item assignment
>>> # but they can contain mutable objects:
>>> v = ([1, 2, 3], [3, 2, 1])
>>> v
([1, 2, 3], [3, 2, 1])

如同我們看到的，被輸出的 tuple 總是以括號包著，如此巢狀的 tuple 才能被正確的直譯 (interpret)；他們可以是以被括號包著或不被包著的方式當作輸入，雖然括號的使用常常是有其必要的（譬如此 tuple 是一個較大的運算式的一部分）。指派東西給 tuple 中的個別項目是不行的，但是可以建立含有可變物件（譬如 list）的 tuple。

雖然 tuple 和 list 看起來很類似，但是他們通常用在不同的情況與不同目的。 tuple 是 immutable（不可變的），通常儲存異質的元素序列，並可經由拆解 (unpacking)（請參考本節後段）或索引 (indexing) 來存取（或者在使用 namedtuples 的時候藉由屬性 (attribute) 來存取）。List 是 mutable（可變的），其元素通常是同質的且可藉由疊代整個 list 來存取。

一個特別的議題是，關於建立一個含有 0 個或 1 個項目的 tuple：語法上會採納一些奇怪的用法。空的 tuple 藉由一對空括號來建立；含有一個項目的 tuple 經由一個值加上一個逗點來建立（用括號把一個單一的值包住是不夠的）。醜，但有效率。例如：

>>> empty = ()
>>> singleton = 'hello',    # <-- 注意後面有個逗號
>>> len(empty)
0
>>> len(singleton)
1
>>> singleton
('hello',)

陳述式 t = 12345, 54321, 'hello!' 就是一個 tuple packing 的例子：12345，54321 和 'hello!' 一起被放進 tuple 裡。反向操作也可以：

>>> x, y, z = t

這個正是我們所說序列拆解 (sequence unpacking)，可運用在任何位在等號右邊的序列。序列拆解要求等號左邊的變數數量必須與等號右邊的序列中的元素數量相同。注意，多重指派就只是 tuple packing 和序列拆解的結合而已。
```

## 3. tuple：一筆不會改的帳

下面都是 Python 3.13.18 實際跑出來的（出錯的只印錯誤訊息的最後一行）：

```
>>> record = ("11/03", "午餐", 120)

>>> record[0]
'11/03'

>>> record[-1]
120

>>> len(record)
3

>>> record[2] = 90
TypeError: 'tuple' object does not support item assignment

>>> record.append(1)
AttributeError: 'tuple' object has no attribute 'append'

>>> one = (120)
... print(one, type(one))
120 <class 'int'>

>>> one = (120,)
... print(one, type(one))
(120,) <class 'tuple'>

>>> t = 1, 2, 3
... print(t)
... print(type(t))
(1, 2, 3)
<class 'tuple'>
```

- tuple 跟 list 一樣用索引拿、用 len 算有幾個；差在**放進去就不能改**：改某一格是 TypeError，也沒有 append。
- 記錯了就整筆換掉：`record = ("11/03", "午餐", 90)`。這一行沒有改到原本那個 tuple，是 record 這個名字拿到一個新的 tuple（家教在影片裡說的「指向一個新的 tuple」）。
- 只有一個值的 tuple，後面要加逗號：`(120,)`。只寫 `(120)` 是加了括號的整數。
- 其實逗號才是 tuple 的關鍵：`t = 1, 2, 3` 沒有括號也是 tuple，印出來 Python 會補上括號。
- 什麼時候用 tuple、什麼時候用 list：官方教學說 tuple 通常放「不同種類」的東西、用拆包或索引拿；list 通常放「同一種」東西、用迴圈一個一個拿，而且可以改。一筆帳（日期、項目、金額三種東西、記下來就不改）適合 tuple；一整個月的帳（一筆一筆加上去）適合 list，list 裡面每一筆是 tuple。

## 4. 拆包與交換

```
>>> date, item, amount = record
... print(date)
... print(item)
... print(amount)
11/03
午餐
120

>>> date, item = record
ValueError: too many values to unpack (expected 2)

>>> a, b, c, d = record
ValueError: not enough values to unpack (expected 4, got 3)

>>> a = 3
... b = 5
... a, b = b, a
... print(a, b)
5 3

>>> a = 3
... b = 5
... temp = a
... a = b
... b = temp
... print(a, b)
5 3
```

- 拆包：左邊的名字照順序一個對一個拿右邊的值。個數要一樣：名字比較少是 `too many values to unpack`，名字比較多是 `not enough values to unpack`。
- 交換 `a, b = b, a`：Python 先把右邊算好（拿出 b 和 a 的值，包成一組），再照順序放進左邊，所以不會互相蓋掉。傳統的寫法是多用一個名字暫放（上面第二段的 temp），一樣對，只是多兩行。

## 5. for 後面也能拆包（影片沒有演）

```
>>> records = [("11/03", "午餐", 120), ("11/03", "車錢", 30)]
... for date, item, amount in records:
...     print(date, item, amount)
11/03 午餐 120
11/03 車錢 30

>>> week = [120, 85]

...     print(pair)

```

- 一整個月的帳是 list，裡面每一筆是 tuple；for 後面寫三個名字，每拿到一筆就拆開。

## 6. set：一袋不重複的東西

```
>>> cats = ["餐飲", "交通", "餐飲", "娛樂", "交通", "餐飲"]
... print(len(cats))
6

>>> s = set(cats)
... print(len(s))
3

>>> print("餐飲" in s)
... print("房租" in s)
True
False

>>> s.add("娛樂")
... print(len(s))
3

>>> s.add("日用品")
... print(len(s))
4

>>> s[0]
TypeError: 'set' object is not subscriptable

>>> print(type({}), type(set()))
<class 'dict'> <class 'set'>

>>> nov = {"餐飲", "交通", "娛樂"}
... dec = {"餐飲", "交通", "醫療"}
... print(sorted(nov & dec))
... print(sorted(nov | dec))
... print(sorted(nov - dec))
... print(sorted(dec - nov))
['交通', '餐飲']
['交通', '娛樂', '醫療', '餐飲']
['娛樂']
['醫療']

>>> nums = {30, 120, 85}
... r = sorted(nums)
... print(r)
... print(type(r))
[30, 85, 120]
<class 'list'>

>>> nums.sort()
AttributeError: 'set' object has no attribute 'sort'
```

- `set(一串)` 把重複的拿掉；`in` 問有沒有；`add` 加一個，已經有的不會變多；set 沒有索引（`s[0]` 是 TypeError）。
- 空的 set 要寫 `set()`；`{}` 是 1-15 才教的 dict（官方教學 5.4 特別提醒）。
- `a & b` 交集（兩邊都有）、`a | b` 聯集（任何一邊有）、`a - b` 差集（a 有、b 沒有）。順序反過來 `dec - nov` 就是 12 月有、11 月沒有的（上面印出 `['醫療']`）。
- set 沒有 `sort()`；要排好用 `sorted(...)`，交回的是 list。

## 7. set 的順序為什麼每次不一樣

同一段程式，分開跑 8 次（每次都是一個新的 Python），第一行是 `print(set(kinds))` 印出來的樣子：

```
第 1 次：{'娛樂', '交通', '餐飲'}
第 2 次：{'娛樂', '餐飲', '交通'}
第 3 次：{'交通', '娛樂', '餐飲'}
第 4 次：{'餐飲', '娛樂', '交通'}
第 5 次：{'娛樂', '餐飲', '交通'}
第 6 次：{'娛樂', '餐飲', '交通'}
第 7 次：{'交通', '娛樂', '餐飲'}
第 8 次：{'娛樂', '交通', '餐飲'}
```

- 8 次裡有 4 種順序，其中有兩次剛好是排好的。**剛好排好，不代表 set 會排序。**
- 原因：Python 用每個值的「雜湊值」（一個算出來的數字）決定它在 set 裡放哪裡。字串的雜湊值，每次執行 Python 都會加上一個猜不到的亂數（官方文件說這是為了安全），同一次執行裡不變，換一次執行就不一樣，所以字串的 set 每次跑的順序可能不同。官方文件也寫：Python 從來沒有保證 set 的順序。
- 小的整數，雜湊值就是它自己，所以 `{3, 1, 2}` 常常印成 `{1, 2, 3}`，看起來像排好了；換成 `{30, 120, 85}` 就印出 `{120, 85, 30}`。這也只是現在這個版本剛好這樣，不能依賴。
- 結論：需要固定的順序，一律用 `sorted(...)`。

```
['2026/10/30', '2026/11/12', '2026/11/3']
```

字串是一個字一個字比的（官方文件：照每個字的 Unicode 編號比）。`"2026-11-03"` 這種寫法，年、月、日都補成固定長度，一個字一個字比就剛好是照日期比；寫成 `"2026/11/3"` 沒有補 0，`"2026/11/12"` 的第 9 個字 `1` 比 `"2026/11/3"` 的 `3` 小，就被排到前面了。日期要照字排，記得月、日都寫兩位數。

## 8. 中文用 sorted 排，是照什麼排？

```
>>> print(sorted(["餐飲", "交通", "娛樂", "醫療"]))
['交通', '娛樂', '醫療', '餐飲']

>>> print([hex(ord(x[0])) for x in ["交通", "娛樂", "餐飲", "醫療"]])
['0x4ea4', '0x5a1b', '0x9910', '0x91ab']
```

照每個字在電腦裡的編號（Unicode 碼位）比，不是注音、也不是筆畫：交（4EA4）< 娛（5A1B）< 醫（91AB）< 餐（9910）。不用背，不確定的時候用 sorted 跑一次看排出來的樣子。

## 9. 第③圈：三個壞版本錯在哪

需求卡：`both_months(nov, dec)` 交回兩個月都有花錢的分類，每個分類只出現一次，而且排好序（用 sorted 排，交回 list）。正確版只有一行：`return sorted(set(nov) & set(dec))`。

- **壞版本 1**（影片裡溜過去的那一個）：`return set(nov) & set(dec)`。少了 sorted，直接交回 set：兩個月都有的分類找對了，可是沒有排序，也不是 list。只用 `in`、`not in`、`len` 檢查都會過，要拿整串排好的 list 用兩個等號比：`assert both_months(nov, dec) == ["交通", "餐飲"]`。set 跟 list 用兩個等號比，就算裡面一樣也是 False。
- **壞版本 2**：`return sorted(set(nov) | set(dec))`。交集 & 寫成聯集 |：只要有一個月有，就被放進去。檢查「只有一個月有的分類不在裡面」就抓得到。
- **壞版本 3**：沒有用 set，照 11 月一筆一筆找：同一個分類記了好幾筆，就重複出現好幾次：

```python
def both_months(nov, dec):
    both = []
    for kind in nov:
        if kind in dec:
            both.append(kind)
    return sorted(both)
```

  資料裡要有「同一個分類記了好幾筆」才抓得到：例如 `both_months(["餐飲", "餐飲"], ["餐飲"])` 應該是 `["餐飲"]`，它交回 `["餐飲", "餐飲"]`。

- 小心兩種寫法會讓你以為抓到了：`assert sorted(r) == [...]`（自己先排好，壞版本 1 的 set 也被排好了，抓不到）；`assert r == {"交通", "餐飲"}`（拿 set 比，正確版交回 list，這一條在正確版上就不成立）。
