# 1-1　print、註解、程式一行一行跑

這課大約 40 分鐘。三圈比例 70／20／10。Windows 同學：指令在 Git Bash 照打，⌘ 換成 Ctrl（安裝見 0-W）。

## 1. 題目

**第①圈：自己寫（關掉 AI）。**

A. 先看範例（`example.py`）：每一步上面那行 `#` 是「這一步要做什麼」，下面是怎麼寫。影片裡猜的那一支在 `day.py`，兩支都可以自己跑跑看。

B. 猜輸出（`guess.txt`）：4 題，先不要跑，用眼睛從第一行往下看，猜它會印出什麼，寫 A、B 或 C。

C. 收據抬頭（`receipt.py`）：在每一步的註解下面寫 print，印出這三行：

```
PyPy 熊的帳本
2026/11/14
收據：第 1 張
```

第二行用**一個** print 加 `sep="/"`（年、月、日分開放）；第三行用**兩個** print，第一個加 `end="："`。

**第②圈：判斷 AI 出的題目（`ai_quiz.txt`）。** 白海豹出了 3 題猜輸出（課程準備的範例示意）。先不要答題，先判斷每一題用到的東西這一課學過了沒，寫「學過」或「沒學過」。白海豹會問你：證據是什麼？

想用自己的家教練習（自評，不檢查）：在 0-8 建好的家教專案裡說「我剛學了 print、sep、end 和註解，請出 3 題猜輸出，先不要給答案」。題目裡有還沒學的，就跟它說你學到哪裡、請它換一題。答完自己用 uv run 跑一次對答案。

**第③圈：先寫預期輸出，再驗收 AI 的程式（`expected.txt`）。** 需求卡：

| 欄 | 內容 |
|---|---|
| 目標 | 印出帳本 v0 的收據 |
| 背景 | 帳本 v0 只印三筆花費，沒有抬頭 |
| 限制 | 只用 print，三筆的字不要改 |
| 怎樣算做完 | 先印你在 receipt.py 寫的收據抬頭（三行），**緊接著**印帳本 v0 的三筆花費（0-C 的 main.py 那三筆），中間沒有空行 |

AI 照這張需求卡交出了三個版本（課程準備的，放在 `mutants/`，正確版在 `reference/`）。你**先不要看它們**，照需求卡把收據「應該印出來的樣子」一行一行寫進 `expected.txt`。check 會拿你寫的，跟正確版和三個版本印出來的**一行一行比，連空白的一行也比**：正確版要跟你寫的一模一樣，三個版本各要被你抓到。

## 2. 提示

- 要印的字放在引號裡：`print("午餐")`。引號要成對，少一個就是 SyntaxError，整支程式一行都不會跑。
- print 括號裡用逗號隔開好幾樣東西，印出來中間會空一格。`sep` 換掉中間的那個空格，`end` 換掉最後面的換行（`end=""` 就是什麼都不加，下一個 print 接在同一行）。
- `print()` 括號裡什麼都沒有：印出空白的一行。空白的一行也算一行。
- `#` 開頭的是註解，寫給人看的，Python 不會跑它。
- 程式從第一行開始，一行一行往下跑。
- `expected.txt`：一個字、一個空格都要一樣（全形、半形的冒號都可以）；`#` 開頭的說明行 check 不看。

## 3. 開始前要打的指令

```bash
cd ~/code/plusform-course
git pull
uv run check.py start 1-1
```

它會把起點檔複製到你的帳本 `lessons/1-1/`：`example.py`、`day.py`、`guess.txt`、`receipt.py`、`ai_quiz.txt`、`expected.txt`。

用 VS Code 打開帳本，寫完存檔，在 VS Code 下面的終端機（帳本資料夾）自己跑跑看：

```bash
uv run lessons/1-1/receipt.py
```

檢查的時候**回到課程資料夾**：

```bash
cd ~/code/plusform-course
uv run check.py 1-1
```

（也可以不切資料夾，直接打完整路徑：`uv run ~/code/plusform-course/check.py 1-1`。課號寫 `1-01` 也可以。）

## 5. 怎麼測

`uv run check.py 1-1` 會先問你：「你覺得會過幾題？」先猜一個數字再按 Enter，它才開始檢查。一共 13 題：

- 對答：`guess.txt` 4 題、`ai_quiz.txt` 3 題
- 官方測試：`receipt.py` 印出的三行
- 第三圈：`expected.txt` 寫滿 6 行、跟正確版一模一樣、抓到 3 個壞版本

沒過的，它只先告訴你第一個沒過的，修好再跑一次（想一次看全部，最後加 `--all`）。不到 8 分鐘就全對，它會印出提醒：只是提醒，不扣分。

## 6. 怎麼交

check 全對就算這課過了，它會記在你帳本的 `.check/` 裡，不用上傳。在 VS Code 按一個存檔點（說明寫「1-1 完成」）。

技能樹上這課的葉子，要過兩課以後、改天答對回顧題才會長出來。補充說明（影片裡家教對話的逐字紀錄、Windows 的差異）在 `補充.md`。
