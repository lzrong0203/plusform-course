## 1. 讀一支陌生程式的四小步

1. **先跑一次**：看它會做什麼（old_ledger.py 能 show、add、total）。
2. **從開始跑的地方畫呼叫圖**：不從第 1 行讀起。上面的 import、def、class 只是先把東西記下來，最下面的 `main()` 一呼叫，程式才開始做事。每個函式呼叫了誰，一層一層畫下來。用 VS Code 的移至定義（F12）找名字從哪裡來，尋找所有參考（⇧⌥F12，Windows 是 Shift＋Alt＋F12）找誰用了它。
3. **看不懂的寫法，先猜大意，再跑一次確認**：@、yield、re、logging 這一課都只要看得懂在做什麼。
4. **照旁邊的樣子加功能**：要加 delete，就照 add 的樣子寫（上面一樣寫 @command，刪完一樣呼叫 save）。

old_ledger.py 的呼叫圖（文字版）：

```
main（最下面 if __name__ == "__main__": 呼叫它，從這裡開始讀）
├── load：把帳讀進來
│   └── read_entries：一次交出一筆（yield）
│       └── parse：用 LINE（re）把一行拆成 Entry，看不懂就 raise ValueError
└── COMMANDS[name](entries, arg)：用打進來的名字查出指令
    ├── show：列出每一筆（fmt 排成「編號. 日期 項目 金額」）
    ├── add：parse 拆開 → append → save 整本存回檔案
    ├── total：合計
    └── delete（這一課加的）：pop(no - 1) → save
```

show、add、total 整支程式都沒有人直接寫 `show(...)`：對 show 按「尋找所有參考」只找得到 def 那一行。追 COMMANDS 的參考，會找到 `command` 這個函式；再追 command 的參考，就是寫在三個函式上面的 `@command`。

## 2. @command（decorator，看得懂就好）

寫在 def 上面的 `@名字`，等於在那一段後面多寫一行 `show = command(show)`（官方術語表：merely syntactic sugar）。這支程式的 command 把函式用名字放進 COMMANDS，再原封不動交回去。

```python
import old_ledger as L
print(list(L.COMMANDS))                 # @command 把 show、add、total 用名字放進來
print(L.COMMANDS["total"] is L.total)    # 查出來的就是那個函式


def plain(entries, arg):
    return "plain"


same = L.command(plain)                   # @command 等於 plain = command(plain)
print(same is plain, "plain" in L.COMMANDS)
```

印出（Python 3.13 實際跑）：

```
['show', 'add', 'total']
True
True True
```

1-24 的 `@dataclass` 也是一種 decorator。

## 3. yield（generator，看得懂就好）

有 yield 的函式叫 generator：每次 yield 交出一個值就停在那裡，要下一個時從停下來的地方接着跑（官方術語表：picks up where it left off）。

```python
from old_ledger import read_entries, DATA
entries = read_entries(DATA)
print(entries)                 # 還沒開始讀：一個 generator
print(next(entries).item)      # 要一筆，它才讀一筆
print(next(entries).item)
print(len(list(read_entries(DATA))))   # list(...) 一直要，直到讀完
print(len(entries))            # generator 沒有長度
```

印出（Python 3.13 實際跑）：

```
<generator object read_entries at 0x…>
午餐
公車
3
TypeError: object of type 'generator' has no len()
```

## 4. re（正規表示式，看得懂就好）

`LINE = re.compile(r"(\d+/\d+) (\S+) (\d+)")` 描述一行長什麼樣子：`\d` 是一個數字（十進位的數字，0 到 9 這種）、`+` 是一個以上、`\S` 是不是空白的字；括號圍起來的三段，比完可以用 `group(1)`、`group(2)`、`group(3)` 拿出來（拿到的都是字，金額要 `int` 才變成數字）。`fullmatch` 要整行都對得上，對不上交回 None。

```python
from old_ledger import LINE
for s in ["11/06 咖啡 85", "11/06 咖啡 八十五", "11/06 咖啡", "咖啡 11/06 85"]:
    m = LINE.fullmatch(s)
    print(s, "→", m.groups() if m else None)
```

印出（Python 3.13 實際跑）：

```
11/06 咖啡 85 → ('11/06', '咖啡', '85')
11/06 咖啡 八十五 → None
11/06 咖啡 → None
咖啡 11/06 85 → None
```

## 5. logging（看得懂就好）

像會標等級的 print（印在終端機上）。沒有另外設定時，只印 WARNING 以上的（官方 logging HOWTO：The default level is WARNING）。看到 `WARNING:root:` 開頭的那一行，不是程式當掉，是程式在提醒你。

```python
import logging
logging.warning("看不懂：11/06 咖啡 八十五")   # 印出來（WARNING 以上）
logging.info("讀了 3 筆")                      # 沒有另外設定：不印
print("程式還在跑")
```

印出（Python 3.13 實際跑）：

```
程式還在跑
WARNING:root:看不懂：11/06 咖啡 八十五
```

old_ledger.py 裡有兩個地方用 logging.warning：main 接住你打錯格式的指令（`WARNING:root:看不懂：…`）、read_entries 遇到檔案裡看不懂的那一行（`WARNING:root:第 2 行看不懂，跳過`，跳過再讀下一行）。

## 6. 編號和索引差一、刪除前要先確認

```python
entries = ["午餐", "公車", "晚餐"]
for no, e in enumerate(entries, start=1):   # show 的編號從 1 開始
    print(no, e)
print(entries[2 - 1])          # 第 2 筆是索引 1
print(entries.pop(0 - 1))      # 編號 0：pop(-1) 刪到最後一筆，也不說一聲
```

印出（Python 3.13 實際跑）：

```
1 午餐
2 公車
3 晚餐
公車
晚餐
```

show 的編號從 1 開始，list 的索引從 0 開始，所以要刪 show 印的第 no 筆，是 `entries.pop(no - 1)`。寫成 `pop(no)` 會刪到下一筆；編號打 0 時 `pop(0 - 1)` 是 `pop(-1)`，會默默刪到最後一筆。

**刪除前要先確認**：刪錯了沒辦法反悔。先把要刪的那一筆交回來給人看，確認了才真的刪。AI 交回的 `delete_ai.py` 把編號當成索引，要刪第 2 筆卻交回晚餐：如果直接刪、不先確認，根本不會發現刪錯；先交回給人看，就看得出「這不是我要刪的」。assert 則是讓程式自己抓到這種差一。

## 8. 家教追問的那一題：把 `return func` 拿掉，show 會變成什麼？（作業做完再看）

```python
COMMANDS = {}


def command(func):
    COMMANDS[func.__name__] = func
    # 把 return func 拿掉


@command
def show(entries, arg):
    print("列出每一筆")


print(show)                    # show 這個名字變成 None（command 沒交回東西）
COMMANDS["show"]([], "")       # 可是 COMMANDS 裡還是原本的函式
```

印出（Python 3.13 實際跑）：

```
None
列出每一筆
```

`@command` 等於 `show = command(show)`：等號右邊是 command 交回的東西。拿掉 `return func`，command 什麼都沒交回（None），show 這個名字就變成 None；可是 COMMANDS 裡放的還是原本的函式，所以打 show 指令照樣能跑，直接寫 `show(...)` 才會出錯。這就是為什麼 decorator 最後一定要把函式交回去。
