# 1-16 第②圈：請家教考你「最後 a 是什麼」，每一題先畫圖（自評，check 不檢查）

在家教專案裡打：「我剛學完 list 的參照和複製。請你考我『最後 a 是什麼』：一次一題，每題用三四行的短程式。每一題都要我先用文字畫圖（哪個名字指著哪個盒子），再回答最後 a 是什麼。等我回答再說對不對，先不要給答案。」
**每一題先在紙上畫圖、寫下答案，再貼給家教。** 家教說你哪裡不對，自己在帳本裡跑一次（印出 a、b，或用 is 看是不是同一個），確定它說得對不對。家教說你錯、你跑出來卻是對的，也要記下來（AI 也會看錯）。

| 第幾題 | 家教的程式（短短寫） | 我畫的圖（名字 → 盒子） | 我的答案 | 家教怎麼說？ | 我自己跑出來是什麼 |
|---|---|---|---|---|---|
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |

自評（打勾）：

- [ ] 每一題都是我先畫圖、寫下答案，才貼給家教
- [ ] 家教說我不對的地方，我自己跑過一次，確定它說得對不對
- [ ] 我分得出「改盒子裡面」（append、b[0] = 0）和「把名字換到別的盒子」（等號）
- [ ] 我說得出 copy() 和 [:] 只複製最外面一層（list 裡面又放 list，裡面那一層還是共用的）
