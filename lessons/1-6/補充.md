## 2. Python 官方文件的原文

Python 3.13 官方文件（2026-11-15 查的）。

**input()**（https://docs.python.org/3.13/library/functions.html#input）

```
input()¶
input(prompt, /)
If the prompt argument is present, it is written to standard output without
a trailing newline.  The function then reads a line from input, converts it
to a string (stripping a trailing newline), and returns that.  When EOF is
read, EOFError is raised.  Example:
>>> s = input('--> ')
--> Monty Python's Flying Circus
>>> s
"Monty Python's Flying Circus"
If the readline module was loaded, then input() will use it
to provide elaborate line editing and history features.
Raises an auditing event builtins.input with
argument prompt before reading input
Raises an auditing event builtins.input/result
with the result after successfully reading input.
```

重點：提示的字「without a trailing newline」（後面不換行），讀進來的「converts it to a string」（一定是字串）。

**int()** 收字串的規定（同一頁 #int）

```
If the argument is not a number or if base is given, then it must be a string,
bytes, or bytearray instance representing an integer
in radix base.  Optionally, the string can be preceded by + or -
(with no space in between), have leading zeros, be surrounded by whitespace,
and have single underscores interspersed between digits.
```

「be surrounded by whitespace」：前後可以有空白，所以 `int(" 85 ")` 是 85。逗號、小數點、「元」都不在規定裡，會出 ValueError。

**float()**（同一頁 #float）

```
If the argument is a string, it should contain a decimal number, optionally
preceded by a sign, and optionally embedded in whitespace.
```

**len()**（同一頁 #len）

```
len(object, /)¶
Return the length (the number of items) of an object.  The argument may be a
sequence (such as a string, bytes, tuple, list, or range) or a collection
(such as a dictionary, set, or frozen set).
```

**ValueError**（https://docs.python.org/3.13/library/exceptions.html#ValueError）

```
Raised when an operation or function receives an argument that has the
right type but an inappropriate value, and the situation is not described by a
more precise exception such as IndexError.
```

型別對（int 願意收字串），值不對（'1,200' 不是長得像整數的字串）。

**術語表**（繁體中文版 https://docs.python.org/zh-tw/3.13/glossary.html）：argument 譯作「引數」（呼叫函式時被傳遞給 function 的值）、function 譯作「函式」（一連串的陳述式，它能夠向呼叫者回傳一些值）；這門課照這個譯法，交回來的值叫「回傳值」。

## 4. 從檔案餵輸入：`uv run add.py < inputs.txt`

`<` 叫重新導向：程式要輸入的時候，不從鍵盤讀，改從檔案一行一行讀（GNU Bash 手冊 3.6.1 Redirecting Input，https://www.gnu.org/software/bash/manual/html_node/Redirections.html）。

畫面為什麼跟手打不一樣：

- input 印提示的字，後面不換行。手打的時候，是你按的 Enter 換了行；從檔案讀，沒有人按 Enter，所以提示的字會一個接一個黏在下一行印的字前面。
- 檔案裡的字是直接交給程式的，終端機不會把它印出來（手打的時候看得到，是終端機把你按的鍵顯示出來）。

```
$ cd lessons/1-6
$ uv run add.py < inputs.txt
品項：金額：記下來了：午餐 1200元
這週還剩 1800 元
```

影片裡跑的是熊自己的 add.py（第①、②圈寫的那支）。check 驗收的是 AI 寫的版本，它多印一行「這週的餐費預算 3000 元」（需求卡的限制）。

- **macOS 終端機（zsh）、Windows 的 Git Bash**：`<` 可以用（Git Bash 就是 bash）。
- **Windows 的 PowerShell**：不能用。PowerShell 的重新導向只有輸出（`>`、`>>`），打 `<` 會出現「The '<' operator is reserved for future use.」（Microsoft Learn：about_Redirection）。這門課一律用 Git Bash（0-W）。
- **check.py 不靠 `<`**：它用 Python 的 subprocess 把 inputs.txt 的字直接餵給每一個版本，所以在 PowerShell 打 `uv run check.py 1-6` 也一樣能驗收。

## 5. inputs.txt 和 expected.txt 的小規則

- inputs.txt 的每一行都會被當成你打的字（連 `#` 開頭的行也是），所以**不能寫說明**；說明寫在 expected.txt 的 `#` 那幾行。
- 行數不夠（程式問兩次、檔案只有一行），程式讀到檔案最後就會當掉（EOFError），check 會告訴你。
- 行數多了沒關係，程式只讀它要的那幾行。
- 品項前後的空白：在「午餐」前面打一個空白就夠了（行尾的空白看不到，有的編輯器存檔時會拿掉）。
- 預期輸出不用寫提示的字（品項：、金額：），check 會先拿掉；你照終端機看到的連提示一起寫，也算對。

## 6. Windows 換行（CRLF）的小坑

Windows 的記事本存出來的檔案，每一行最後是 `\r\n`。**本次在 macOS 沙盒實測**：把這樣的檔案餵給程式，input 只拿掉最後的 `\n`，`\r` 會留在字串裡（`' 午餐 \r'`）。在 Windows 上用 Python 讀標準輸入，換行的處理跟 macOS 不一定一樣（平台差異），這門課沒有逐一實測。不管哪一種，`strip()` 和 `int()` 都會把 `\r` 當成空白拿掉，所以記帳程式不受影響；check.py 讀 inputs.txt 時也會先把 `\r\n` 換成 `\n`。VS Code 右下角可以把 CRLF 改成 LF（0-W）。
