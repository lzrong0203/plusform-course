這課大約 40 分鐘。三圈比例 70／20／10。Windows 同學：指令在 Git Bash 照打，⌘ 換成 Ctrl（安裝見 0-W）；第③圈的 `<` 只能在 Git Bash 用，PowerShell 不行（見第 2 節）。
要會的：`print`、變數、資料型別（1-3）、`//` 和 `%`（1-4）、字串的 `strip()`、`replace()`、f-string（1-5）。

## 1. 題目

**第①圈：自己寫（關掉 AI）。**

A. 先猜輸出（`guess.txt`）：8 題，`len()`、`int()`、`float()`、`input()` 交回什麼。先不要跑，在「答：」後面寫印出來的樣子，選擇題寫 A、B 或 C。

B. 分帳機（`bill.py`）：用 `input()` 問總金額和幾個人，印出每人付多少、零頭多少（1-4 的 `//` 和 `%`）。把三個 `？` 換掉，存檔再跑。總金額有人會打 `1,450`（千分位逗號），也要收得下。

**第②圈：判斷家教的解釋。**

A. `ai_ask.txt`（對答 3 題）：影片裡熊的記帳程式打 1,200 當掉，熊只問家教「ValueError 是什麼意思」，判斷它的解釋。

B. `my_ask.md`（自評）：拿你自己的錯誤訊息，只問家教「是什麼意思」，自己修。影片裡熊跟家教的完整對話在 `補充.md`。

**第③圈：替 AI 寫的記帳程式準備輸入和預期輸出（`inputs.txt`、`expected.txt`）。** 需求卡：

| 欄 | 內容 |
|---|---|
| 目標 | 記一筆帳，算出這週的餐費還剩多少（預算 3000 元） |
| 背景 | 品項前後常多打空白；金額有人打千分位逗號，像 1,200 |
| 限制 | 先印「這週的餐費預算 3000 元」，再問品項、金額；品項前後的空白不算；金額變成整數 |
| 怎樣算做完 | 你的 inputs.txt 餵給正確版，印出來的跟你的預期輸出一模一樣；三個壞版本，各被你抓到 |

AI 照這張需求卡寫了記帳程式（課程凍結的版本：正確版在 `reference/`，三個壞版本在 `mutants/`）。你**不用看懂它的程式**，也先不要看，只準備兩個檔：

- `inputs.txt`：程式會問兩次（品項、金額），照它問的順序，一行寫一個你要打的字。每一行都會被當成你打的字，**不能寫說明**。
- `expected.txt`：這些字餵進去以後，它應該印出來的樣子（三行）。提示字（`品項：`、`金額：`）不用寫，check 會先拿掉。

`uv run check.py 1-6` 會自己把你的 `inputs.txt` 餵給正確版和三個壞版本（用 Python 的 subprocess，不靠 `<`），印出來的一行一行跟你的預期輸出比。三個壞版本都要抓到：需求卡「背景」那一欄的情況，要放進你的 `inputs.txt`。

## 2. 提示

- 函式是別人寫好的一段程式。寫名字加括號就是**呼叫**它；括號裡放的東西叫**引數**；它算完交回來的值叫**回傳值**。`len("午餐")` 交回 2。
- 回傳值可以直接放進另一個函式的括號：`print(len("午餐"))` 先算裡面的 `len`，再交給 `print`。
- `input("品項：")` 先印出提示字，停下來等你打字，按 Enter 以後把你打的字交回來：**一定是字串**。要拿去算，先用 `int()` 變成整數（型別轉換）。
- `int()` 收的字串要長得像整數：前後的空白它會自己拿掉（`int(" 85 ")` 是 85），可是有逗號、小數點、「元」都會當掉（ValueError）。小數用 `float()`。
- 字串的方法可以直接接在 `input()` 後面：`input("品項：").strip()`、`input("金額：").replace(",", "")`。
- 從檔案餵輸入：`uv run lessons/1-6/add.py < lessons/1-6/inputs.txt`。`<` 叫**重新導向**：程式要輸入的時候，從檔案一行一行讀。這時提示字後面不換行、檔案裡的字也不會出現在畫面上，所以提示字會一個接一個黏在結果前面，這是正常的。
- Windows：`<` 在 Git Bash 可以用；PowerShell 不行（它會說 The '<' operator is reserved for future use.）。check.py 不靠 `<`，PowerShell 也跑得動。

## 5. 怎麼測

`uv run check.py 1-6` 會先問你：「你覺得會過幾題？」先猜一個數字再按 Enter，它才開始檢查。一共 19 題：

- 第一圈：`guess.txt` 8 題、`bill.py` 3 題（check 自己餵三組總金額和人數：1450 和 4、1000 和 3、1,450 和 4）
- 第二圈：`ai_ask.txt` 3 題
- 第三圈：預期輸出至少寫 3 行、正確版跑起來一模一樣、抓到 3 個壞版本

沒過的，它只先告訴你第一個沒過的，修好再跑一次（想一次看全部，最後加 `--all`）。不到 8 分鐘就全對，它會印出提醒：只是提醒，不扣分。`my_ask.md` 是自評，check 不檢查。

## 6. 怎麼交

check 全對就算這課過了，它會記在你帳本的 `.check/` 裡，不用上傳。在 VS Code 按一個存檔點（說明寫「1-6 完成」）。
