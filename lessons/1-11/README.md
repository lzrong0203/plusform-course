## 1. 題目

**第①圈：自己寫（關掉 AI）。**

A. range 和迴圈跑幾次（`range.txt`）：先不要跑，用眼睛追 4 題。

B. 一週七天的花費（`week.py`）。方括號 `[120, 85, 200, 95, 150, 60, 180]` 先當成「一串數字」（1-13 再細講），用 `for` 一個一個拿出來，算出三件事：

**第②圈：請家教出追蹤題（`tutor.md`、`trace_quiz.txt`）。** 在家教專案裡請它出三題「這個迴圈印幾行」，只用 for、range 和兩層迴圈，**先不要給答案**。在紙上追完再把答案貼給它；答錯的那一題，照它問你的問題一輪一輪列出來，自己確定它說得對不對。記在 `tutor.md`（自評，不擋過關）。`trace_quiz.txt` 有三題同樣的題型。

**第③圈：先寫下應該是多少，再驗收 AI 寫的預算表（`facts.txt`）。** 需求卡：

| 欄 | 內容 |

## 2. 提示

- `for 名字 in 一串東西:` 的意思是：從那一串裡一個一個拿出來，放進那個名字，每拿一個就做一次下面縮排的那幾行；拿完了，迴圈就結束。不用像 while 那樣自己寫「加 1」。
- `range(開始, 結束, 每次加多少)`：從開始那個數算起，到結束那個數**之前**就停，**結束那個數不算**。只寫一個數字 `range(5)` 是從 0 開始（0、1、2、3、4）；不寫每次加多少，就是每次加 1。`range(1, 10, 3)` 是 1、4、7。
- 累加：`total = 0` 放在**迴圈外面**，只做一次；迴圈裡每一圈 `total = total + cost`。`total = 0` 寫進迴圈裡，每一圈都會被歸零，最後只剩最後一個數（影片裡果凍兔的錯）。
- 計數：`count = 0` 放在迴圈外面，迴圈裡 `if cost > 150:` 才 `count = count + 1`。
- 找最大值：`biggest = 0`（花費都是正的），迴圈裡 `if cost > biggest:` 就 `biggest = cost`。Python 也有現成的 `max`，這一課先自己寫，看懂它怎麼找。
- `enumerate(week, start=1)` 每一圈給你兩個東西：編號和那一個數，所以 for 後面寫兩個名字，中間用逗號隔開：`for day, cost in enumerate(week, start=1):`。不寫 `start=1`，編號會從 0 開始。
- 兩層迴圈：外層跑一次，內層就跑完一整圈；**內層跑完一整圈，外層才往下一個**。內層每一輪跑的次數都一樣，印幾行才能用「外層次數乘內層次數」算；內層跟著外層的數字變（例如 `range(i)`），就要一輪一輪加起來。
- 一列印完才換行：同一列用 `print(…, end=" ")`，一天印完再 `print()`。`print()` 要跟內層的 `for` 對齊，縮進內層就變成每一格各換一次行。
- 歸零放在哪一層，決定從哪裡開始重新算：要整週一直累計，`total = 0` 放在最外面；放進外層迴圈裡，就變成每天重新從 0 算。
- 第③圈：先照需求卡算出應該是多少，**再**跑程式比。只數列數，抓不到「列數對、數字錯」的版本。

## 5. 怎麼測

`uv run check.py 1-11` 會先問你：「你覺得會過幾題？」先猜一個數字再按 Enter，它才開始檢查。一共 18 題：

- 第一圈：`range.txt` 4 題、`week.py` 2 題（原本的 week 跑一次；check 把 week 換成別的七個數字再跑一次）、`number.py` 1 題、`table.py` 1 題、`parsons.py` 2 題（五行都用上、Python 讀得懂；跑出來是第 1 餐到第 9 餐）
- 第二圈：`trace_quiz.txt` 3 題
- 第三圈：至少寫 1 件事、你寫的在正確版上都對、抓到 3 個壞版本

沒過的，它只先告訴你第一個沒過的，修好再跑一次（想一次看全部，最後加 `--all`）。不到 10 分鐘就全對，它會印出提醒：只是提醒，不扣分。`tutor.md` 是自評，check 不檢查。

### 常見錯誤

| 你看到 | 意思 | 怎麼辦 |
|---|---|---|
| week.py 第一題過了、第二題沒過 | 把答案直接寫進 print 了 | 三件事都用 for 一個一個算 |
| 一週一共只有 180 元 | `total = 0` 寫進迴圈裡，每一圈都歸零 | 把 `total = 0` 搬到 for 的上面 |
| number.py 從第 0 天開始 | enumerate 沒寫 `start=1` | `enumerate(week, start=1)` |
| 預算表每個數字各佔一列 | `print()` 縮進了內層迴圈 | 讓 `print()` 跟內層的 `for` 對齊 |
| `IndentationError: expected an indented block` | 冒號那一行的下一行沒有往右縮 | for 那一行最後有冒號，下一行往右縮四格 |
| 拼圖說「不是拼圖裡的行」 | 改到字、多寫或刪了一行 | 只搬動和縮排，題目的五行都要用上 |
| `error: Failed to spawn: check.py` | 你不在課程資料夾裡 | 先打 `cd ~/code/plusform-course` |
