**官方教學 4.2 for 陳述式**（https://docs.python.org/zh-tw/3.13/tutorial/controlflow.html）

```
4.2. for 陳述式¶

在 Python 中的 for 陳述式有點不同於在 C 或 Pascal 中的慣用方式。相較於只能疊代 (iterate) 一個等差數列（如 Pascal），或給予使用者定義疊代步驟與終止條件（如 C），Python 的 for 陳述式疊代任何序列（list 或者字串）的元素，順序與它們出現在序列中的順序相同。例如（無意雙關）：

>>> # 測量一些字串：
>>> words = ['cat', 'window', 'defenestrate']
>>> for w in words:
...     print(w, len(w))
...
cat 3
window 6
defenestrate 12
```

**官方教學 4.3 range() 函式**

```
4.3. range() 函式¶

如果你需要疊代一個數列的話，使用內建 range() 函式就很方便。它可以生成一等差數列：

>>> for i in range(5):
...     print(i)
...
0
1
2
3
4

給定的結束值永遠不會出現在生成的序列中；range(10) 生成的 10 個數值，即對應存取一個長度為 10 的序列內每一個項目的索引值。也可以讓 range 從其他數值開始計數，或者給定不同的公差（甚至為負；有時稱之為 step）：

>>> list(range(5, 10))
[5, 6, 7, 8, 9]

>>> list(range(0, 10, 3))
[0, 3, 6, 9]

>>> list(range(-10, -100, -30))
[-10, -40, -70]
```

**官方教學 5.6 迴圈技巧**（enumerate，https://docs.python.org/zh-tw/3.13/tutorial/datastructures.html）

```
5.6. 迴圈技巧¶

當對 dictionary 作迴圈時，鍵以及其對應的值可以藉由使用 items() method 來同時取得：

>>> knights = {'gallahad': 'the pure', 'robin': 'the brave'}
>>> for k, v in knights.items():
...     print(k, v)
...
gallahad the pure
robin the brave

當對序列作迴圈時，位置索引及其對應的值可以藉由使用 enumerate() 函式來同時取得：

>>> for i, v in enumerate(['tic', 'tac', 'toe']):
...     print(i, v)
...
0 tic
1 tac
2 toe
```

**enumerate(iterable, start=0)**（https://docs.python.org/3.13/library/functions.html#enumerate）

```
Return an enumerate object. iterable must be a sequence, an
iterator, or some other object which supports iteration.
The __next__() method of the iterator returned by
enumerate() returns a tuple containing a count (from start which
defaults to 0) and the values obtained from iterating over iterable.

>>> seasons = ['Spring', 'Summer', 'Fall', 'Winter']
>>> list(enumerate(seasons))
[(0, 'Spring'), (1, 'Summer'), (2, 'Fall'), (3, 'Winter')]
>>> list(enumerate(seasons, start=1))
[(1, 'Spring'), (2, 'Summer'), (3, 'Fall'), (4, 'Winter')]
```

**Ranges**（https://docs.python.org/3.13/library/stdtypes.html#ranges）

```
The arguments to the range constructor must be integers (either built-in
int or any object that implements the __index__() special
method).  If the step argument is omitted, it defaults to 1.
If the start argument is omitted, it defaults to 0.
If step is zero, ValueError is raised.

For a positive step, the contents of a range r are determined by the
formula r[i] = start + step*i where i >= 0 and
r[i] < stop.

For a negative step, the contents of the range are still determined by
the formula r[i] = start + step*i, but the constraints are i >= 0
and r[i] > stop.
```

## 3. range 的三個數字

`range(開始, 結束, 每次加多少)`：從開始那個數算起，到結束那個數**之前**就停，結束那個數不算。下面都是 Python 3.13.18 實際跑出來的：

```
>>> list(range(5))
[0, 1, 2, 3, 4]
>>> list(range(1, 8))
[1, 2, 3, 4, 5, 6, 7]
>>> list(range(1, 10, 3))
[1, 4, 7]
>>> list(range(10, 0, -3))
[10, 7, 4, 1]
>>> list(range(3, 3))
[]
```

- 只寫一個數字：從 0 開始。`range(5)` 剛好跑 5 次，所以「做 N 次」常寫成 `for i in range(N):`。
- 每次加多少也可以是負的，就是倒著數（`range(10, 0, -3)`）。開始和結束一樣，一次都不跑。
- 這裡的 `list(...)` 只是為了把 range 的數字一次印出來看，list 在 1-13 才細講。

## 4. enumerate：編號從 0 還是 1

```
>>> week = [120, 85, 200, 95, 150, 60, 180]
>>> for day, cost in enumerate(week):
...     print(day, cost)
0 120
1 85
...
>>> for day, cost in enumerate(week, start=1):
...     print(day, cost)
1 120
2 85
...
```

enumerate 每一圈給兩個東西：編號和那一個值，所以 for 後面寫兩個名字，中間用逗號隔開。不寫 `start`，編號從 0 開始；記帳要從第 1 天開始數，就寫 `start=1`。

## 5. for 跟 while

1-10 的 while 和這一課的 for，可以寫出一模一樣的結果：

```
day = 1                         for day in range(1, 8):
while day <= 7:                     print("第", day, "天記帳")
    print("第", day, "天記帳")
    day = day + 1
```

while 要自己寫三件事：起點（`day = 1`）、什麼時候停（`day <= 7`）、每一圈怎麼往下（`day = day + 1`），少了最後一件就停不下來（1-10 的無窮迴圈）。for 從一串東西裡一個一個拿，拿完就停，三件事都由 range 包好了。
什麼時候用哪一個：知道要跑幾次、或要把一串東西一個一個拿出來，用 for；不知道要跑幾次、要等某件事發生才停（例如打 q），用 while（1-10）。

## 6. 累加、計數、找最大值

- 累加：`total = 0` 放在迴圈**外面**，只做一次；迴圈裡 `total = total + cost`。影片裡果凍兔把 `total = 0` 放進迴圈，每一圈都被歸零，最後只剩最後一天的 180。
- 計數：`count = 0` 放在外面，迴圈裡 `if cost > 150:` 才加 1。剛好 150 不算超過（跟 1-8、1-9 一樣，「超過」是大於）。
- 找最大值：`biggest = 0`，迴圈裡比它大就換掉。這個寫法要所有數字都大於 0 才對；如果數字可能是負的，起點要換成第一個數字（1-13 學 list 以後會寫）。
- Python 有現成的 `max(week)`，直接交回最大的那個（官方說明：Return the largest item in an iterable or the largest of two or more arguments.）。這一課先自己寫，是為了看懂它怎麼一個一個比；以後看到 AI 寫 `max(...)`，你知道它在做什麼。

## 7. 兩層迴圈：印幾行怎麼算

- 外層跑一次，內層就跑完一整圈；內層跑完一整圈，外層才往下一個。
- 內層每一輪跑的次數都一樣（例如 `range(4)`），印幾行就是「外層次數乘內層次數」。
- 內層跟著外層的數字變（例如 `range(i)`），每一輪次數不一樣，要一輪一輪寫下來再加起來（影片裡家教的第 3 題：1 + 2 + 3 = 6）。
- 一列印完才換行：同一列用 `print(…, end=" ")`，一列印完再 `print()`。`print()` 要跟內層的 `for` 對齊；縮進內層，就變成每一格各換一次行。
- 歸零放在哪一層，決定從哪裡開始重新算：要整週一直累計，`total = 0` 放在最外面；放進外層迴圈裡，就變成每天重新從 0 算（第③圈的壞版本 2）。要「每天小計」的時候，放在外層裡面才是對的，所以要先看需求。

## 8. 拼圖（parsons.py）怎麼做

`parsons.py` 裡有五行程式，順序被打亂了、縮排也被拿掉了。你只能上下搬動、往右縮排（每一層四個空格），不能改字、不能刪、不能多寫。排好存檔，在帳本資料夾打 `uv run lessons/1-11/parsons.py`，要印出第 1 餐到第 9 餐。

check 分兩題判：第一題看五行都用上、沒有改字（多打或少打空格不算改字）、縮排是四的倍數，而且 Python 讀得懂（沒有 IndentationError）；第二題把你排好的程式真的跑一次，跟範例一模一樣才算過，所以排法不只一種也沒關係。卡住的時候先想：哪一行只要做一次？哪一行要每一餐都做？

這種把打亂的程式行排回去的題目叫 Parsons 題（Parsons problem），1-12 的關卡也會出現。
