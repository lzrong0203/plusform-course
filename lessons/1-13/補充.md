```
3.1.3. List（串列）¶

Python 理解數種複合型資料型別，用來組合不同的數值。當中最多樣變化的型別為 list，可以寫成一系列以逗號分隔的數值（稱之元素，即 item），包含在方括號之中。List 可以包合不同型別的元素，但通常這些元素會有相同的型別：

>>> squares = [1, 4, 9, 16, 25]

[1, 4, 9, 16, 25]

>>> squares[0]  # 索引回傳項目
1
>>> squares[-1]
25
>>> squares[-3:]  # 切片回傳新串列
[9, 16, 25]
```

**官方教學 5.1 進一步了解 List（串列）**（https://docs.python.org/zh-tw/3.13/tutorial/datastructures.html#more-on-lists，只節錄這一課用到的方法）

```
5.1. 進一步了解 List（串列）¶

The list data type has some more methods. Here are all of the methods of list objects:

list.append(value, /)

將一個新的項目加到 list 的尾端。與 a[len(a):] = [x] 類似。

list.extend(iterable, /)

將 iterable（可疊代物件）接到 list 的尾端。與 a[len(a):] = iterable 類似。

list.insert(index, value, /)

將一個項目插入至 list 中給定的位置。第一個引數為插入處前元素的索引值，所以 a.insert(0, x) 會插入在 list 首位，而 a.insert(len(a), x) 則相當於 a.append(x)。

list.remove(value, /)

Remove the first item from the list whose value is equal to value. It raises a ValueError if there is no such item.

list.pop(index=-1, /)

移除 list 中給定位置的項目，並回傳它。如果沒有指定位置， a.pop() 將會移除 list 中最後的項目並回傳它。若 list 是空的或是索引值超出範圍，則會引發 IndexError 例外。
```

```
基礎排序¶

單純的升冪排序很容易做到：只要呼叫 sorted() 函式，它會回傳一個新的串列：

你也可以使用 list.sort() 方法，它會原地排序串列（並回傳 None 以避免混淆）。它通常會比 sorted() 來得不方便——但如果你不需要保留原始串列的話，它會稍微有效率一點。
```

## 3. 索引和切片

下面都是 Python 3.13.18 實際跑出來的：

```
>>> amounts = [120, 85, 200, 95]

>>> amounts[0]
120

>>> amounts[-1]
95

>>> amounts[-2]
200

>>> len(amounts)
4

>>> amounts[4]
IndexError: list index out of range

>>> amounts[1:3]
[85, 200]

>>> amounts[:2]
[120, 85]

>>> amounts[2:]
[200, 95]

>>> amounts[-2:]
[200, 95]

>>> amounts[2:100]
[200, 95]
```

- 索引從 0 開始：四筆的索引是 0、1、2、3。寫 `amounts[4]` 就超出範圍（IndexError）。最後一筆不用先算有幾筆，寫 `amounts[-1]`。
- 切片 `[開始:結束]` 跟 range 一樣，結束那一格不算；前面空著是從頭、後面空著是到最後。切出來的是一串新的，原本的 list 不會變。
- 切片超出範圍不會出錯：`amounts[2:100]` 一樣拿到 `[200, 95]`（官方文件：j 比長度大，就當成長度）。

## 4. 改 list 的四個方法，會遇到的狀況

```
>>> amounts.append(150)
... print(amounts)
[120, 85, 200, 95, 150]

>>> amounts.insert(1, 60)
... print(amounts)
[120, 60, 85, 200, 95, 150]

>>> amounts.remove(85)
... print(amounts)
[120, 60, 200, 95, 150]

>>> x = [1, 2, 3]
... x.insert(10, 99)
... print(x)
[1, 2, 3, 99]

>>> x = [1, 2, 3]
... x.insert(-1, 99)
... print(x)
[1, 2, 99, 3]

>>> y = [85, 120, 85]
... y.remove(85)
... print(y)
[120, 85]

>>> amounts.remove(999)
ValueError: list.remove(x): x not in list

>>> last = amounts.pop()
... print(last)
... print(amounts)
150
[120, 60, 200, 95]

>>> first = amounts.pop(0)
... print(first)
... print(amounts)
120
[60, 200, 95]

>>> [].pop()
IndexError: pop from empty list
```

- `append(x)`：加在最後面。
- `insert(i, x)`：插在索引 i，原本在 i 和後面的每一筆都往後挪一格。i 比長度還大，就加在最後面（上面 `x.insert(10, 99)`）；i 是負的，從後面數（`insert(-1, 99)` 插在最後一筆的前面）。
- `remove(x)`：刪掉**第一個**等於 x 的那一筆（上面兩個 85 只刪掉前面那個）；找不到會出現 ValueError。括號裡寫的是值，不是索引。
- `pop()`：拿走最後一筆、**還會交回它**；`pop(0)` 拿走第一筆。list 是空的時候 pop 會出現 IndexError。
- 改過以後，後面的索引都會跟著變：插一筆，後面每一筆的索引都加 1（作業 index.txt 第 4 題）。

## 5. sort() 和 sorted()

```
>>> a = [3, 1, 2]
... b = sorted(a)
... print(a)
... print(b)
[3, 1, 2]
[1, 2, 3]

>>> print(sorted([3, 1, 2], reverse=True))
[3, 2, 1]
```

（上面第一段是 `sorted(a)`：a 不動、b 是排好的。下面這幾段是 `a.sort()` 和 `b = a.sort()`。）

```
>>> a = [3, 1, 2]
... b = a.sort()
... print(b)
... print(a)
None
[1, 2, 3]

>>> a = [3, 1, 2]
... sorted(a)
... print(a)
[3, 1, 2]
```

- `sorted(a)` 交回一串新的、排好的 list，a 不動。只寫 `sorted(a)` 不放進名字，排好的那一串就不見了，a 還是原本的。
- `a.sort()` 直接把 a 本身排好，交回 `None`（什麼都沒有）。所以 `b = a.sort()` 的 b 是 None；`nums = nums.sort()` 更糟，排好的 a 也被 None 蓋掉了（影片裡家教的第 3 題）。
- `append`、`insert`、`remove` 也一樣只改 list、交回 None（官方文件：「這是一個用於 Python 中所有可變資料結構的設計法則」）。
- 要由大到小，加 `reverse=True`（`sorted` 和 `sort` 都可以）。不確定拿到什麼，就先印出來看。

## 6. 第③圈：三個壞版本錯在哪

需求卡：`remove_last(amounts)` 刪掉最後一筆、交回被刪掉的那一筆；`index_of_max(amounts)` 交回最大的那一筆在第幾個位置（索引，從 0 數），一樣大的交回前面那一筆；**查最大的時候，不能動到原本的順序**。課程準備的三個壞版本（示意）：

- 壞版本 1：index_of_max 找對了位置，最後多了一行 amounts.sort()：傳進來的 list 被排好，原本的順序不見了。只看交回的答案抓不到；要先把 list 放進一個名字，查完再比它還是不是原本的順序（`assert b == [120, 300, 85]`），或查完再刪最後一筆（會刪到最大的那一筆）。
- 壞版本 2：remove_last 寫成 amounts.pop(0)：刪掉的是第一筆。看交回的是不是最後一筆、剩下的對不對，就抓得到。
- 壞版本 3：index_of_max 的大於寫成大於等於：一樣大的交回最後面那一筆。要測「一樣大的有兩筆」才抓得到（跟 1-8 的「剛好等於」一樣，是邊界）。

壞版本 1 的 `index_of_max`（`def` 到 1-18 才教，這裡只看倒數第二行）：

```python
def index_of_max(amounts):
    where = 0
    for i, cost in enumerate(amounts):
        if cost > amounts[where]:
            where = i
    amounts.sort()
    return where
```

影片裡熊的第一版只檢查了交回的答案，壞版本 1 溜過去；加上「查完以後 b 還是原本的順序」那一條，三個都抓到。交回的答案對，還要檢查它有沒有動到原本的東西。

check 跑 assert 的方法：每個版本各開一個程序跑你的 checks_list.py，只算最外層的 assert，正確版上要全部成立、每個壞版本至少一條不成立。assert 兩邊各算一次（`remove_last(a)` 不會因為要報「正確版交回什麼」被多呼叫一次）。
