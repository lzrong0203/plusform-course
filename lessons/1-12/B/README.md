## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-12B` 會問你），交卷時再問一次。一共 20 題，第一次交卷過 16 題以上算過：

- `trace.txt`（讀程式，9 題）：五段程式，前四段預測輸出，第五段讀一個錯誤訊息（哪一種錯、第幾行、怎麼改）。
- `parsons.py`（讀程式，2 題）：拼圖，八行排回去、自己縮排。
- `fix.py`（讀程式，3 題）：修好一支記飲料的程式；修好一個以後，可能又跳出另一種錯誤訊息；中間多按一下 Enter 也要對。
- `ledger.py`（從零寫，6 題）：帳本 v0.1，規格跟卷 A 一樣，只是分類換成「飲食」「娛樂」和其他。

## 2. 提示

跟卷 A 一樣：`continue` 跳過這一圈下面的那幾行、`break` 結束整個迴圈；`print` 縮在哪一層就屬於哪一層；`if`／`elif` 沒有 `else`，都不成立就什麼都不做；切片拿到的是字串；錯誤訊息從最下面一行看起，引號裡是程式實際拿到的值；count 加 1 放在 `break`、`continue` 的下面；燈號剛好 100% 是黃燈；分帳用 `//` 和 `%`。卡住了回矯正包寫的那幾段影片，不問 AI。
