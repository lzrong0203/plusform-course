# 1-12　Lv1 上關卡：帳本 v0.1

這一關確認 Lv1 上（1-1～1-11）你不靠 AI 也會，過了就升級。一共三部分：

| 部分 | 做什麼 | 怎麼判 |
|---|---|---|
| 第一部分　考卷 | **關掉 AI**，參考 45 分鐘：讀程式 14 題（預測輸出、讀錯誤訊息、拼圖、修好一支程式），從零寫帳本 v0.1（6 題） | 自動判分，第一次交卷過 16 題以上（20 題的八成）算過 |
| 第二部分　家教問三題 | 把通過檢查的 v0.1 交給 0-8 的家教，請它只問你三個問題，把回答寫下來 | 自評：寫了就算交了，內容不改對錯 |
| 第三部分　分帳的 assert | 替課程的分帳 `share()` 寫 assert，抓到課程藏的 3 個壞版本 | 自動判分，3 個都抓到算過 |

**升級條件：第一部分過了、第二部分交了、第三部分過了，練習天數滿 7 天。** 練習天數跟 0-C 的「滿 3 天」同一個算法：跑過課號檢查、或答過回顧題的不同日子（同一天做再多也只算一天）。Windows 同學：指令在 Git Bash 照打，⌘ 換成 Ctrl。

考卷的比例（讀程式 70%、從零寫 30%）、預測分數、自評的出處，卡住時回哪一課看，寫在 [補充.md](補充.md)。

## 1. 題目

**開始前先寫下預測分數。** `uv run check.py start 1-12` 會問你：考卷一共 20 題，你覺得會過幾題。交卷時它會再問一次（考前預測、考後估分）。

**第一部分：考卷（全程關掉 AI）。** VS Code 的 AI 功能 0-6 已經關了；聊天的 AI 和 0-8 設好的家教，考卷這一段也先不開。卡住了不問 AI，不會的題目寫你覺得最可能的答案。參考 45 分鐘，check 會照檔案時間記下你花了多久，**只記錄、不擋你**。作答檔四個，都在帳本的 `lessons/1-12/`：

- `trace.txt`（讀程式，9 題）：五段程式，先不要跑，用眼睛從第一行往下追，在「答：」後面寫答案。前四段預測輸出（while、for 和兩層迴圈、enumerate 和 if、切片和 f-string），第五段讀一個錯誤訊息：哪一種錯、第幾行、怎麼改。
- `parsons.py`（讀程式，2 題）：拼圖。八行程式被打亂、也沒有縮排，排回去、自己縮排，跑出來要跟題目寫的一樣。只能搬動和縮排，不能改字、多寫、少寫。
- `fix.py`（讀程式，3 題）：一支壞掉的記帳程式。先跑，跳出錯誤訊息就從最下面一行看起，修好一個再跑一次；修好一個以後，可能又跳出另一種錯誤訊息。跑得起來以後，再照註解試一次「中間多按一下 Enter」。
- `ledger.py`（從零寫，6 題）：帳本 v0.1。照註解的規格從零寫一支 30 行左右的記帳程式：先問預算，一直問分類和金額、打 q 就停，印出三個分類的小計和合計、預算燈號（1-9 的規則），最後問幾個人分、印出每人付多少和零頭（1-4）。

**第二部分：家教問三題（交卷以後才做）。** 第一部分交卷以後，`tutor.md` 才會放進帳本。先把 `ledger.py` 改到 check 全過（交卷以後再打是訂正），再打開 0-8 建好的家教專案「PyPy 熊的程式家教」，新開一個對話，把 `ledger.py` 整份貼上，接着打：

```
這是我關掉 AI 自己寫的帳本 v0.1。請你只問我三個問題，一次問一題，等我回答完再問下一題。不要給答案，也不要改我的程式。
```

家教問什麼，照抄在 `tutor.md` 的「家教問：」後面；你的回答自己想、自己打，寫在「我的回答：」後面，也貼回對話裡。答不出來的，先回去看程式、改一個數字跑跑看，再回答；還是不確定，就照實寫「我不確定，我猜……」。最後照 `tutor.md` 下面的三個勾自評（check 不看）。

**第三部分：替分帳寫 assert（交卷以後才做）。** `share.py` 是課程的正確版分帳（不用改、也不用看懂），`checks_share.py` 寫你的 assert（至少 5 條）。需求卡：

| 欄 | 內容 |
|---|---|
| 目標 | `share(total, people, who)`：total 元給 people 個人分，交回第 who 個人（從 1 數起）要付多少 |
| 限制 | 每個人付的錢，最多只差 1 元；除不盡剩下的零頭，由前面的人各多付 1 元 |
| 一定要成立 | 所有人付的加起來，等於 total |
| 例子 | 1000 元三個人分：第 1 個人付 334 元，第 2、3 個人各付 333 元 |
| 怎樣算做完 | 你的 assert 在正確版上全部成立；課程藏的 3 個壞版本，每一個都至少有一條不成立 |

寫法跟 1-8、1-9 一樣。課程不給你看壞版本的程式；寫滿 5 條以後，check 會說溜過去的是哪一種情況。

## 2. 提示

- **while**：每一圈開始前先看一次條件；`continue` 跳過這一圈下面的那幾行、回到 while；`break` 讓整個迴圈結束（1-10）。算跑幾次：一圈寫一列追蹤表。
- **for 和兩層迴圈**：`range(1, 4)` 是 1、2、3；內層跑完一整圈，外層才往下一個；`print` 縮在哪一層，就屬於哪一層（1-11）。`enumerate(…, start=1)` 的編號從 1 開始。
- **if／elif 沒有 else**：都不成立，就什麼都不做（1-9）。
- **錯誤訊息從最下面一行看起**：冒號前面是哪一種錯，往上看是第幾行。錯誤出現的那一行，不一定是要改的那一行（1-7）。`input` 交回的一定是字串；打 q 的那一次，也會被交給後面的程式（1-6、1-10）。
- **count 加 1 放在 break、continue 的下面**：真的記了一筆才加（1-10）。
- **燈號的邊界**：剛好 80% 是黃燈、剛好 100% 也是黃燈，超過才紅燈；想想 `<` 和 `<=`（1-8、1-9）。
- **分帳**：每人先付 `total // people`，零頭是 `total % people`（1-4）。用 `/` 會變成有小數點的數字。
- **第三部分**：先想需求卡說會遇到哪些情況（除得盡、除不盡、零頭不只 1 元、不是三個人分……），每一種寫一條。加起來等於 total 也可以寫成一條 assert。
- 不會的也要寫：考卷有題目空着，check 不讓你交卷（真的寫不出來，加 `--submit` 照樣交卷）。

```bash

uv run lessons/1-12/fix.py
uv run lessons/1-12/ledger.py
```

## 5. 怎麼測

考卷四個檔都寫好，回到課程資料夾打 `uv run check.py 1-12`，這就是**交卷**。一共 20 題：

- 讀程式 14 題：`trace.txt` 9 題（對答）、`parsons.py` 2 題（每一行都用上、縮排對；跑出來跟題目一樣）、`fix.py` 3 題（check 替你打 120、85、q：跑得起來；印出的兩行對；再打 120、空白的一行、85、q 也對）
- 從零寫 6 題：`ledger.py`，check 替你打六組輸入，每一組的預算、人數都不一樣：一開始就打 q（小計都是 0、綠燈）；三個分類的小計和合計；剛好 80% 的黃燈；剛好 100% 的黃燈；超過預算的紅燈；分帳的零頭

**第一次交卷就過 16 題以上，第一部分就過了。** 成績只照第一次交卷算：交卷以後再打 `uv run check.py 1-12` 是訂正，可以看自己改對了沒（加 `--all` 看全部），但不改成績。還有題目空着，check 不算交卷。開始前猜的、交卷時猜的、實際過了幾題，都記進校準曲線（`uv run check.py status`）。

**沒過：領矯正包，隔天以後考卷 B。** 交卷沒過，check 把矯正包寫進帳本的 `lessons/1-12/矯正包.md`：錯了哪幾題、正確答案和為什麼、要回哪一課影片的哪個時間看、要做哪一個練習（練習檔複製到 `lessons/1-12/practice/`）。練完，**隔天以後**打：

```bash
uv run check.py start 1-12B
```

卷 B 的題目不一樣，考的東西一樣（作答檔在帳本的 `lessons/1-12B/`，交卷打 `uv run check.py 1-12B`）。卷 B 第一次交卷過 16 題以上，第一部分一樣算過。卷 A 交卷的同一天打 `start 1-12B`，它會請你明天再來。

**第二、三部分：** 第一部分交卷以後（過不過都一樣），`tutor.md`、`share.py`、`checks_share.py` 會放進帳本。做完再打 `uv run check.py 1-12`（考過卷 B 的打 `1-12B` 也可以），它會檢查第二部分寫了沒、第三部分抓到幾個壞版本，再告訴你升級還差什麼。這兩部分不限次數，改到全過為止；全過的日期記下來以後，之後再改也不會倒退。

## 6. 怎麼交

不用交給任何人：在課程資料夾打 `uv run check.py 1-12`，成績和升級都記在你帳本的 `.check/` 裡。`uv run check.py status` 看得到三部分各自過關的日期，升級了會寫「已升級」。

關卡不擋你往下上課：沒過的時候，矯正包、卷 B 可以跟 1-13 一起進行。YouTube 沒辦法監考，這一關是給你校準自己用的，關掉 AI 自己考，分數才有意義。

技能樹上這一關的葉子，跟其他課一樣：第一部分過了以後，兩課以後、改天答對回顧題才會長出來。
