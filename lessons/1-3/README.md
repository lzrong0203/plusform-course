## 2. 提示

- `type(資料)` 告訴你資料是哪一種。`print(type(120))` 印出 `<class 'int'>`，只要看引號裡面那個字。
- 有小數點的是 `float`（`120.0` 也是）；有引號的是 `str`（`"120"`、`"True"`、`""` 都是）；`True`、`False` 是 `bool`（不加引號、第一個字母大寫）；`None` 是「還沒有值」，型別叫 `NoneType`。
- `"100" + 20` 會跳出 `TypeError`：文字只能跟文字接起來（`"100" + "20"` 是 `"10020"`），不能直接加整數。
- 0.1 + 0.2 印出 0.30000000000000004：大部分的小數，電腦用二進位存不剛好，這不是 Python 的 bug。我們的帳本只記到元，所以錢存成整數元，加起來剛好。
- `cases.txt` 的右邊寫的是**型別也要對**的值：整數寫 `120`，不要寫 `"120"`（文字）或 `120.0`（小數），也不要寫單位「元」。check 會連型別一起比，所以 `120` 和 `120.0` 算不一樣。
- 箭頭是減號加大於：`->`。引號要用鍵盤上的半形 `"`，不是中文的「」或 “ ”。

## 5. 怎麼測

`uv run check.py 1-3` 會先問你：「你覺得會過幾題？」先猜一個數字再按 Enter，它才開始檢查。一共 13 題：

- 對答：`types.txt` 4 題
- 官方測試：`entry.py` 的金額、備註、發票號碼各是對的型別（3 題）
- 第三圈：`cases.txt` 寫滿 4 組一般的案例、正確版都算得對、抓到 3 個壞版本、1 組標了「已知會當掉」而且正確版真的會當掉

沒過的，它只先告訴你第一個沒過的，修好再跑一次（想一次看全部，最後加 `--all`）。不到 8 分鐘就全對，它會印出提醒：只是提醒，不扣分。第②圈是自評，check 不檢查。
