# 分帳機是 AI 照需求卡寫的（課程準備、凍結的版本）：丟進去一筆錢（整數元），交回三個人各付多少。
# 需求卡：
#   目標：一筆錢三個人分，算出每個人付多少
#   背景：吃飯要平分；退款也要分回去（退款記成負數）
#   限制：每人相差不超過 1 元，加起來要等於原金額；零頭從第一個人開始，一人多付 1 元
#   怎樣算做完：你寫的案例，正確版都算得對；三個壞版本，各被你抓到
#
# 每一行這樣寫：左邊是總金額（整數，不加引號），中間是箭頭 ->，
# 右邊是三個人各付多少（照第一、二、三個人的順序，用逗號隔開，不寫「元」）。
# 算法：先用 // 算每人付多少、用 % 算零頭，零頭從第一個人開始，一人多 1 元。退款（負數）也照同一個算法。
#
# 第 1 組是範例，可以留著：
