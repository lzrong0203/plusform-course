# 1-4 用到的概念

這課的示範、起點檔、正確版（`reference/`）和壞版本（`mutants/`），只能用到下面這些概念。
老師端的 `tools/validate_lesson.py` 會用 Python 的 ast 模組粗略檢查，壞版本用到沒列的概念就不能收進題庫。

## 可以用的概念

- 註解
- print
- 變數
- 資料型別
- 數字運算（/、//、%、**、運算順序，這課教）
- 函式呼叫（例外：壞版本 1、3 的 round()、int() 學員不用看懂；呼叫函式到 1-6 才細講）
- 函式外殼（例外：split3() 是課程版本包成的分帳機，學員只寫案例表、不讀也不寫它；def 到 1-18 才教）
- tuple（例外：split3() 用 return 交回三個數字；學員在案例表只寫「三個數字用逗號隔開」，tuple 到 1-14 才教）

`guess.txt`、`ai_list.txt`、`my_list.md`、`cases.txt` 是文字檔，不是程式，不在檢查範圍。
