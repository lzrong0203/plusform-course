# 0-W 補充：Windows 同學先看——裝好 Git Bash、uv、VS Code

影片說明欄放不下的參考資料。這一課沒有作業，三章各對到一課：第 1 章 Git Bash（0-4 要用）、第 2 章 uv（0-5 要用）、第 3 章 VS Code（0-6 要用）。

錄影用的是一台 Windows 11 專業版的虛擬機（Arm 版、顯示比例 175%、示範帳號 bear），版本是 Git for Windows 2.56.1、uv 0.13.8、VS Code 1.146.0（2026-11-14）。你的版本號可能比較新，沒關係。

## 開始之前

- 建議用你自己的電腦。公司的電腦，先問公司的資訊人員能不能裝。
- x64 的電腦，Windows 10 或 11 都可以；ARM 的電腦要 Windows 11。Git for Windows 的官方需求寫 Windows 10 or later on a 64-bit CPU (x64 or amd64)，ARM64 則是 requires Windows 11；VS Code 官方寫 Requires Windows 10 or 11 (64-bit)，uv 官方寫最低支援 Windows 10。Windows 10 已經在 2025-10-14 結束支援，有機會建議升級。
- 先看電腦的種類：在工作列的開始按鈕上按右鍵 → 系統，找「系統類型」那一行。寫 ARM 的選 ARM64，寫 x64 的選 x64。這一頁在比較新的 Windows 11 叫「系統資訊」，有的電腦叫「關於」。
- 沒有管理員權限：Git 的安裝程式會跳出「使用者帳戶控制」問你要不要允許，沒有管理員權限的帳號，要輸入管理員的帳號密碼才能裝。git-scm.com 的下載頁另外有免安裝的 Portable 版（thumbdrive edition），這一課沒有示範，裝之前先問公司的資訊人員。uv 和 VS Code 的 User Installer 都裝在你自己的帳號裡，官方寫不需要管理員權限。

## 第 1 章：Git for Windows（裡面有 Git Bash）

1. 打開 <https://git-scm.com/install/windows>。最上面那行寫的 x64 或 ARM64，是網站自己判斷你的電腦；跟系統類型一樣就按 Click here to download，不一樣就從下面的 Standalone Installer 挑 x64 Setup 或 ARM64 Setup。
2. 下載好按「開啟檔案」。跳出「使用者帳戶控制」時，確認中間寫的是 Git for Windows，按「是」。
3. 安裝精靈一共 15 頁，只有一頁要改：

| 頁面（英文標題） | 怎麼選 |
|---|---|
| Information（授權說明） | Next |
| Select Destination Location（裝在哪裡） | 預設，Next |
| Select Components（裝哪些東西） | 預設，Next |
| Select Start Menu Folder（開始功能表資料夾） | 預設，Next |
| Choosing the default editor used by Git | **改成 Use Notepad as Git's default editor（Windows 內建的記事本）**。預設是 Vim，安裝程式自己寫 Vim can be hard to use、建議換掉 |
| Adjusting the name of the initial branch | 預設（Let Git decide），0-7 才會用到 |
| Adjusting your PATH environment | 預設（寫著 Recommended 的那個） |
| Choosing the SSH executable | 預設 |
| Choosing HTTPS transport backend | 預設 |
| Configuring the line ending conversions | 預設 |
| Configuring the terminal emulator to use with Git Bash | 預設（MinTTY） |
| Choose the default behavior of `git pull` | 預設 |
| Choose a credential helper | 預設 |
| Configuring extra options | 預設，按 Install |
| Completing the Git Setup Wizard | View Release Notes 可以取消，按 Finish |

4. 打開 Git Bash：按開始，打 `git bash`，按 Enter。以後每次都這樣打開。
5. 打 `git --version`，印出 `git version 2.56.1.windows.1` 這種字就是裝好了。

**提示字元長得不一樣？** 第一行是「帳號@電腦名稱」加上一個英文字。錄影的 Arm 電腦寫 `CLANGARM64`；x64 的電腦在 Git for Windows 2.56 起可能寫 `UCRT64`（2.56.0 把 MINGW64 換成 UCRT64，release notes 有寫），比較舊的版本寫 `MINGW64`。都正常，指令一樣。最後的 `~` 是家目錄，下一行的 `$` 代表可以打字了。

## 第 2 章：uv

1. 打開 uv 官方的安裝頁 <https://docs.astral.sh/uv/getting-started/installation/>，在 Standalone installer 那一段按 **Windows** 分頁。
2. 指令是：

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

   - `irm` 從後面的網址下載安裝程式，`iex` 把它交給電腦執行（官方原文：Use irm to download the script and execute it with iex）。
   - `-ExecutionPolicy ByPass`：官方寫 Changing the execution policy allows running a script from the internet.
   - 網址是 `https` 開頭的 `astral.sh`，跟官網 `docs.astral.sh` 是同一家。怎麼判斷一行安裝指令能不能信，0-5 會講。
3. 按指令右邊的複製按鈕（複製出來的不會帶前面的 `PS>`），回到 Git Bash，**在視窗裡按右鍵 → Paste**，或按 **Shift + Insert** 貼上，按 Enter。
4. 等它印出 `everything's installed!`。它裝在 `C:\Users\你的帳號\.local\bin`，不需要管理員權限。
5. **同一個視窗打 `uv --version`，錄影時出現 `bash: uv: command not found`**，這很正常：安裝程式最後一段寫 To add … to your PATH, either restart your shell。把 Git Bash 關掉，開一個新的，再打 `uv --version`，印出 `uv 0.13.8 (…)` 就好了。
6. 括號裡的 `x86_64-pc-windows-msvc` 是下載的版本種類。x64 的電腦都是這個；Arm 的電腦可能是這個或 `aarch64`，兩種都能用（uv 的 PowerShell 安裝程式註解寫：在 ARM64 Windows 上可能回傳 X64，靠模擬執行，沒關係）。

## 第 3 章：VS Code，內建終端機改成 Git Bash

1. 打開 <https://code.visualstudio.com/download>，Windows 那一格的 Download 寫的是 x64 或 Arm64 的 **User Installer**（官方說明：不需要管理員權限，裝在你自己的帳號裡）。
2. 安裝精靈（中文）：
   - 授權合約：選「我同意」，下一步。
   - 安裝的位置、開始功能表的資料夾：預設，下一步。
   - 選擇附加的工作：**最下面的「加入 PATH 中」要有勾**（預設就勾好了）。有勾，0-6 才能在終端機打 `code .` 打開 VS Code。
   - GitHub Copilot CLI：預設是 Install GitHub Copilot CLI now（會多下載大約 125 MB）。它是 GitHub 的另一個產品（安裝頁寫 requires a GitHub Copilot subscription，要另外的 GitHub Copilot 方案），這門課現在用不到，選 **Don't add the copilot command**。
   - 準備安裝 → 安裝 → 完成。
3. 第一次打開會問要不要登入，按右下角 **Continue without Signing In**；顏色主題用預設，按 **Get Started**。
4. 打開終端機：上面的 **⋯（三個點）→ Terminal → New Terminal**（視窗寬一點的話選單列直接有 Terminal；快速鍵是 Ctrl + Shift + `）。打開的是 **PowerShell**（最前面寫 `PS`，最後是 `>`），這是 VS Code 在 Windows 上的預設。
5. 改成 Git Bash：終端機右上角 **加號旁邊的小箭頭 → Select Default Profile → Git Bash**。已經開著的那一個還是 PowerShell，按加號開一個新的，最前面變成 `bear@… ~` 和 `$` 就是 Git Bash 了。
6. **在 VS Code 的終端機打 `uv --version` 找不到？** 錄影時，安裝精靈最後直接打開的 VS Code 就遇到這個狀況（推測是它還沒讀到裝好 uv 之後的新設定）。把 VS Code 整個關掉，從開始打 `vs code` 重新打開就好。

## 常見問題

- **`bash: uv: command not found`**：開一個新的 Git Bash（或重開 VS Code）。還是找不到，重跑一次 uv 的安裝指令，看最後有沒有印 `everything's installed!`。
- **打 `python` 跳出 Microsoft Store**（有的電腦會這樣）：不用裝。這門課一律用 `uv run`，0-5 會教。
- **在 Git Bash 按 Ctrl + C 想複製**：Ctrl + C 在終端機是「取消」。貼上用右鍵 → Paste 或 Shift + Insert。
- **畫面是英文的**：Git 的安裝精靈和 VS Code 的介面是英文（VS Code 的安裝精靈是中文），按鈕的位置跟影片一樣。
