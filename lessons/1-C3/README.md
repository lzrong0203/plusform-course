## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-C3` 會問你：一共 11 題，你覺得會過幾題）。交卷時它會再問你一次。

**第二部分：拼圖（`parsons.py`，2 題）。** 七行程式被打亂了，縮排也被拿掉了。只能搬動和縮排（每一層四個空格），不能改字、不能多寫、不能少寫；排好跑起來要印出檔案最上面寫的三行。check 看兩件事：七行都用上、Python 讀得懂；排好跑出來一樣。

**第三部分：手寫（`write.py`，3 題）。** 照註解的題目從零寫：`records` 是一串 (分類, 金額)，算出每一個分類一共花了多少，一類印一行。對答案的時候，check 會把 `records` 那一行換成別的帳再跑；每一題跑好幾組帳，有在中間的、也有在邊界的（只有一筆、全部同一類、一筆都沒有），每一組都印對才算一題。

## 2. 提示

- `b = a` 不是複製：`b` 和 `a` 指著同一個 list，改一個、兩個都變。要另一份，用 `a.copy()` 或 `a[:]`（1-16）。
- `append` 加在最後、`insert(i, x)` 插在索引 i、`remove(x)` 刪掉第一個等於 x 的、`pop()` 拿走最後一筆、`pop(0)` 拿走第一筆（1-13）。
- `a.sort()` 直接把 a 排好，**交回 None**；`sorted(a)` 交回排好的新 list，a 不動（1-13）。
- `for kind, amount in records:` 一次拆出一筆 tuple 的兩個值；`set` 會去掉重複的，沒有保證順序（1-14）。
- dict 用鍵拿值；同一個鍵再放一次是**換掉**值；`get(鍵, 0)` 查不到交回 0；dict 記得放進去的順序（1-15）。
- 推導式先看中間的 `for`，再看後面的 `if`，最後看最前面放進去的是什麼；`zip` 把兩串一格一格配成一對對（1-17）。
- 拼圖：只做一次的放最上面；`for`、`if` 那一行最後有冒號，底下要做的往右縮四格；只印一次的放最後、不縮排（1-11 做過拼圖）。
- 不會的也要寫：空著的題目，check 不讓你交卷（真的寫不出來，加 `--submit` 照樣交卷）。
