# 1-C3　檢核站 3　卷 B（關掉 AI，25 分鐘）

卷 A 交卷沒過的同學，照矯正包練完以後，**隔天以後**考這一份。題目跟卷 A 不一樣，每一題考的東西跟卷 A 同一題一樣（1-13～1-17：list、tuple 與 set、dict、可變與參照、推導式與 zip）。全程關掉 AI；參考時間 25 分鐘，只記錄、不擋你。說明照卷 A 的 [README](../README.md)，這裡只寫不一樣的地方。

## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-C3B` 會問你），交卷時再問一次。

**第一部分：追蹤（`trace.txt`，6 題）。** 三段程式，先不要跑，用眼睛追、在紙上畫格子，在「答：」後面寫答案。

**第二部分：拼圖（`parsons.py`，2 題）。** 七行程式被打亂、縮排被拿掉了。只能搬動和縮排，排好跑起來要印出檔案最上面寫的三行。

**第三部分：手寫（`write.py`，3 題）。** `pays` 是一串 (付款方式, 金額)，算出每一種付款方式一共付了多少，一種印一行。check 會把 `pays` 那一行換成別的帳再跑，三題各換兩組（一組在中間的、一組在邊界的），兩組都印對才算一題。

## 2. 提示

跟卷 A 一樣：`b = a` 不是複製、`copy()` 才是另一個 list；`sort()` 交回 None、`sorted()` 交回新的 list；`for` 後面拆包、`set` 去掉重複；dict 同一個鍵再放一次是換掉、`get(鍵, 0)` 查不到交回 0；推導式先看 `for`、再看 `if`；`zip` 配成一對對；拼圖只做一次的放最上面、冒號底下的往右縮四格。卡住了回矯正包寫的那幾段影片，不問 AI。

## 3. 開始前要打的指令

卷 A 交卷的隔天以後，在課程資料夾打：

```bash
cd ~/code/plusform-course
uv run check.py start 1-C3B
```

作答檔在帳本的 `lessons/1-C3B/`：`trace.txt`、`parsons.py`、`write.py`。跑程式在帳本資料夾打 `uv run lessons/1-C3B/parsons.py`、`uv run lessons/1-C3B/write.py`。
