# 1-C3 檢核站 3：補充

影片和 [README](README.md) 放不下的細節：這一站怎麼判分、check 怎麼換你的帳、卡住了回哪一課看、矯正包和卷 B 怎麼用、為什麼考前要先猜分數、Windows 的做法。

## 1. 這一站怎麼運作

- **考什麼**：只考 1-13～1-17（list、tuple 與 set、dict、可變與參照、推導式與 zip），三部分一共 11 題：追蹤 6 題（`trace.txt`）、拼圖 2 題（`parsons.py`）、手寫 3 題（`write.py`）。
- **全程關掉 AI**：VS Code 的 AI 功能 0-6 關了；聊天的 AI 和 0-8 設好的家教，這一站也先不開。
- **開始**：`uv run check.py start 1-C3`。它把三個作答檔複製到帳本的 `lessons/1-C3/`，再問你「一共 11 題，你覺得會過幾題」。
- **交卷**：三部分都寫好，打 `uv run check.py 1-C3`。它會再問你一次猜幾題，然後對答案。**第一次交卷就過 9 題以上，這一站就過了。**
- **還沒寫完不算交卷**：還有「答：」空著、`parsons.py` 沒動、`write.py` 只有題目那一行，check 會列出來，這次不算交卷。不會的也寫一個你覺得最可能的答案；真的寫不出來，加 `--submit` 照樣交卷。
- **交卷以後再打是訂正**：可以看自己改對了沒（平常只顯示第一個沒過的，加 `--all` 看全部），成績還是照第一次交卷算。
- **25 分鐘只記錄**：check 照「打 start 的時間」到「三個作答檔最後一次存檔的時間」算你花了多久，印出來給你參考，超過也不扣分、不擋你。
- **不擋你往下上課**：過了沒過，都可以接著上 1-18。

## 2. 三部分怎麼判

- **追蹤**：在「答：」後面寫印出來的樣子。印 list 的照印出來的寫，方括號、逗號都要（空格多少不算，`[45,300]` 和 `[45, 300]` 都對）；一行印好幾個值的（例如 `2 3`），值和值中間要空一格，`23` 不算對。選擇題只寫一個字母，寫兩個（例如「A 或 C」）不算。
- **拼圖**：兩題。第一題看七行都用上、沒有改字（多打少打空格不算改字）、縮排是四個空格的倍數、Python 讀得懂；第二題真的跑一次，印出來要跟檔案最上面的三行一樣。排法不只一種也沒關係（例如 if 底下的兩行誰先誰後），照跑出來的結果判。
- **手寫**：check 不看你怎麼寫（用 dict、用 list 都可以），只看印出來的那幾行：一行的字要跟題目的樣子一樣（空格多少不算），而且照分類第一次出現的順序（dict 記得放進去的順序；用 set 印，順序沒有保證，1-14 講過）。

## 3. check 怎麼換你的帳

`write.py` 最上面那一行 `records = [...]` 是題目的帳。對答案的時候，check 會在系統的暫存資料夾複製一份你的程式，把這一行換成別的帳再跑（你的檔案不會被改），所以 `records` 那一行要留著、寫在同一行。三題各跑兩、三組帳（一組可能就是題目原本的帳），每一組都印對才算一題：

- 每一類只有一筆：`[("交通", 30), ("醫療", 500), ("娛樂", 250), ("文具", 35)]`、同樣四類換個順序的 `[("娛樂", 250), ("交通", 30), ("文具", 35), ("醫療", 500)]`，和只有一筆的 `[("文具", 35)]`。
- 同一類有好幾筆：題目原本的帳，和四筆都是午餐的 `[("午餐", 120), ("午餐", 90), ("午餐", 75), ("午餐", 100)]`。
- 沒看過的分類、一筆都沒有：`[("文具", 35), ("娛樂", 250), ("醫療", 500), ("交通", 30), ("娛樂", 50), ("醫療", 80), ("交通", 20)]`（七筆，四類第一次出現的順序跟第一組相反），和 `[]`（什麼都不印）。

為什麼每一題都放在中間的、也放在邊界的？只放邊界的話，寫錯的程式也可能剛好對。例如把 print 縮在 for 底下、每一圈都印一次：每一類只有一筆的時候，印出來剛好一樣；同一類有好幾筆的時候才會多印。筆數也不會只到五筆：只算前幾筆的程式，在七筆那一組就會算錯。

## 5. 矯正包怎麼用

交卷沒過（或過了但有錯的題目），check 會寫一份 `矯正包.md` 到帳本的 `lessons/1-C3/`（卷 B 的寫在 `lessons/1-C3B/`）。照順序做：

1. **錯在哪裡**：每一題你寫了什麼、正確答案和為什麼；程式題附 check 的說明（換了哪一組帳、應該印出什麼、你的印出）。
2. **回原課看那一段**：照上面那張表的時間碼，看那一章。
3. **做練習**：每個練習檔最上面寫著怎麼做。追蹤的先在紙上畫格子、寫下答案，再用 `uv run` 跑一次對答案；拼圖、修縮排和手寫的，排好、改好、寫好再跑。
4. **隔天以後考卷 B**：`uv run check.py start 1-C3B`。

練習的時候一樣關掉 AI。

## 6. 卷 B

- 卷 A 交卷的**隔天以後**才能開始（同一天打 `start 1-C3B`，它會請你明天再來）。
- 題目不一樣，每一題考的東西跟卷 A 同一題一樣（例如第 4 題都是「sort() 交回 None」；手寫都是依某一欄加總，卷 B 是依付款方式）。
- 作答檔在帳本的 `lessons/1-C3B/`，交卷打 `uv run check.py 1-C3B`。第一次交卷過 9 題以上，檢核站 3 一樣算過。
- 卷 B 也沒過：照它的矯正包把那幾段再看一次、練習做完，再接著上課。卷 A 就過了的人，卷 B 不用考（想多練一次也可以）。
- 卷 B 由 AI 照卷 A 的概念清單出題，答案都用 Python 3.13 實際跑過。

## 7. 為什麼考前要先猜分數

開始時猜一次、交卷時再猜一次，對完答案看猜的跟實際一不一樣。兩次猜的和實際過了幾題，都記進校準曲線（`uv run check.py status`）；不一樣太多時，check 會請你寫一句「下次我會怎麼估」。

有一個研究請 246 個人用 AI 解 20 題邏輯題（美國法學院入學考試的題目），大家估自己的表現，平均比實際高了 4 分（Fernandes 等人，原文：participants overestimated their performance by four points）。做完了，也可能把自己估得太高；所以這一站先關掉 AI，自己做、自己估，再對答案。這門課不保證越估越準，曲線只是讓你看到自己估得準不準。
