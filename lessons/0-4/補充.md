影片：AI 時代的 Python 零基礎課 0-4〈終端機不可怕，順便看懂 agent 要下的指令〉。題目的完整版在同一個資料夾的 [README.md](README.md)。

## 打開終端機

1. 先把輸入法切成英文：通常按一下 Caps Lock，或按 control＋空白鍵。
2. 按 ⌘＋空白鍵叫出搜尋框，打 terminal（中文介面也可以打「終端機」），再按 Enter。
3. 開著注音打字，會出現 `zsh: command not found`，意思是找不到這個指令。切成英文再打一次就好。
4. 字太小：按 ⌘ 和加號放大。Mac 鍵盤上的 Enter 那顆寫的是 return。

開始前要打的指令（從這一課才開始看的也一樣）：

```
mkdir -p ~/code/ledger
cd ~/code/ledger
pwd
```

## 你的畫面跟影片不一樣？

- 提示字元（每一行最前面那一串）前面是你自己的帳號和電腦名稱（影片是示範用的 bear@MacBook-Air），而且只寫最後一個資料夾的名字。想看完整的位置就打 `pwd`。
- 影片的提示字元是新 Mac 預設的樣子。改過終端機設定的話，長相會不一樣，指令都一樣。
- 新視窗第一行的 Last login 是上次登入的時間，不用管。
- `ls -a` 多一個 `.DS_Store`：那是 Mac 的 Finder 自己放的檔案，用 Finder 打開過的資料夾常會有，不用理它。

**作業三**：讀 agent 想下的六行指令（`start/agent_setup.txt`），寫出「做完之後帳本應該長什麼樣子」的檢查。

需求卡：

## 指令小抄

- 指令和後面的東西中間，都要空一格（`mkdir -p ~/code/ledger` 裡有兩個空格）
- `pwd`：我現在在哪裡
- `ls`：列出這一層有什麼；`ls -a` 連藏起來的也列；`ls -R` 每一層都列（R 大寫：按住 shift 再按 R）
- `cd 資料夾`：走進去；`cd ..`：往上走一層
- `mkdir -p a/b`：建資料夾（斜線是「裡面的」：a 裡面的 b），缺的資料夾一起建，已經有了也不會出錯
- `touch 檔名`：建一個空檔案
- `cp 來源 目的地`：複製（先寫要複製的那個，再寫新的那份放哪裡）
- `mv 來源 目的地`：搬家；在同一個資料夾裡就是改名
- `rm 檔名`：刪除，不進垃圾桶，刪之前先 `ls` 看清楚
- Tab：把打一半的名字補完；↑（上方向鍵）：叫回上一個指令；control + C（按住 control 再按 C）：取消這一行，或讓正在做的指令停下來（Mac 的複製是 ⌘ + C）
- 看到 `No such file or directory`：找不到這個檔案或資料夾。通常是打錯字，或你不在你以為的資料夾（打 `pwd` 看看）。
- 問 AI 家教的時候：貼上你打的那一行、完整的錯誤訊息（用滑鼠選起來 ⌘ + C 複製，不要自己重打），還有你在哪個資料夾。
- agent 要你加 sudo：先停下來，問清楚為什麼要用管理員的身分。sudo 會跟你要 Mac 的密碼，剛開始學都用不到。

## Windows 的同學

先看〈0-W　Windows 同學先看：裝好 Git Bash、uv、VS Code〉第 1 章，裝好 Git for Windows、打開 Git Bash（0-W 上架後補連結）。這一課的指令在 Git Bash 都一樣，有幾個畫面長得不一樣：

- 提示字元分兩行：上一行是「帳號@電腦名稱 MINGW64」加上位置，位置寫完整、從家目錄算起（家目錄顯示成 `~`，帳本裡是 `~/code/ledger`），`$` 在下一行。打 `pwd` 顯示的是 `/c/Users/你的帳號名稱/code/ledger` 這種寫法。
- `ls` 會在資料夾名字後面加 `/`；`ls -R` 最前面會多一行「`.:`」，這是正常的。
- 打錯路徑時，錯誤訊息寫成 `cp: cannot stat 'pratice/hello.txt': No such file or directory`，一樣是「誰在抱怨、要找的路徑、原因」三段。
- 少打結尾的引號時，出現的是 `>`，不是 `dquote>`，一樣按 Ctrl + C 取消。
- Ctrl + C 在 Git Bash 也是取消，不是複製。

## 延伸與參考

- rm 刪掉的不會進垃圾桶。比較新的 macOS（本片錄影用的 macOS 26）內建 `trash` 指令，會把檔案移到垃圾桶（終端機打 `man trash` 看說明，舊版 macOS 可能沒有）。
- macOS rm 說明（終端機打 `man rm`）：`-f` 不管檔案權限都不問、找不到檔案也不報錯；It is an error to attempt to remove the files /, . or ..（所以 `rm -rf ../` 會被擋，`rm -rf ../ledger` 擋不住）。
- 版本：2026-11 版 · macOS 終端機（zsh）。終端機畫面是在練習資料夾實際錄的；為了不露出真實帳號，路徑顯示成示範用的 `/Users/bear`，提示字元也換成示範用的 bear@MacBook-Air。
