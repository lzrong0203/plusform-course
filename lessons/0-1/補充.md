這份是〈AI 時代的 Python 零基礎課 0-1 課程導覽〉影片說明欄放不下的內容（YouTube 說明欄有字數上限）。影片：（連結上架時補）

## 這門課免費

每一課都放在 YouTube，課程資料夾公開、不用註冊，上到哪一級都不收學費。片中和說明欄提到要付費的，只有第四級起的 agent 工具，那是付給工具公司的費用，不是付給我們的，也沒有推廣連結。

## 要準備什麼

一台電腦，Mac 或 Windows 都可以（手機和平板沒辦法跟這門課）。用 Windows 的同學，上到終端機那一課前先看 0-W（Windows 準備篇）。

## 一課要花多少時間

新手村每課影片十幾分鐘，練習大約再花 40 分鐘（以 0-4 為例，檢查程式開始時會告訴你這課大約要多久）。不用每天練，每週固定幾天就好。

## 課程地圖（八級）

- Lv0 新手村：認識終端機、裝好 Python、跑起第一支自己的程式
- Lv1 看得懂：先猜一段程式會印出什麼、讀懂錯誤訊息；學完，片中那支記帳程式每一行你都講得出來，也說得出它為什麼當掉
- Lv2 做小工具：匯入對帳單、多幣別
- Lv3 跟人協作：用 Git 記下每次修改、讓別人和 AI 一起檢查
- Lv4 把工作交給 AI：交給會自己動手的 agent，你寫需求和驗收
- Lv5 把關長任務：權限、自動檢查、驗收 agent
- Lv6 做 AI 應用：做一個 AI 助理給別人用
- Lv7 大師之路：設計、資安、開源、帶新人

整門課只做一個專案：你自己的記帳程式，從印出三筆花費開始，一級一級長大，最後變成會記帳的 AI 助理。新手村和第一級上半，第三圈的「交出去」由課程在畫面上示範，你負責驗收課程準備的版本；AI 能碰多少東西也照等級慢慢放，新手村的 AI 只當家教，不碰你的檔案、不給指令照貼。

## 學習契約為什麼寫「每週練幾天」

一份 Python 入門課的隨機實驗（143 人）發現，照「有練習的天數」給分的那組，期末考比照題數給分的那組好（85.3% 對 81.7%）。升級看的也是關卡過了沒、練了幾天，不看你看了幾支影片。

在課程資料夾的 showcase/ledger_app.py，是課程照「agent 照需求交件」常見的樣子準備的示範（情境重現），不是真的 agent 紀錄，之後也不會再改。它看起來很完整，有型別提示、有說明、也處理了負數，卻沒想到有人會打國字：它會先把 NT$、$、逗號和「元」拿掉再轉成數字，所以「120元」可以，「一百元」剩下「一百」就轉不過去、整支當掉。它也只在你選「存檔」或「離開」時才存檔，所以一當掉，前面記的也跟著不見（片中沒演這段，可以自己試）。檔案打開是 221 行，看得懂進度條算的是不算空行的 172 行。學完第一級，每一行你都講得出來。想自己跑跑看：

## 檢查程式（check.py）

檢查程式（check.py）是 0-5 以後才會用到的：它從來不呼叫 AI、也不連網；跑之前先問你猜會過幾題；一次只給你看第一個沒過的題目；猜的跟實際差太多，會請你寫一句下次怎麼估；太快就全對會提醒你這可能是警訊（只是提醒，不扣分）；學過的題目在通過後第 2 課和第 5 課各再考一次，跟通過那天不同天答對，技能樹才長葉子。YouTube 沒辦法監考，所以這套檢查是拿來校準自己的，不發證書。

## 要誠實講的兩件事

第一，這樣學速度不會比以前快多少，同樣的時間，換到的是看得出 AI 哪裡錯的能力。第二，「每課三圈」的教法還沒有實驗直接證明過，是我們從下面這幾份研究推出來的，所以前幾課會看大家的留言和觀看情況調整。

## 研究補充

- Anthropic（做 Claude 的公司）的研究：52 位工程師（多數資歷淺）學一套沒用過的 Python 工具（Trio），用 AI 的那組測驗平均 50 分、自己寫的 67 分，差最多的是除錯題。這是 arXiv 預印本，尚未經同儕審查。
- 光譜左邊：片中舉哈佛的 CS50，學術誠信規定只允許課程自己的 AI（CS50 Duck），其他會幫你寫答案的 AI 不行（CS50x 和 Python 入門的 CS50P 寫法一樣）。另一個常被舉的例子是 The Odin Project，它寫的是「不建議」用 AI 學，不是禁止。
- 「新手一句話叫 AI 寫好整題，當下分數最高、之後自己改時最差」的研究（Kazemitabaar 等人），受試者是 33 位 10 到 17 歲的新手，用法是他們自己選的，所以是相關，不是隨機比較；修改題那一段不能用 AI。
- 土耳其近千名高中生學數學的實驗（Bastani 等人）：練習時能隨便問 GPT-4 的那組，AI 拿走後考試比沒用過的同學低 17%；家教版背後有老師寫好的解答，AI 只給提示、不直接給答案，傷害大多被抵銷。
- 延伸閱讀（片中沒講）：Strömberg 等人追蹤兩萬六千多名中國中學生 30 個月，開始用 AI 後作業分數高了 18%，每月考試卻在半年內掉了 20%，兩種升學考試分別掉 18% 和 24%；研究者判斷損失集中在大約 80% 看起來像把作業外包的人（工作論文，尚未經同儕審查）。加州大學聖地牙哥分校（UCSD）的入門課第一週就引進 AI，期末考 85% 的分數在實驗室電腦作答、不能用 AI，成績跟往年大致相當（非正式比較）；他們也建議先讓學生自己寫一些小程式再引進 AI，這正是我們新手村先不用 AI 的理由之一。
