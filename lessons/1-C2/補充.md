# 1-C2 檢核站 2：補充

影片和 [README](README.md) 放不下的細節：這一站怎麼判分、check 怎麼替你打字、卡住了回哪一課看、矯正包和卷 B 怎麼用、為什麼考前要先猜分數、Windows 的做法。

## 1. 這一站怎麼運作

- **考什麼**：只考 1-5～1-9（字串、input 與型別轉換、讀錯誤訊息、比較與邏輯、if／elif／else），三部分一共 12 題：預測輸出 6 題（`trace.txt`）、修好 3 題（`fix.py`）、手寫 3 題（`write.py`）。
- **全程關掉 AI**：VS Code 的 AI 功能 0-6 關了；聊天的 AI 和 0-8 設好的家教，這一站也先不開。
- **開始**：`uv run check.py start 1-C2`。它把三個作答檔複製到帳本的 `lessons/1-C2/`，再問你「一共 12 題，你覺得會過幾題」。
- **交卷**：三部分都寫好，打 `uv run check.py 1-C2`。它會再問你一次猜幾題，然後對答案。**第一次交卷就過 10 題以上，這一站就過了。**
- **還沒寫完不算交卷**：還有「答：」空着、`fix.py` 沒改、`write.py` 一行程式都沒有，check 會列出來，這次不算交卷。不會的也寫一個你覺得最可能的答案；真的寫不出來，加 `--submit` 照樣交卷。
- **交卷以後再打是訂正**：可以看自己改對了沒（平常只顯示第一個沒過的，加 `--all` 看全部），成績還是照第一次交卷算。
- **25 分鐘只記錄**：check 照「打 start 的時間」到「三個作答檔最後一次存檔的時間」算你花了多久，印出來給你參考，超過也不扣分、不擋你。
- **不擋你往下上課**：過了沒過，都可以接着上 1-10。

## 2. check 怎麼替你打字

`fix.py` 和 `write.py` 都會用 `input` 問你。對答案的時候，check 會自己替你打字（跟 1-6 用 `inputs.txt` 餵程式一樣），不用你在旁邊打：

- `fix.py`：先餵「珍奶、65元」跑一次，看跑不跑得起來、印出來的三行對不對；再餵「紅茶、300元」跑一次，看剛好花完的時候對不對。
- `write.py`：規則的三段各算一題，每一段餵兩個金額各跑一次、都印對才算：不到 500（120、499）、500 到 999（剛好 500、800）、1000 以上（剛好 1000、1500）。有剛好在邊界上的，也有在中間的：只放邊界的話，把「大於或等於」寫成「等於」也會被當成對的。
- 提示字（「品項：」「金額：」）後面不換行，會跟印出來的第一行黏在一起，這是正常的；check 只看你印的那幾行裡有沒有應該要有的字。
- 印出來的字要跟題目的樣子一樣，空格也算（`運費 60 元，一共 710 元`）。逗號用全形「，」或半形「,」都可以。提示字寫什麼、判斷怎麼寫，check 不另外檢查，只看印出來的那一行。

跑起來跳出錯誤訊息，就照 1-7 從最下面一行看起：冒號前面是哪一種錯，後面是原因，引號裡的值是程式實際拿到的東西；往上是第幾行。錯誤出現的那一行，不一定是要改的那一行。

## 4. 矯正包怎麼用

交卷沒過（或過了但有錯的題目），check 會寫一份 `矯正包.md` 到帳本的 `lessons/1-C2/`（卷 B 的寫在 `lessons/1-C2B/`）。照順序做：

1. **錯在哪裡**：每一題你寫了什麼、正確答案和為什麼；程式題附 check 的說明（餵了什麼、應該印出什麼、你的印出）。
2. **回原課看那一段**：照上面那張表的時間碼，看那一章。
3. **做練習**：每個練習檔最上面寫着怎麼做。猜輸出的先在紙上寫下來，再用 `uv run` 跑一次對答案；壞掉的程式先跑、從錯誤訊息最下面一行看起，修好再跑。
4. **隔天以後考卷 B**：`uv run check.py start 1-C2B`。

練習的時候一樣關掉 AI。

## 5. 卷 B

- 卷 A 交卷的**隔天以後**才能開始（同一天打 `start 1-C2B`，它會請你明天再來）。
- 題目不一樣，每一題考的東西跟卷 A 同一題一樣（例如第 3 題都是「input 交回字串，+ 是接起來」）。
- 作答檔在帳本的 `lessons/1-C2B/`，交卷打 `uv run check.py 1-C2B`。第一次交卷過 10 題以上，檢核站 2 一樣算過。
- 卷 B 也沒過：照它的矯正包把那幾段再看一次、練習做完，再接着上課。卷 A 就過了的人，卷 B 不用考（想多練一次也可以）。
- 卷 B 由 AI 照卷 A 的概念清單出題，答案都用 Python 3.13 實際跑過。

## 6. 為什麼考前要先猜分數

開始時猜一次、交卷時再猜一次，對完答案看猜的跟實際一不一樣。兩次猜的和實際過了幾題，都記進校準曲線（`uv run check.py status`）；不一樣太多時，check 會請你寫一句「下次我會怎麼估」。

有一個研究請 246 個人用 AI 解 20 題邏輯題（美國法學院入學考試的題目），大家估自己的表現，平均比實際高了 4 分（Fernandes 等人，原文：participants overestimated their performance by four points）。做完了，也可能把自己估得太高；所以這一站先關掉 AI，自己做、自己估，再對答案。這門課不保證越估越準，曲線只是讓你看到自己估得準不準。

## 7. Windows

指令都在 Git Bash 照打，跟 Mac 一樣；VS Code 裡 ⌘ 換成 Ctrl。check.py 自己替你打字、自己跑你的程式、自己算時間，Mac 和 Windows 一樣。
