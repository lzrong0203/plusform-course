# 1-C2　檢核站 2　卷 B（關掉 AI，25 分鐘）

卷 A 交卷沒過的同學，照矯正包練完以後，**隔天以後**考這一份。題目跟卷 A 不一樣，每一題考的東西跟卷 A 同一題一樣（1-5～1-9：字串、input 與型別轉換、讀錯誤訊息、比較與邏輯、if／elif／else）。全程關掉 AI；參考時間 25 分鐘，只記錄、不擋你。說明照卷 A 的 [README](../README.md)，這裡只寫不一樣的地方。

## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-C2B` 會問你），交卷時再問一次。

**第一部分：預測輸出（`trace.txt`，6 題）。** 四段程式，先不要跑，用眼睛追，在「答：」後面寫答案。

**第二部分：修好（`fix.py`，3 題）。** 照註解打品項和價錢，修好以後要印出註解寫的三行；剛好花到預算也要對。

**第三部分：手寫（`write.py`，3 題）。** 照註解的題目從零寫，用 `input` 問金額、`if`／`elif`／`else` 判斷折多少（check 會餵三個金額，有剛好在邊界上的）。

## 2. 提示

跟卷 A 一樣：切片拿到結束那一格之前、`split()`、`replace()`、`{x:,}`；`input` 交回的一定是字串，要算先 `int()`；錯誤訊息從最下面一行看起，引號裡是程式實際拿到的值，錯誤出現的那一行不一定是要改的那一行；剛好等於時 `>` 不成立、`>=` 成立；`if`／`elif` 從上往下、第一個成立的才做。卡住了回矯正包寫的那幾段影片，不問 AI。

## 3. 開始前要打的指令

卷 A 交卷的隔天以後，在課程資料夾打：

```bash
cd ~/code/plusform-course
uv run check.py start 1-C2B
```

作答檔在帳本的 `lessons/1-C2B/`：`trace.txt`、`fix.py`、`write.py`。跑程式在帳本資料夾打 `uv run lessons/1-C2B/fix.py`、`uv run lessons/1-C2B/write.py`。

## 4. 成品示範

修好的 `fix.py`（品項打 蛋餅、價錢打 45元）印出：

```
品項：蛋餅
價錢：45元
蛋餅 45 元
這週花了 165 元
還在預算內
```

`write.py`（金額打 1200）印出：

```
金額：1200
折 50 元，要付 1150 元
```
