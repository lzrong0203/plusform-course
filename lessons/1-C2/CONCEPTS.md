# 1-C2 用到的概念

檢核站 2 只考 1-5～1-9 教過的東西（也會用到 1-1～1-4 的 print、變數、型別、運算）。卷 A、卷 B（`B/`）、正確版、矯正包練習（`practice/`）都只能用到下面這些概念。
老師端的 `tools/validate_lesson.py` 會用 Python 的 ast 模組粗略檢查。

## 可以用的概念

- 註解（1-1）
- print（1-1）
- 變數（1-2）
- 資料型別（1-3）
- 數字運算（1-4）
- 字串操作（1-5：索引、切片、strip、split、replace、f-string 的千分位）
- input（1-6：先印提示、等你打字、交回的一定是字串）
- 函式呼叫（1-6：int()、input() 這種呼叫別人寫好的函式；回傳值可以直接放進另一個函式的括號）
- 比較與邏輯（1-8：>、<、>=、<=、==、!=、and、or、not）
- if（1-9：if、elif、else）
- list（例外：split() 交回的一串文字，只用 parts[0]、parts[-1] 拿出第幾段，跟 1-5 一樣；list 到 1-13 才細講）

`trace.txt` 是文字檔，裡面的程式不跑，不在 ast 檢查範圍；它的四段程式也只用上面這些概念。
第二部分的 `fix.py` 故意壞掉（跑起來會遇到 TypeError、ValueError，剛好花完的判斷也寫錯），起點檔照樣做概念檢查；矯正包練習裡故意寫錯的 `p_syntax.py`（少冒號、少縮排）Python 看不懂，不做概念檢查。
