# 1-C2　檢核站 2（關掉 AI，25 分鐘）

這一站確認 1-5～1-9（字串、input 與型別轉換、讀錯誤訊息、比較與邏輯、if／elif／else）你不靠 AI 也會。**全程關掉 AI**：VS Code 的 AI 功能 0-6 已經關了；聊天的 AI 和 0-8 設好的家教，這一站也先不開。卡住了不問 AI，不會的題目寫你覺得最可能的答案。Windows 同學：指令在 Git Bash 照打，⌘ 換成 Ctrl。

參考時間 25 分鐘：check 會照檔案時間記下你花了多久，**只記錄、不擋你**。檢核站也不擋你往下上課，沒過照樣可以開始 1-10。卡住時回哪一課看、矯正包怎麼用、預測分數的出處，寫在 [補充.md](補充.md)。

## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-C2` 會問你：一共 12 題，你覺得會過幾題）。交卷時它會再問你一次。

**第一部分：預測輸出（`trace.txt`，6 題）。** 四段程式，先不要跑，用眼睛從第一行往下追，在「答：」後面寫答案。有 `input` 的那一段，題目會寫你打了什麼。

**第二部分：修好（`fix.py`，3 題）。** 一支壞掉的程式，最上面的註解寫着跑的時候要打什麼、修好以後應該印出哪三行。先跑，跳出錯誤訊息就從最下面一行看起，修好一個再跑一次；修好一個以後，可能又跳出另一種錯誤訊息。跑得起來以後，跟註解的三行一行一行比，再想想「剛好花完」的時候對不對。

**第三部分：手寫（`write.py`，3 題）。** 照註解的題目，從零寫一支 10 行左右、有 `input` 和 `if` 的小程式。對答案的時候，check 會餵三個不一樣的金額（有剛好在邊界上的），每一個都要印對。

## 2. 提示

- 切片 `d[開始:結束]` 拿到結束那一格**之前**；負的從後面數。`split()` 用空白拆開，`replace("元", "")` 把「元」拿掉，`{x:,}` 加千分位逗號（1-5）。
- `input` 交回來的**一定是字串**：兩個字串用 `+` 是接起來；要算，先用 `int()` 變成整數（1-6）。
- 錯誤訊息從最下面一行看起：冒號前面是哪一種錯，後面是原因；引號裡的值，是程式實際拿到的東西。往上看是第幾行。**錯誤出現的那一行，不一定是要改的那一行**（1-7）。
- 比較的結果是 `True` 或 `False`。剛好等於的時候，`>` 不成立、`>=` 成立。`or` 的兩邊要各寫一個完整的比較（1-8）。
- `if`／`elif` 從上往下看，第一個成立的那一條才做；沒有縮排的那一行，不屬於 if，一定會做（1-9）。
- 不會的也要寫：空著的題目，check 不讓你交卷（真的寫不出來，加 `--submit` 照樣交卷）。

## 5. 怎麼測

三部分都寫好，回到課程資料夾打 `uv run check.py 1-C2`，這就是**交卷**。一共 12 題：

- 第一部分：`trace.txt` 6 題（對答）
- 第二部分：`fix.py` 跑得起來（check 餵 珍奶、65元）；印出來的三行跟題目一樣；剛好花完（check 餵 紅茶、300元）也印出「還在預算內」
- 第三部分：`write.py` 餵三個金額：120、剛好 500、剛好 1000，各算一題

**第一次交卷就過 10 題以上，這一站就過了。** 成績只照第一次交卷算：交卷以後再打 `uv run check.py 1-C2` 是訂正，可以看自己改對了沒（加 `--all` 看全部），但不改成績。還有題目空著，check 不算交卷，會告訴你哪幾題沒寫。

開始前猜的、交卷時猜的、實際過了幾題，都記進校準曲線（`uv run check.py status`）。猜的跟實際不一樣太多，它會請你寫一句「下次我會怎麼估」。

**沒過：領矯正包，隔天以後考卷 B。** 交卷沒過，check 會把矯正包寫進帳本的 `lessons/1-C2/矯正包.md`：你錯了哪幾題、正確答案和為什麼、要回哪一課影片的哪個時間看、要做哪一個練習（練習檔複製到 `lessons/1-C2/practice/`）。練完，**隔天以後**打：

```bash
uv run check.py start 1-C2B
```

卷 B 的題目不一樣，考的東西一樣（作答檔在帳本的 `lessons/1-C2B/`，交卷打 `uv run check.py 1-C2B`）。卷 B 第一次交卷過 10 題以上，這一站一樣算過。卷 A 交卷的同一天打 `start 1-C2B`，它會請你明天再來。

不用交給任何人：交卷就是在課程資料夾打 `uv run check.py 1-C2`，成績記在你帳本的 `.check/` 裡。過了沒過，都可以接着上 1-10（矯正包和卷 B 可以跟 1-10 一起進行）。
