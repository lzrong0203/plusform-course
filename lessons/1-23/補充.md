### 緩衝區：write 的字先放在 Python 手上

`f.write` 寫的字先放進緩衝區；關檔（with 那一段做完）、緩衝區滿了、或呼叫 `f.flush()`，才送進檔案。

```python
from pathlib import Path

p = Path("ledger.txt")
with open(p, "w", encoding="utf-8") as f:
    f.write("11/03,午餐,120\n")
    print("write 以後：", repr(p.read_text(encoding="utf-8")))
    f.flush()   # 叫 Python 現在就把緩衝區送進檔案
    print("flush 以後：", repr(p.read_text(encoding="utf-8")))
print("with 結束以後：", repr(p.read_text(encoding="utf-8")))
print("f.closed：", f.closed)
```

印出（Python 3.13 實際跑）：

```
write 以後： ''
flush 以後： '11/03,午餐,120\n'
with 結束以後： '11/03,午餐,120\n'
f.closed： True
```

## 5. 對答題的說明（作業做完再看）

**predict.txt**：第 1 題 B（w 一打開就先清空，只剩新寫的那一行）、第 2 題 C（a 接在後面，跑兩次就兩行）、第 3 題 A（只寫檔名是相對路徑，從你打指令的帳本資料夾算起）。

**close.txt**：第 1 題 B（write 的字還在緩衝區，with 還沒結束時讀到的是空的）、第 2 題 C（with 那一段跑完就關檔，f.closed 是 True）、第 3 題 A（官方教學 7.2 的 Warning：不關檔，寫的字可能沒有完整寫進去，就算程式正常結束也一樣）。

**checks_store.py**：課程藏的 3 個 AI 寫錯的版本是：存檔用 a 接在後面（同一個測試檔存第二次才抓得到）、只讀回第一行（好幾筆的帳本才抓得到）、空的帳本不存（存一個 [] 再讀回來才抓得到）。
