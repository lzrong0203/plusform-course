## 2. Python 官方文件怎麼說（原文節錄，Python 3.13）

**索引從 0 開始、負的從右邊數**（[教學 3.1.2 Text](https://docs.python.org/3.13/tutorial/introduction.html#text)）：

> Strings can be indexed (subscripted), with the first character having index 0. … Indices may also be negative numbers, to start counting from the right

**切片：左邊包含、右邊不包含**（同一節）：

> Note how the start is always included, and the end always excluded. This makes sure that s[:i] + s[i:] is always equal to s

影片說的「左邊的數字要拿，右邊的數字不拿」就是這一句：`d[5:7]` 拿索引 5、6，不拿 7。省略的時候：an omitted first index defaults to zero, an omitted second index defaults to the size of the string（左邊省略從頭、右邊省略到尾）。

**全形空白也是空白**（[str.isspace](https://docs.python.org/3.13/library/stdtypes.html#str.isspace)，文件裡的例子就是全形空白）：

> >>> '\u3000'.isspace() # IDEOGRAPHIC SPACE
> True
> A character is whitespace if in the Unicode character database (see unicodedata), either its general category is Zs ("Separator, space"), or its bidirectional class is one of WS, B, or S.

**strip() 不帶參數：拿掉前後的空白**（[str.strip](https://docs.python.org/3.13/library/stdtypes.html#str.strip)）：

> If omitted or None, the chars argument defaults to removing whitespace. … Whitespace characters are defined by str.isspace().

**split() 帶不帶參數不一樣**（[str.split](https://docs.python.org/3.13/library/stdtypes.html#str.split)）：

> If sep is given, consecutive delimiters are not grouped together and are deemed to delimit empty strings (for example, '1,,2'.split(',') returns ['1', '', '2']).
> If sep is not specified or is None, a different splitting algorithm is applied: runs of consecutive whitespace are regarded as a single separator, and the result will contain no empty strings at the start or end if the string has leading or trailing whitespace.

所以 `split()`（括號裡不寫東西）把連在一起的空白當成一個，全形空白也認得；`split(" ")`（括號裡寫一個半形空白）只照半形空白拆，兩個空白中間會拆出空的一段，全形空白它不認得。

**f-string 的格式**（[Format Specification Mini-Language](https://docs.python.org/3.13/library/string.html#format-specification-mini-language)、[教學 7.1.1](https://docs.python.org/3.13/tutorial/inputoutput.html#formatted-string-literals)）：

> '<' Forces the field to be left-aligned within the available space (this is the default for most objects).
> '>' Forces the field to be right-aligned within the available space (this is the default for numbers).
> The width is a decimal integer defining the minimum total field width
> ',' Inserts a comma every 3 digits for integer presentation type 'd' and floating-point presentation types
> 'f' Fixed-point notation. For a given precision p, formats the number as a decimal number with exactly p digits following the decimal point. … If p=0, the decimal point is omitted
> Passing an integer after the ':' will cause that field to be a minimum number of characters wide.

## 4. 全形空白（第③圈的提示）

- 全形空白是中文輸入法常打出來的空白，比一般的（半形）空白寬，Unicode 編號是 U+3000。
- 在 `cases.txt` 裡寫全形空白：可以從檔案說明那一行的「　」複製，也可以在引號裡寫 `\u3000`（反斜線 u3000），例如 `"午餐\u3000120元" -> "午餐", 120`。check 會把 `\u3000` 當成全形空白。
- 全形空白要放在**品項和金額中間**。放在前後的話，三個版本都會先用 `strip()` 拿掉（全形的也會拿掉），就抓不到只認半形空白的那個版本：

```
>>> print(" \u3000早餐 65元\u3000".strip().split())
['早餐', '65元']
```

## 5. `.0f` 遇到剛好一半

`{x:,.0f}` 是小數點後面留 0 位，取最接近的整數。剛好一半的時候，實際跑出來跟 1-4 的 `round()` 一樣取偶數（沙盒 Python 3.13.18）：

```
>>> print(f"{2.5:.0f}", f"{3.5:.0f}", f"{1234.5:,.0f}", f"{1235.5:,.0f}")
2 4 1,234 1,236
>>> print(round(2.5), round(3.5))
2 4
```

帳本的錢一律存成整數元（1-3），寫 `{amount:,}` 就夠了；看到 AI 寫 `.0f`，表示它把數字當小數在排。

## 6. 中文字為什麼對不齊

`{item:<6}` 是「補到 6 個字」：Python 照字數補空白（`len("午餐")` 是 2、`len("生日蛋糕")` 是 4，所以一個補 4 格、一個補 2 格）。可是在終端機裡，中文字是寬字元，一個佔兩格（Unicode 的 East Asian Width 把漢字列為 Wide），字數不一樣，後面的欄位就歪了。影片裡熊的 table.py 在終端機跑出來是這樣：

```
午餐       120元
生日蛋糕   1,280元
   120元 午餐
 1,280元 生日蛋糕
```

前兩行品項放前面，「元」沒有對齊；後兩行把數字放前面、中文放最後，就對齊了。這是這一課最簡單的做法；要讓中文在前面也對齊，得照「寬度」而不是「字數」補空白，之後用得到再說。

## 7. 兩個冒號後面寫別的數字（超出這一課，先知道就好）

切片的第三個數字是「每次走幾格」：`d[::5]` 從頭開始每次跳 5 格（索引 0、5），印出 `21`；`d[::-1]` 是倒著一格一格走，整串倒過來。這一課的作業只用 `[::-1]`。
