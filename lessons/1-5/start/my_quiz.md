# 1-5 第②圈：請家教出切片題考你（自評，check 不檢查）

1. 在 0-8 建好的家教專案裡，換一個你自己的字串（例如你的生日 "2010-05-20"），請它出 5 題切片題，先不要給答案。可以照這個寫：
   我剛學了字串的索引和切片。請用 d = "（你的字串）" 出 5 題切片的題目，讓我猜 print 會印出什麼。先不要給答案。
2. 先看題目：有沒有用到這一課還沒教的寫法？有的話，請它先解釋，或換一題。
3. 把你的答案寫給它改。**它改完，你自己用 Python 跑一次**，看它改得對不對。
