## 1. 題目

**第①圈：自己寫（關掉 AI）。**

A. 先猜輸出（`guess.txt`）：8 題，`d = "2026-12-25"`。先不要跑，用眼睛看每一行 `print(…)` 會印出什麼，在「答：」後面寫印出來的樣子。

B. 收據的一行（`receipt.py`）：帳本裡的一行 `" 2026-12-25 聖誕大餐 1280 "`，排成 `12月25日 聖誕大餐 1,280元`。第一步（拆開）已經寫好，把三個 `？` 換掉：切出月和日、用 f-string 印出來，存檔再跑。

**第②圈：判斷家教出的題目。**

A. `ai_quiz.txt`（對答 3 題）：影片裡家教用 `d = "2026-11-07"` 出了 5 題切片，判斷哪一題超出這一課、照它的解釋 `d[::5]` 會印出什麼、它的第一句說得準不準。

B. `my_quiz.md`（自評）：換一個你自己的字串，請 0-8 建好的家教專案出 5 題切片題考你；它改完，你自己用 Python 跑一次，看它改得對不對。影片裡熊跟家教的完整對話在 `補充.md`。

**第③圈：替拆帳機寫案例（`cases.txt`）。** 需求卡：

| 欄 | 內容 |
|---|---|
| 目標 | 把一行「品項 金額」拆成品項和金額 |
| 背景 | 有人打好幾個空白；有人用中文輸入法，打出全形空白；有人沒寫「元」；前後常多了空白 |
| 限制 | 品項是文字，金額是整數；品項中間沒有空白 |
| 怎樣算做完 | 你寫的案例，正確版都拆得對；三個壞版本，各被你抓到 |

AI 照這張需求卡寫了拆帳機 `split_item`（課程凍結的版本：正確版在 `reference/`，三個壞版本在 `mutants/`）。你**不用看懂它的程式**，也先不要看，只寫案例表：每一行左邊是丟進去的那一行（加引號）、右邊是品項（加引號）和金額（整數，不加引號、不寫「元」），用逗號隔開。至少 6 組，三個壞版本都要抓到。

```
"午餐 120元" -> "午餐", 120
```

全形空白不好打：`cases.txt` 的說明裡有一個可以複製，也可以在引號裡寫 `　`（`"午餐　120元"`）。

## 2. 提示

- 索引從 0 開始：`d[0]` 是第一個字。負的從後面數：`d[-1]` 是最後一個字。
- 切片 `d[開始:結束]`：從「開始」那一格拿起，到「結束」那一格**之前**停，結束那一格不拿。`d[5:7]` 只拿索引 5、6。左邊省略是從頭，右邊省略是到尾：`d[:4]`、`d[-2:]`。
- `d[::-1]` 是整串倒過來（兩個冒號後面那個數字是一次走幾格，-1 是倒著一格一格走；這一課只用 -1）。
- `.strip()` 拿掉前後的空白（全形空白也會拿掉），中間的不動。`.split()` 括號裡不寫東西，就用空白拆開：連在一起的好幾個空白算一個，全形空白也認得；`.split(" ")` 括號裡寫一個半形空白，就**只認半形空白**，而且兩個空白中間會拆出空的一段。
- `.replace("元", "")` 把「元」換成空的，也就是拿掉。`.startswith("2026")` 問是不是用 2026 開頭，答案是 `True` 或 `False`。
- f-string：引號前面加 `f`，大括號裡放變數：`f"{month}月{day}日"`。大括號裡冒號後面是格式：`{amount:,}` 加千分位逗號；`{amount:>6}` 靠右、補到 6 個字寬。
- AI 常寫的 `f"{x:,.0f}"`：逗號是千分位，`.0f` 是小數點後面留 0 位（取最接近的整數）。帳本的錢都是整數元，寫 `{amount:,}` 就夠了。
- 中文字在終端機裡佔兩格寬，可是 `{item:<6}` 是照字數補空白，品項字數不一樣，後面就會歪。簡單的做法：數字放前面，中文放最後（細節在 `補充.md`）。

## 5. 怎麼測

`uv run check.py 1-5` 會先問你：「你覺得會過幾題？」先猜一個數字再按 Enter，它才開始檢查。一共 17 題：

- 第一圈：`guess.txt` 8 題、`receipt.py` 印出收據的一行（1 題）
- 第二圈：`ai_quiz.txt` 3 題
- 第三圈：`cases.txt` 至少 6 組、正確版都拆得對、抓到 3 個壞版本

沒過的，它只先告訴你第一個沒過的，修好再跑一次（想一次看全部，最後加 `--all`）。不到 8 分鐘就全對，它會印出提醒：只是提醒，不扣分。`my_quiz.md` 是自評，check 不檢查。
