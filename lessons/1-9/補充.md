https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=542&pid=9737

●BMI＝體重(公斤)÷身高(公尺)÷身高(公尺)

所以：剛好 18.5 算健康體重（18.5 ≤ BMI）、剛好 24 算體重過重（24 ≤ BMI）、剛好 27 算肥胖（BMI ≥ 27）。`bmi_level()` 交回的四種文字照原文：「體重過輕」「健康體重」「體重過重」「肥胖」。**本課只拿它來練程式，不是健康建議**；原文也寫了 BMI 是判定體位常用的簡易方法，不同個案可能有所差異。

### Language Reference 8.1 The if statement（英文原文）

https://docs.python.org/3.13/reference/compound_stmts.html#the-if-statement

```
# https://docs.python.org/3.13/reference/compound_stmts.html#the-if-statement
8.1. The if statement¶
The if statement is used for conditional execution:
if_stmt ::= "if" assignment_expression ":" suite
 ("elif" assignment_expression ":" suite)*
 ["else" ":" suite]
It selects exactly one of the suites by evaluating the expressions one by one
until one is found to be true (see section Boolean operations for the definition of
true and false); then that suite is executed (and no other part of the
if statement is executed or evaluated). If all expressions are
false, the suite of the else clause, if present, is executed.
```

意思：從上往下一個一個算條件，**第一個成立的那一塊才執行**，if 敘述其他的部分都不執行、也不算；全部不成立，才執行 else 那一塊。影片裡「從上往下看，第一個成立的那一條才做，後面的都不看」就是這一段。

## 4. elif 和兩個 if 的差別

把熊的 `elif ratio <= 1:` 改成另一個 `if ratio <= 1:`，花 500 會印出兩個燈（Python 3.13 實跑）：

```python
spent = 500
budget = 1000
ratio = spent / budget
if ratio < 0.8:
    print("綠燈")
if ratio <= 1:
    print("黃燈")
```

```
綠燈
黃燈
```

兩個獨立的 if 會各看各的：0.5 小於 0.8 成立、0.5 小於等於 1 也成立，所以兩行都印。`elif` 只有在前面都不成立時才會看，所以熊的版本只印綠燈。作業的 check 會餵花 500 的那一組，同時印出綠燈和黃燈就不算過。

## 5. 果凍兔的版本：條件都對，順序寫反

果凍兔照「每個燈從哪裡開始」寫（綠燈從 0 開始、黃燈從 0.8 開始、紅燈超過 1），三個條件跟需求的數字都一樣，可是 `ratio >= 0` 寫在最上面：

```python
if ratio >= 0:
    print("綠燈")
elif ratio >= 0.8:
    print("黃燈")
elif ratio > 1:
    print("紅燈")
```

花 500、800、1000、1200 跑出來全部是綠燈（Python 3.13 實跑）。花的錢不會是負數，所以 ratio 一定大於或等於 0，第一條都成立，後面的 elif 永遠輪不到。把三條倒過來、從最大的開始寫，就對了：

```python
if ratio > 1:
    print("紅燈")
elif ratio >= 0.8:
    print("黃燈")
elif ratio >= 0:
    print("綠燈")
```

熊的寫法是從小寫到大（`ratio < 0.8`、`ratio <= 1`、`else`）；花費是零或正數、預算大於零的時候，兩種都對，重點是順序。（如果硬要輸入負數，倒過來的版本什麼都不印、熊的版本印綠燈；這課的需求沒有負數。）第③圈藏的壞版本 3 也是同一種錯：健康體重寫在體重過重前面，體重過重永遠不會出現。

## 6. 選做：特殊作答（影片沒有講）

`checks_bmi.py` 裡，如果你想到某一條連正確版都會當掉（例如 `bmi_level("23")` 傳的是文字，正確版也會 TypeError），在行尾加 `# 已知會當掉`；覺得需求本身沒講清楚（例如 BMI 是 0 或負數，要交回什麼？），加 `# 需求有問題`。標了的不算在 6 條裡，check 會另外對答案。1-3 用過「已知會當掉」；「需求有問題」1-15 會正式練。標了「已知會當掉」的那一行，自己試跑時一定會當掉、後面的 assert 就跑不到了，請放在檔案最後面。
