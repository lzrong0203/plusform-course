# 0-6 補充頁：裝 VS Code，打開你的專案

影片說明欄放不下的東西都在這裡：完整步驟、設定的名字、畫面跟影片不一樣時怎麼辦、Windows 的做法，還有每一個說法的官方出處。影片錄的是 2026 年 11 月的 VS Code 1.146、Python 擴充 2026.10。

## 一、完整步驟（Mac）

1. **裝 VS Code**（官方說明 Install VS Code on macOS）：
   1. 到 VS Code 官方網站下載 Mac 版。
   2. 打開下載好的 `.dmg` 檔。
   3. 把 Visual Studio Code 拖進「應用程式」資料夾。
   4. 在「應用程式」資料夾裡，按兩下 Visual Studio Code 的圖示打開它。
2. **關掉內建的 AI**：按 `⌘,`（Command 加逗號）打開設定，在最上面的搜尋框打 `disable ai`，勾 **Chat: Disable AI Features**。右邊的 Chat 會不見。之後想用，回來把勾拿掉就好。
3. **加入 `code` 指令**：按 `⌘⇧P`（Command、Shift、P）打開命令選擇區，打 `shell command`，選 **Shell Command: Install 'code' command in PATH**。然後把終端機整個關掉，再打開一個新的視窗（跟 0-5 裝好 uv 時一樣，新的視窗才讀得到新的 PATH）。
4. **打開帳本**：在新的終端機打 `cd ~/code/ledger`，再打 `code .`（code、空一格、一個點；點代表現在這個資料夾）。
5. **Trust**：最上面會有一條 Restricted Mode（受限模式）的橫幅。按 **Manage**，在 Workspace Trust 那一頁按 **Trust**。
6. **裝 Python 擴充**：按左邊的方塊圖示（Extensions），搜尋 `python`，裝作者是 **Microsoft**、旁邊有藍色勾勾的 **Python**。它會順便裝好 Pylance、Python Debugger、Python Environments 這幾個官方的擴充。
7. **確認 Python**：在左邊的檔案總管按 `main.py`，看右下角是不是 `ledger (3.13…)`。不是的話，按一下它，選寫著帳本 `.venv` 的那一行。
8. **存檔**：把 `main.py` 第二行引號裡的 `ledger` 改成 `PyPy`，分頁上會多一個圓點（還沒存檔）。按 `⌘S` 存檔，圓點不見。
9. **跑起來**：按 `⌃` 加反引號（Control 加 `` ` ``）打開下面的終端機，打 `uv run main.py`，印出 `Hello from PyPy!`。
10. **自動存檔（選做）**：設定搜尋 `auto save`，**Files: Auto Save** 選 `afterDelay`（改完大約一秒自動存）。

## 二、用到的設定名字

| 設定畫面上的名字 | settings.json 裡的名字 | 這一課設成 |
|---|---|---|
| Chat: Disable AI Features | `chat.disableAIFeatures` | 勾起來（`true`） |
| Files: Auto Save | `files.autoSave` | `afterDelay`（選做；預設 `off`） |
| Files: Auto Save Delay | `files.autoSaveDelay` | 不用改（預設 1000 毫秒） |

## 三、為什麼現在先關掉內建的 AI

VS Code 內建的 AI 會跟你聊天，也會在你打字時直接建議下一段程式。第①圈要練的是你自己寫得出來；它先幫你補完，你就分不出哪些是自己會的。檢核站也要關著做。要跟 AI 學，是第②圈的事，這門課會教你怎麼把 AI 設成只問問題、不給答案的家教（0-8）。

另外，官方說明寫到：AI 功能關掉以後，加入 `code` 指令那一項會維持原本的名字 **Install 'code' command in PATH**，也不會問你要不要裝 Copilot CLI。如果你還沒關 AI，那一項會寫成 Install 'code' and optionally 'copilot' commands in PATH，接著問要不要裝 GitHub Copilot CLI，這一課選 **No**（只加 `code`）。

## 四、你的畫面跟影片不一樣？

- **影片的 VS Code 是瀏覽器版。** 錄影用的是官方的 VS Code Server（在瀏覽器裡跑的 VS Code），介面跟 Mac 桌面版幾乎一樣。差別：桌面版的選單在螢幕最上面（File、Edit…），瀏覽器版在左上角的三條線；設定視窗上方瀏覽器版多一個 Remote 分頁；右下角瀏覽器版多一個「Layout: U.S.」。
- **自動存檔的預設。** 桌面版預設不自動存（`off`），瀏覽器版預設會自動存。影片照桌面版設成 `off` 再示範。
- **終端機前面多一行 `source …/activate`、提示字元前面多一個 `(ledger)`。** 那是 Python 擴充幫你接上帳本的 Python（啟用虛擬環境）。這門課一律用 `uv run`，有沒有它都一樣，不用管。影片為了不露出錄影電腦的路徑，把這個功能關掉了。
- **帳本裡多一個 `.vscode` 資料夾。** 你在右下角選了 Python 以後，VS Code 會把這個選擇記在帳本的 `.vscode/settings.json`，不用管它。
- **終端機打開時有一行淡淡的「Show suggestions ⌃Space…」。** 那是 VS Code 的提示，開始打字就會消失。
- **右下角寫的不是 `ledger (3.13.x)`。** 版本號的寫法會隨 Python 擴充改版；重點是括號裡是 3.13、按下去那一行寫著帳本的 `.venv`。
- **第一次打開 VS Code，Mac 跳出確認視窗。** 從 App Store 以外下載的 app 第一次打開時，Mac 會問你確定要打開嗎（Apple 說明：Safely open apps on your Mac）。確認是從 VS Code 官方網站下載的，就按打開。
- **路徑。** 影片的路徑顯示成示範帳號的 `/Users/bear`，你的會是 `/Users/你的帳號`。

## 五、Windows

- 先看 0-W 第 3 章：裝 VS Code、把內建終端機的預設改成 Git Bash（命令選擇區的 **Terminal: Select Default Profile**）。
- 安裝程式會把 `code` 加進 PATH（官方：Setup adds Visual Studio Code to your %PATH%），裝好以後重開 Git Bash，就能在帳本裡打 `code .`。
- **裝完先關掉 VS Code，從開始選單重新打開**，內建終端機才找得到 uv（0-W 在 Windows 11 虛擬機實測：從安裝程式最後一頁直接開的 VS Code，終端機還是舊的設定）。
- 關 AI、Trust、裝擴充、存檔的按法都一樣，只是 `⌘` 換成 `Ctrl`（存檔 `Ctrl+S`、設定 `Ctrl+,`、命令選擇區 `Ctrl+Shift+P`），終端機一樣是 `` Ctrl+` ``。
- 右下角的 Python 一樣要是帳本的 `.venv`；Windows 的路徑寫成 `.venv\Scripts\python.exe`。
