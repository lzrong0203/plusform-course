# 0-5 用到的概念

0-5 的 doctor.py 是給你**跑**的，不是給你讀的。它的正確版（`reference/`）和壞版本（`mutants/`）只能用到下面這些概念（老師端用 `tools/validate_lesson.py` 檢查）。等到 Lv1 下學完 import 和 pathlib，你會看得懂它每一行。

這些概念都比 0-5 晚才教，所以每一項都標成「例外」：只跑、不讀，畫面上也不講解程式碼。

## 可以用的概念

- 註解（例外：只跑不讀）
- print（例外：只跑不讀）
- 變數（例外：只跑不讀）
- 資料型別（例外：只跑不讀）
- 數字運算（例外：只跑不讀；這裡的 / 是在接路徑）
- 字串操作（例外：只跑不讀）
- 函式呼叫（例外：只跑不讀）
- 比較與邏輯（例外：只跑不讀）
- if（例外：只跑不讀；這裡用的是一行的 if：A if 條件 else B）
- 模組與 import（例外：只跑不讀）
