# 0-5 補充：裝 uv，跑起第一支 Python

影片說明欄放不下的參考資料。作業的完整步驟在同一個資料夾的 [README.md](README.md)。

## 指令小抄（照影片的順序）

1. `xcode-select --install`：裝蘋果的開發工具 Command Line Tools。已經裝過會印 `already installed`，直接往下。
2. `git --version`：印出版本就是裝好了。
3. `curl -LsSf https://astral.sh/uv/install.sh | sh`：uv 官方的安裝指令。從 <https://docs.astral.sh/uv/> 複製，貼上前看網址是不是 `astral.sh`、`https` 開頭。
4. 關掉終端機，再打開一個新的視窗。
5. `uv --version`：印出版本就是找得到了。
6. `cd ~/code/ledger`：進到帳本資料夾。
7. `uv init --no-package --vcs none --python 3.13`：把帳本變成 Python 專案。`--no-package` 用比較簡單的結構；`--vcs none` 先不建 git 存放庫（0-7 再自己建）；`--python 3.13` 指定版本。
8. `uv python pin 3.13`：把版本釘在 3.13，寫進 `.python-version`（電腦上沒有會先下載一份）。
9. `uv run main.py`：印出 `Hello from ledger!`。
10. `uv run python --version`：帳本自己的 Python 3.13。打 `python3 --version` 看到的是跟著開發工具來的系統 Python（影片的電腦是 3.9）。

## 你的畫面跟影片不一樣？

- 提示字元前面是你自己的帳號和電腦名稱（影片是示範用的 `bear@MacBook-Air`），路徑也會是 `/Users/你的帳號`。
- uv、Python、git 的版本號可能比影片新，沒關係。影片用的 uv 0.13.8 是 2026-11-12 發佈的版本。
- `xcode-select --install`：還沒裝過的電腦會跳出一個視窗問要不要安裝，按「安裝」、再按「同意」，等它跑完。影片錄影的電腦已經裝過，所以只印出 `already installed`。
- 剛裝好 uv 就打 `uv --version`，出現 `zsh: command not found: uv`：把終端機整個關掉，再打開一個新的視窗。
- `uv init` 說 `Cannot initialize a project … because pyproject.toml already exists`：帳本已經是專案了，不用再 init，直接往下做。
- `uv run main.py` 出現 `error: Failed to spawn: main.py`：你不在帳本資料夾裡（新開的視窗常常是在家目錄；不確定在哪裡，先打 `pwd` 看位置），先打 `cd ~/code/ledger`。
- 網路上的教學叫你在指令前面加 `sudo`：這門課都不用。uv 裝在你自己的家目錄（`~/.local/bin`），不需要管理員的身分。

## 名詞小抄

| 名詞 | 意思 |
|---|---|
| uv | 幫你裝 Python、跑 Python 的工具 |
| Command Line Tools | 蘋果給的一組開發工具，裡面有 git |
| PATH | 電腦找指令的清單（一串資料夾）；剛裝好的工具找不到，常常是這張清單還沒更新 |
| 專案 | uv 認得的程式資料夾（有自己的設定 `pyproject.toml`） |
| 虛擬環境（`.venv`） | 帳本自己的一份 Python，跟電腦的其他地方隔開 |
| 系統 Python | 跟著開發工具（Command Line Tools）安裝的那一份 Python（影片的電腦是 3.9.6），這門課不用它，也不去動它 |
| https | 網址開頭的 s 代表連線有加密 |
| agent | 會自己在電腦上動手的 AI |

## Windows 的同學

先看〈0-W　Windows 同學先看：裝好 Git Bash、uv、VS Code〉第 2 章，裝好 uv。

- 不用裝 Command Line Tools（`xcode-select` 只有 Mac 有）。git 已經跟著 Git for Windows 裝好，直接打 `git --version` 確認。
- uv 官方網站給 Windows 的是 PowerShell 指令：`powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`（一樣先對照網址是不是 `astral.sh`）。裝好以後關掉視窗、開一個新的 Git Bash，再打 `uv --version`。
- Git Bash 找不到 uv 時寫的是 `bash: uv: command not found`，意思一樣。
- 打 `python` 跳出 Microsoft Store：不用裝，這門課一律打 `uv run`（例如 `uv run main.py`）。
- ZIP 用右鍵「解壓縮全部」，有時候會多包一層：`plusform-course-main` 裡面還有一個 `plusform-course-main`，打開來直接看到 `check.py`、`lessons` 的那一層才是要搬的。
- 作答檔用記事本打開：`notepad ~/code/ledger/lessons/0-5/error_match.txt`
- 其他步驟（`cd`、`uv init`、`uv python pin`、`uv run`、`check.py`）在 Git Bash 照打。
