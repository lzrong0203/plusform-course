## 1. 為什麼 csv 不怕逗號

CSV 的規則是：一格裡有逗號、雙引號或換行，整格用雙引號包起來；格子裡的雙引號寫兩次（`""`）。csv 模組存的時候照這個規則寫，讀的時候照這個規則拆，所以「跟小明, 小華」存進去、讀回來還是同一格。1-23 用 `f.write(f"{d},{item},{amount},{note}\n")` 自己接、用 `split(",")` 自己切，就沒有這一層保護。

官方文件（docs.python.org，csv 模組）：

- If csvfile is a file object, it should be opened with newline=''.
- If newline='' is not specified, newlines embedded inside quoted fields will not be interpreted correctly, and on platforms that use \r\n line endings on write an extra \r will be added.
- DictReader：Create an object that operates like a regular reader but maps the information in each row to a dict whose keys are given by the optional fieldnames parameter. If fieldnames is omitted, the values in the first row of file f will be used as the fieldnames.

## 2. JSON 的 ensure_ascii

官方文件（json 模組）：If ensure_ascii is true (the default), the output is guaranteed to have all incoming non-ASCII and non-printable characters escaped. If ensure_ascii is false, all characters will be output as-is.

## 3. BOM 與 utf-8-sig

官方文件（codecs 模組）：On encoding the utf-8-sig codec will write 0xef, 0xbb, 0xbf as the first three bytes to the file. On decoding utf-8-sig will skip those three bytes if they appear as the first three bytes in the file.

## 4. re 的兩個符號

官方文件（re 模組）：

- `\d`：Matches any Unicode decimal digit（也包含全形數字這類別的數字字元；這課的對帳單只有 0–9）。
- `\D`：Matches any character which is not a decimal digit. This is the opposite of \d.
- `re.fullmatch`：If the whole string matches the regular expression pattern, return a corresponding Match. Return None if the string does not match the pattern.

## 5b. 影片裡 Copilot agent 實際寫的 import_bank.py

2026-11-21 用 GitHub 示範帳號錄的（VS Code 網頁版、Copilot Chat 的 Agent、Local）。它先讀了樣本、測試、clean.py、settings.json，還有資料夾裡課程固定的 ai_import_bank.py，自己指出那份會把金額的負號丟掉，所以 _parse_amount 只拿掉千分位的逗號。uv run pytest lessons/2-4 是 2 passed。每次交辦，它寫的都會不一樣，你拿到的版本一樣要用自己手算的 test_totals 驗收。

```python
import csv
import re


DATE_COLS = ("交易日期", "消費日")
ITEM_COLS = ("摘要", "說明")
AMOUNT_COLS = ("金額", "交易金額")


def _find(row, names):
    for name in names:
        if name in row:
            return row[name]
    raise KeyError(f"找不到欄位：{names}")


def _parse_date(text):
    match = re.fullmatch(r"(\d{2,3})/(\d{1,2})/(\d{1,2})", text.strip())
    if match is None:
        raise ValueError(f"日期格式不對：{text}")
    year, month, day = map(int, match.groups())
    return f"{year + 1911}/{month:02d}/{day:02d}"


def _parse_amount(text):
    return int(text.strip().replace(",", ""))


def _category(item, keywords):
    for word, category in keywords.items():
        if word in item:
            return category
    return "其他"


def import_statement(path, keywords):
    entries = []
    with open(path, encoding="utf-8-sig", newline="") as statement:
        for row in csv.DictReader(statement):
            date = _find(row, DATE_COLS)
            if not date or not date.strip():
                continue
            item = _find(row, ITEM_COLS).strip()
            amount = _parse_amount(_find(row, AMOUNT_COLS))
            entries.append(
                (_parse_date(date), item, _category(item, keywords), amount)
            )
    return entries


def category_totals(entries):
    totals = {}
    for _date, _item, category, amount in entries:
        totals[category] = totals.get(category, 0) + amount
    return totals
```
