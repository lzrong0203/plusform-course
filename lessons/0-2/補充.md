# 0-2　程式是什麼：補充（影片說明欄放不下的部分）

影片：AI 時代的 Python 零基礎課 0-2〈程式是什麼〉（連結上架時補）。這一課不用電腦，只要一張紙和一支筆，沒有要下載的作業檔；題目、例子、自評和兩段 AI 回答的完整紀錄都在這一頁。

用 Windows 的同學：這一課不用電腦，照 0-1 → 0-2 → 0-3 → 0-W → 0-4 的順序就好。

## 桌上有什麼（暖身寫步驟用）

一碗泡麵（還沒打開）、一包調味包（放在碗旁邊）、熱水壺（裡面的水剛煮滾）、水龍頭、一雙筷子。

## 熊一開始寫的五條（先自己寫完再看）

1. 打開泡麵
2. 加調味包
3. 加水
4. 等三分鐘
5. 端給熊

## 每一條，問自己三個問題

- 要做什麼動作？（例：調味包要撕開，把粉倒進碗裡）
- 用的是哪一個？（例：用熱水壺裡剛煮滾的水）
- 做到哪裡停？（例：倒到碗裡面那條線就停）

三個問題都答得出來的那一條（例如「端給熊」：動作是端、用的是那碗泡麵、端到熊面前就停），就不用改；用不上的問題就跳過（例如「等三分鐘」沒有「用哪一個」），答不出來的才要改。標的時候畫圈、打問號都可以。

寫到多細才夠？寫到照做的人不會做錯就夠了。

## 常藏著模糊的詞

一點（是多少？）、一下（是多久？）、適量（是多少？）、弄好（是什麼樣子？）。看到這些詞，就換成數字，或看得到的樣子。

## 作業（大約 20 分鐘）

**作業一**：把你暫停時寫的泡麵步驟改寫完，再列出你找到的模糊的地方（一個寫一條）。

**作業二**：換一件生活小事寫步驟，例如刷牙、泡一杯茶、摺一件衣服。寫好以後，請家人或朋友只照你寫的字做一次，對方做錯、或做得怪怪的地方，就是模糊的地方。（例：寫「擠牙膏」，對方可能擠了一整條。）

## 第②圈的 AI 家教（實際錄影）

2026-11-13 用示範帳號在 Claude 網頁版（https://claude.ai）錄的：一般聊天、網頁版預設的模型（Sonnet 5.5）、記憶功能關閉（帳號設定裡的 Generate memory from chats 關掉，每一段都開新的對話），沒有其他特別的設定。畫面上的貼上和打字是程式送出的，不是真人手打。

影片裡只放貼上和送出的畫面，家教的問題整理在步驟旁邊：每一條放一到兩個最關鍵的問題，照原文縮短，不加不改意思。

送出了兩次：第一次輸入框裡留著測試時的字，那一句黏在第 5 條裡送出去（變成「5. 請用問題…不要幫我改寫。端給熊」），跟要示範的提問不一樣，所以重錄一次；影片用的是第二次。第一次的回答沒有用在影片裡。

熊送出的字（逐字）：

```
1. 打開泡麵
2. 加調味包
3. 加水
4. 等三分鐘
5. 端給熊
請用問題標出我的步驟裡模糊的地方，不要幫我改寫。
```

家教的完整回答（逐字，網頁上的條列照原樣）：

> 以下是我在你的步驟裡看到的模糊之處，我只用問題標出，沒有改寫：
>
> 步驟 1：打開泡麵
> - 要打開到什麼程度？是只掀開一部分蓋子，還是整個撕掉？
> - 麵碗的蓋子要不要先留著，之後拿來悶？
>
> 步驟 2：加調味包
> - 有幾包？全部都加，還是只加其中幾包？
> - 要先拆開調味包再倒，還是整包丟進去？
> - 加在麵上面還是麵下面？
>
> 步驟 3：加水
> - 加的是熱水還是冷水？水要先煮滾嗎？
> - 加多少水？加到哪裡為止（例如碗內的水位線）？
> - 水從哪裡來？誰去準備？
>
> 步驟 4：等三分鐘
> - 從什麼時候開始算？是水加完的那一刻，還是蓋上蓋子之後？
> - 等的時候要不要蓋蓋子？
> - 三分鐘是精確要求，還是大概就好？
>
> 步驟 5：端給熊
> - 熊指的是誰？是真的熊、玩偶，還是某個人的暱稱？
> - 要不要先攪拌或確認溫度，免得太燙？
> - 端到哪裡？要不要附筷子或叉子？
>
> 整體順序的問題
> - 步驟 2 和步驟 3 的順序是刻意的嗎？先加調味包再加水，和先加水再加調味包有差別嗎？
> - 整個流程有沒有前提條件，例如需要先準備好熱水或餐具？

## 第③圈的 AI 畫面（實際錄影）

同一天、另開一個新的對話，熊只打了「幫我把下面的步驟整理成清單」再貼上六條。只送出一次。回答出到一半，網頁跳出升級方案的視窗蓋住畫面，關掉以後，影片接上同一個回答完整的畫面（回答的字沒有改、沒有重問）。

熊送出的字（逐字）：

```
幫我把下面的步驟整理成清單：
1. 把碗蓋掀開一半
2. 撕開調味包，把粉倒進碗裡
3. 拿熱水壺，把剛煮滾的水倒進碗裡
4. 倒到碗裡面那條線就停
5. 蓋上碗蓋，蓋好再等三分鐘
6. 端給熊
```

AI 的完整回答（逐字；逗號、冒號照原樣是半形，影片卡片右欄也照這樣抄）：

```
以下是整理後的清單:
1. 把碗蓋掀開一半
2. 撕開調味包,把粉倒進碗裡
3. 拿熱水壺,把剛煮滾的水倒進碗裡
4. 倒到碗內的水位線就停
5. 蓋上碗蓋,等三分鐘
6. 端給熊
小提醒:第 3 步倒熱水時要小心燙傷,也別讓熊等太久,麵會糊掉喔 🐻
```

**怎麼對**：換個說法、意思一樣，不算（像「碗裡面那條線」寫成「碗內的水位線」、「蓋好再等三分鐘」寫成「等三分鐘」）；多了一個動作、少了一個細節，才算。這次多了最後那段小提醒，熊寫的六條都找得到。同一句話問不同的 AI、或同一個 AI 問第二次，回答都可能不一樣，所以每次交回來都要一條一條對。
