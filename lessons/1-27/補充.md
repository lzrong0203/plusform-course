## 2. 第一部分怎麼判（20 題：讀程式 14、手寫 6）

- **追蹤 `trace.txt`（6 題）**：寫印出來的樣子。一行印好幾個值的，值和值中間要空一格（`350 80` 跟 `35080` 不一樣）。

- **手寫 `ledger_v1.py`（6 題）**：前五題用課程準備的小程式載入你的檔、在系統的暫存資料夾另外擺資料試（你帳本裡的檔一個都不動）：

  - `to_yuan` 不合法的三種：`八十`（int 自己會丟 ValueError，不要接住）、`0`、`-35元`，都要丟 ValueError，錯誤訊息裡要有打進來的字。

## 3. 第二部分：評分量表與範例講解

挑一個你自己寫的函式（建議 `load` 或 `to_yuan`），講給別人聽，大約 3 分鐘。用手機錄音或寫成文字都可以；聽的人可以是家人、朋友，或只是錄給自己聽。講完照下面五項，替自己每一項打 0、1 或 2 分，寫進 `explain.md`。check 只看寫了沒，不改對錯，也不擋升級。

| 項目 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 1. 它收什麼、交回什麼 | 講出每一個參數是什麼、交回什麼型別的什麼 | 只講了其中一半 | 沒講 |
| 2. 照執行的順序，一行一行講 | 每一行都講到，順序對 | 跳過幾行，或有一行講錯 | 只講大概 |
| 3. 舉一個例子，算出交回什麼 | 自己挑一個輸入，一步一步算出交回的值，算對 | 有例子，可是沒算完或算錯 | 沒有例子 |
| 4. 一個特別的情況會怎樣 | 講出一種特別的輸入（空的、0、不合法、檔案不存在）會怎樣，而且對 | 講了，可是不確定、或講錯 | 沒講 |
| 5. 為什麼這樣寫 | 講出某一行為什麼要這樣寫，或換一種寫法會怎樣 | 講得含糊 | 沒講 |

講不出來的那一項，回去看程式、改一個數字跑一次，再講一次。

### 範例講解：熊講 showcase 的 ask_category（0-1 那支記帳程式，不是你的作業）

```python
119  def ask_category() -> str:
120      for number, name in enumerate(CATEGORIES, start=1):
121          print(f"  {number}. {name}")
122      choice = input("分類（輸入編號）：").strip()
123      if choice.isdigit() and 1 <= int(choice) <= len(CATEGORIES):
124          return CATEGORIES[int(choice) - 1]
125      print("  沒有這個編號，先放進「其他」。")
126      return "其他"
```

1. **收什麼、交回什麼**：`ask_category` 不收東西（括號裡是空的），交回一個分類的名字，是文字（`-> str`）。
2. **一行一行**：第 120–121 行用 `enumerate(CATEGORIES, start=1)` 把五種分類從 1 開始編號，一行印一個。第 122 行用 input 問編號，`strip()` 拿掉頭尾的空白。第 123 行看兩件事：`choice.isdigit()` 是不是數字，而且 `1 <= int(choice) <= len(CATEGORIES)` 在 1 到 5 之間，兩個都成立才進去。第 124 行交回 `CATEGORIES[int(choice) - 1]`：編號從 1 開始、索引從 0 開始，所以要減 1（1-26 刪錯一筆的就是這種差一）。第 125–126 行，前面不成立的話，印出「沒有這個編號，先放進「其他」。」，交回「其他」。
3. **例子**：打 2，`int("2") - 1` 是 1，`CATEGORIES[1]` 是「交通」，交回「交通」。
4. **特別的情況**：打 6（沒有第 6 種），第 123 行的範圍不成立，走到最後交回「其他」，不會當掉；打 abc，`isdigit()` 是 False，也交回「其他」。
5. **為什麼這樣寫**：先檢查是不是數字，`int()` 才不會遇到 abc 丟出 ValueError；`and` 左邊不成立就不看右邊（1-8 的短路求值），所以 abc 根本不會跑到 `int(choice)`。先檢查範圍，才不會去拿不存在的第 6 種（少了範圍檢查，打 6 會跳出 IndexError）。

這份範例五項都講到、也講對，照量表是 10 分。你講自己的函式時，不用照這個長度，五項都講到就好。

## 4. 第三部分：每月預算設定

需求卡（README 第 1 節有完整的一張）：`set_budget(budgets, month, text)` 設定某個月的預算，記進 budgets（`{月份: 預算}`），交回設定好的金額；月份寫成「年-月」（例如 `2026-11`），月要在 01 到 12；金額拿掉逗號和「元」以後要大於 0，存成整數；不合法丟 ValueError，budgets 不能被改到；同一個月再設一次，蓋掉舊的。

- **`budget.py`**：用自己的話把需求寫成 docstring，四個標籤（輸入、輸出、規則、例子）後面都要寫，例子要是一次真的呼叫（例如 `set_budget(b, "2026-11", "8,000元")` 交回 8000）。函式內容不用寫。
- **`budget_ai.py`**：AI 照需求交回來的版本（課程準備的固定版本，範例示意）。不要改它；它不一定對，收不收由你的檢查決定。
- **`checks_budget.py`**：寫至少 5 條（起點檔的範例算一條）。check 拿你的檢查去跑課程的正確版（要全部成立）和三個藏起來的壞版本（每一個至少一條不成立）。寫滿 5 條以後，溜過去的那一個，check 會說是哪一種情況。
- **「應該丟出 ValueError」怎麼寫**：照 1-22，用 try 寫，最外層的一個 try 整個算一條：

```python
try:
    set_budget(b, ……)
except ValueError:
    pass
else:
    assert False, "……應該丟 ValueError"
```

需求卡上的每一條規則都想一條檢查：不只看交回的值，也看 budgets 裡存了什麼、不合法的時候有沒有被改到。

## 8. 升級的天數怎麼算

練習天數是「跑過課號檢查、或答過回顧題的不同日子」，同一天做再多也只算一天（跟 0-C、1-12 同一個算法）。第一級下半要滿 14 天。第一、三部分都過了、天數還不夠，check 會說還要練幾天。升級看的是關卡過了沒、練了幾天，不看你看了幾支影片。

## 9. 為什麼考前要先猜分數

開始時猜一次、交卷時再猜一次，對完答案看猜的跟實際一不一樣，都記進校準曲線（`uv run check.py status`）。有一個研究請 246 個人用 AI 解 20 題邏輯題，大家估自己的表現，平均比實際高了 4 分（Fernandes 等人，原文：participants overestimated their performance by four points）。做完了，也可能把自己估得太高；所以這一關先關掉 AI，自己做、自己估，再對答案。這門課不保證越估越準。
