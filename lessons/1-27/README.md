## 1. 題目

**開始前先寫下預測分數。** `uv run check.py start 1-27` 會問你：考卷一共 20 題，你覺得會過幾題。交卷時它會再問一次（考前預測、考後估分）。

**第一部分：考卷（全程關掉 AI）。** VS Code 的 AI 功能 0-6 已經關了；聊天的 AI 和 0-8 設好的家教，考卷這一段也先不開。卡住了不問 AI，不會的題目寫你覺得最可能的答案。參考 60 分鐘，check 會照檔案時間記下你花了多久，**只記錄、不擋你**。作答檔五個，都在帳本的 `lessons/1-27/`：

- `plain.txt`（讀程式，3 題）：三小段 AI 很愛寫的程式，選出哪一句白話說得對（A、B 或 C）。

**第二部分：v1.0 講解（交卷以後才做，自評，不擋升級）。** 第一部分交卷以後，`explain.md` 才會放進帳本。先把 `ledger_v1.py` 改到 check 全過（交卷以後再打是訂正），那就是你的帳本 v1.0。從裡面挑一個你自己寫的函式（建議 `load` 或 `to_yuan`），講給別人聽，大約 3 分鐘：用手機錄音、或寫成文字都可以。講之前先看補充.md 的評分量表（五項，每項 0–2 分）和範例講解（熊講 showcase 的 `ask_category`）。講完照量表自己打分數，寫進 `explain.md`。check 只看你寫了沒，不改對錯。

**第三部分：每月預算設定（交卷以後才做）。** 一樣交卷以後，`budget.py`、`budget_ai.py`、`checks_budget.py` 會放進帳本。需求卡：

| 欄 | 內容 |
|---|---|
| 目標 | `set_budget(budgets, month, text)`：設定某個月的預算，記進 budgets（`{月份: 預算}`），交回設定好的金額 |
| 輸入 | budgets 是一個 dict；month 寫成「年-月」，例如 `"2026-11"`；text 是打進來的金額，例如 `"8,000元"` |
| 規則 | 月份要像 2026-11（四位數的年、兩位數的月），月要在 01 到 12；金額拿掉逗號和「元」以後要大於 0；存進去的是整數 |
| 不合法 | 月份或金額不合法：丟 ValueError，budgets 不能被改到 |
| 例子 | `set_budget(b, "2026-11", "8,000元")` 交回 8000，b 變成 `{"2026-11": 8000}`；同一個月再設一次，蓋掉舊的 |
| 怎樣算做完 | budget.py 的 docstring 寫了輸入、輸出、規則、例子；你的 assert 在正確版上全部成立，課程藏的 3 個壞版本每一個都至少有一條不成立 |

先在 `budget.py` 用你自己的話把需求寫成 docstring（1-18 起的寫法）。函式內容不用寫：`budget_ai.py` 是 AI 照需求交回來的版本（課程準備的固定版本，不要改它）。再在 `checks_budget.py` 寫 assert 驗收它，至少 5 條（起點檔的範例算一條）；「應該丟出 ValueError」照 1-22 的寫法用 try 寫。課程不給你看壞版本的程式；寫滿 5 條以後，check 會說溜過去的是哪一種情況。

**最後：回頭看 0-1。** 拿出 0-1 寫的「我現在會什麼」自評表，照補充.md 的對照表，一題一題跟這一級的檢查成績比，看看當初估得準不準（只給自己看，check 不看）。再打開 `showcase/ledger_app.py`，從第 129 行的 `cmd_add` 開始一行一行講給自己聽，講到它打「一百元」為什麼會當掉。

## 2. 提示

- **參照**：`b = a` 不是複製，是同一個 list 或 dict 多一個名字；要另一個用 `copy()`（1-16）。預設值 `[]` 只做一次，每次呼叫共用（1-19）。
- **推導式**：先看 for、再看 if、最後看最前面放進去的是什麼；`zip` 配成一對對（1-17）。`sorted(…, key=lambda p: p[1])` 照每一個的第二個排，`reverse=True` 大的在前（1-20）。`any` 只要有一個成立、`all` 每一個都要成立。
- **例外**：try 裡出錯，後面的跳過，跳到對得上的 except；`raise ValueError(…)` 把錯丟出去，訊息寫清楚（1-22）。
- **檔案**：`with open(路徑, "w", encoding="utf-8")` 是整個重寫，`"a"` 是接在後面；讀的時候一行一行拿，`rstrip("\n")` 拿掉換行（1-23）。
- **@dataclass**：`@dataclass` 下面寫 `class Entry:`，欄位一行一個 `名字: 型別`（1-24）。
- **找 bug**：先照註解說應該印什麼，再一行一行追「實際會發生什麼」，兩邊不一樣的那一行就是 bug（1-25、1-26）。
- **第三部分**：需求卡的每一條規則想一條檢查；不只看交回的值，也看 budgets 裡存了什麼。
- 不會的也要寫：考卷有題目空着，check 不讓你交卷（真的寫不出來，加 `--submit` 照樣交卷）。

## 5. 怎麼測

考卷五個檔都寫好，回到課程資料夾打 `uv run check.py 1-27`，這就是**交卷**。一共 20 題：

- 讀程式 14 題：`trace.txt` 6 題、`plain.txt` 3 題（對答）、`parsons.py` 2 題（每一行都用上、縮排對；跑出來跟題目一樣）、`fix.py` 3 題（第一行是 11 月共 3 筆；第二行跟第一行一樣；最大的一筆對）
- 手寫 6 題：`ledger_v1.py`。前五題用課程準備的小程式載入你的檔、另外擺資料試（`to_yuan` 寫得對的四種、不合法的三種、`load`、`save`、`totals`）；最後一題整支跑起來：記兩筆（中間打錯一次金額）、分類加總、q 存檔，看 `ledger_v1.txt` 存了什麼。都在系統的暫存資料夾裡跑，不動你帳本裡的檔案。

**第一次交卷就過 16 題以上，第一部分就過了。** 成績只照第一次交卷算：交卷以後再打 `uv run check.py 1-27` 是訂正，可以看自己改對了沒（加 `--all` 看全部），但不改成績。還有題目空着，check 不算交卷。開始前猜的、交卷時猜的、實際過了幾題，都記進校準曲線（`uv run check.py status`）。

**沒過：領矯正包，隔天以後考卷 B。** 交卷沒過，check 把矯正包寫進帳本的 `lessons/1-27/矯正包.md`：錯了哪幾題、正確答案和為什麼、要回哪一課影片的哪個時間看、要做哪一個練習（練習檔複製到 `lessons/1-27/practice/`）。過了也一樣會寫錯的那幾題。練完，**隔天以後**打 `uv run check.py start 1-27B`。卷 B 的題目不一樣，考的東西一樣（作答檔在帳本的 `lessons/1-27B/`，交卷打 `uv run check.py 1-27B`），第一次交卷過 16 題以上，第一部分一樣算過。

**第二、三部分：** 第一部分交卷以後（過不過都一樣），`explain.md`、`budget.py`、`budget_ai.py`、`checks_budget.py` 會放進帳本。做完再打 `uv run check.py 1-27`（考過卷 B 的打 `1-27B` 也可以），它會看第二部分寫了沒、第三部分的 docstring 和抓到幾個壞版本，再告訴你升級還差什麼。不限次數，改到全過為止；全過的日期記下來以後，之後再改也不會倒退。

## 6. 怎麼交

不用交給任何人：在課程資料夾打 `uv run check.py 1-27`，成績和升級都記在你帳本的 `.check/` 裡。`uv run check.py status` 看得到三部分各自過關的日期，升級了會寫「已升級」。

關卡不擋你往下上課：沒過的時候，矯正包、卷 B 可以跟第 2 級一起進行。YouTube 沒辦法監考，這一關是給你校準自己用的，關掉 AI 自己考，分數才有意義。
