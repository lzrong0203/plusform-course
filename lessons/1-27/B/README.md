## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-27B` 會問你），交卷時再問一次。一共 20 題，第一次交卷過 16 題以上算過：

- `trace.txt`（讀程式，6 題）：三段程式，用眼睛追，寫出印出什麼。
- `plain.txt`（讀程式，3 題）：選出哪一句白話說得對。
- `parsons.py`（讀程式，2 題）：拼圖，十一行排回去、自己縮排。
- `fix.py`（讀程式，3 題）：熊的 12 月月報，跑得起來，可是有三個 bug。
- `ledger_v1.py`（手寫，6 題）：帳本 v1.0，這一版會記「誰付的」：`Entry` 四個欄位是 date、item、amount、payer；自己寫 `Entry`、`to_yuan`、`load`、`save`、`by_payer`（每個人付了多少）。最下面的選單 `main()` 課程寫好了。

## 2. 提示

跟卷 A 一樣：`b = a` 是同一個盒子、要另一個用 `copy()`；推導式先看 for、再看 if；`sorted` 的 key 照哪一部分排、沒寫 `reverse` 是小的在前；`all` 每一個都要成立；`"a"` 是接在後面；try 裡出錯跳到 except；預設值 `[]` 只做一次；「有出現」（`in`）和「開頭是」（`startswith`）不一樣。卡住了回矯正包寫的那幾段影片，不問 AI。
