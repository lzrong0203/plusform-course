# 1-7 第②圈：照四樣東西問家教（自評，check 不檢查）

1. 拿你這一課修 p1～p8 時看到的錯誤訊息，或你自己的程式當掉時的錯誤訊息。
2. 照下面四樣，寫成一則訊息貼給 0-8 建好的家教專案（不要貼密碼、個資、真實帳單）：
   - 出事的程式（貼出事的那幾行就好）
   - 完整的錯誤訊息（從 Traceback 那一行貼到最後一行）
   - 我猜的原因（猜錯也沒關係）
   - 我試過什麼（改了哪裡、結果有沒有變）
3. 照它的回答自己想、自己改、自己跑一次。它說的話，能對到錯誤訊息的哪一段，再相信。

|---|---|---|---|---|
