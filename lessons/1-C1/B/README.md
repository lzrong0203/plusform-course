# 1-C1　檢核站 1　卷 B（關掉 AI，20 分鐘）

卷 A 交卷沒過的同學，照矯正包練完以後，**隔天以後**考這一份。題目跟卷 A 不一樣，每一題考的東西跟卷 A 同一題一樣（1-1～1-4：print 與註解、變數、資料型別、數字運算）。全程關掉 AI；參考時間 20 分鐘，只記錄、不擋你。說明照卷 A 的 [README](../README.md)，這裡只寫不一樣的地方。

## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-C1B` 會問你），交卷時再問一次。

**第一部分：追蹤（`trace.txt`，6 題）。** 三段程式，先不要跑，用眼睛追，在「答：」後面寫答案。

**第二部分：修好（`fix.py`，2 題）。** 修好以後要印出註解寫的兩行，每一行的字要跟註解一樣（多打的空格、空白的行不算錯）。

**第三部分：手寫（`write.py`，2 題）。** 照註解的題目從零寫，第一行程式碼（註解不算）一定要寫 `total = 2350`（check 會把它換成別的金額再跑一次）。

## 2. 提示

跟卷 A 一樣：註解不跑、等號右邊先算、沒有等號的那一行不改任何名字；`sep`、`end`、`print()`；`/` 一定是小數、`//` 向下取整（兩邊都是整數時，結果是整數）、`%` 是餘數、先乘除後加減；錯誤訊息從最下面一行看起。卡住了回矯正包寫的那幾段影片，不問 AI。

## 3. 開始前要打的指令

卷 A 交卷的隔天以後，在課程資料夾打：

```bash
cd ~/code/plusform-course
uv run check.py start 1-C1B
```

作答檔在帳本的 `lessons/1-C1B/`：`trace.txt`、`fix.py`、`write.py`。跑程式在帳本資料夾打 `uv run lessons/1-C1B/fix.py`、`uv run lessons/1-C1B/write.py`。

## 4. 成品示範

修好的 `fix.py` 印出：

```
一共 245 元
平均 81 元
```

`write.py` 印出三行：`每人 ？ 元`、`零頭 ？ 元`、`驗算 2350`。

## 5. 怎麼測

三部分都寫好，打 `uv run check.py 1-C1B` 交卷。一共 10 題，第一次交卷過 8 題以上，檢核站 1 就算過了；之後再打是訂正，不改成績。沒過的話，矯正包寫在帳本的 `lessons/1-C1B/矯正包.md`。

## 6. 怎麼交

不用交給任何人，成績記在帳本的 `.check/` 裡。兩份卷都交過以後，照矯正包把那幾段再看一次、練習做完；檢核站不擋你往下上課。
