# 1-C1 檢核站 1：補充

影片和 [README](README.md) 放不下的細節：這一站怎麼判分、卡住了回哪一課看、矯正包和卷 B 怎麼用、為什麼考前要先猜分數、Windows 的做法。

## 1. 這一站怎麼運作

- **考什麼**：只考 1-1～1-4（print 與註解、變數、資料型別、數字運算），三部分一共 10 題：追蹤 6 題（`trace.txt`）、修好 2 題（`fix.py`）、手寫 2 題（`write.py`）。
- **全程關掉 AI**：VS Code 的 AI 功能 0-6 關了；聊天的 AI 和 0-8 設好的家教，這一站也先不開。
- **開始**：`uv run check.py start 1-C1`。它把三個作答檔複製到帳本的 `lessons/1-C1/`，再問你「一共 10 題，你覺得會過幾題」。
- **交卷**：三部分都寫好，打 `uv run check.py 1-C1`。它會再問你一次猜幾題，然後對答案。**第一次交卷就過 8 題以上，這一站就過了。**
- **還沒寫完不算交卷**：還有「答：」空著、`fix.py` 沒改、`write.py` 一行程式都沒有，check 會列出來，這次不算交卷。不會的也寫一個你覺得最可能的答案；真的寫不出來，加 `--submit` 照樣交卷。
- **交卷以後再打是訂正**：可以看自己改對了沒（平常只顯示第一個沒過的，加 `--all` 看全部），成績還是照第一次交卷算。
- **20 分鐘只記錄**：check 照「打 start 的時間」到「三個作答檔最後一次存檔的時間」算你花了多久，印出來給你參考，超過也不扣分、不擋你。
- **不擋你往下上課**：過了沒過，都可以接着上 1-5。

## 2. 第三部分為什麼要換金額再跑一次

題目規定第一行寫 `total = 1730`。對答案時，check 會把這一行換成 `total = 2026`，在暫存資料夾另外跑一次（不會改到你的檔），看印出來的有沒有跟着變。

- 用 `total` 算出來的（`each = total // 7`），換了金額也會對。
- 直接把答案寫進去的（`print("每天", 247, "元")`），金額一換就不對：第一題會過，第二題不會過。

`total=1730`、`total = 1730  # 這週的零用錢` 這種寫法都認得；名字換成別的（例如 `money = 1730`）就找不到那一行。

## 4. 矯正包怎麼用

交卷沒過（或過了但有錯的題目），check 會寫一份 `矯正包.md` 到帳本的 `lessons/1-C1/`（卷 B 的寫在 `lessons/1-C1B/`）。照順序做：

1. **錯在哪裡**：每一題你寫了什麼、正確答案和為什麼；程式題附 check 的說明（應該印出什麼、你的印出）。
2. **回原課看那一段**：照上面那張表的時間碼，看那一章。
3. **做練習**：每個練習檔最上面寫着怎麼做。猜輸出的先在紙上寫下來，再用 `uv run` 跑一次對答案；壞掉的程式先跑、從錯誤訊息最下面一行看起，修好再跑。
4. **隔天以後考卷 B**：`uv run check.py start 1-C1B`。

練習的時候一樣關掉 AI。

## 5. 卷 B

- 卷 A 交卷的**隔天以後**才能開始（同一天打 `start 1-C1B`，它會請你明天再來）。
- 題目不一樣，每一題考的東西跟卷 A 同一題一樣（例如第 2 題都是「註解、end、print() 一共印出幾行」）。
- 作答檔在帳本的 `lessons/1-C1B/`，交卷打 `uv run check.py 1-C1B`。第一次交卷過 8 題以上，檢核站 1 一樣算過。
- 卷 B 也沒過：照它的矯正包把那幾段再看一次、練習做完，再接着上課。卷 A 就過了的人，卷 B 不用考（想多練一次也可以）。
- 卷 B 由 AI 照卷 A 的概念清單出題，答案都用 Python 3.13 實際跑過。

## 6. 為什麼考前要先猜分數

開始時猜一次、交卷時再猜一次，對完答案看差多少。兩次猜的和實際過了幾題，都記進校準曲線（`uv run check.py status`）；差太多時，check 會請你寫一句「下次我會怎麼估」。

有一個研究請 246 個人用 AI 解 20 題邏輯題（美國法學院入學考試的題目），大家估自己的表現，平均比實際高了 4 分（Fernandes 等人，原文：participants overestimated their performance by four points）。做完了，也可能把自己估得太高；所以這一站先關掉 AI，自己做、自己估，再對答案。這門課不保證越估越準，曲線只是讓你看到自己估得準不準。

## 7. Windows

指令都在 Git Bash 照打，跟 Mac 一樣；VS Code 裡 ⌘ 換成 Ctrl。check.py 自己跑你的程式、自己算時間，Mac 和 Windows 一樣。
