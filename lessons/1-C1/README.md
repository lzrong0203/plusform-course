# 1-C1　檢核站 1（關掉 AI，20 分鐘）

這一站確認 1-1～1-4（print 與註解、變數、資料型別、數字運算）你不靠 AI 也會。**全程關掉 AI**：VS Code 的 AI 功能 0-6 已經關了；聊天的 AI 和 0-8 設好的家教，這一站也先不開。卡住了不問 AI，不會的題目寫你覺得最可能的答案。Windows 同學：指令在 Git Bash 照打，⌘ 換成 Ctrl。

參考時間 20 分鐘：check 會照檔案時間記下你花了多久，**只記錄、不擋你**。檢核站也不擋你往下上課，沒過照樣可以開始 1-5。卡住時回哪一課看、矯正包怎麼用、預測分數的出處，寫在 [補充.md](補充.md)。

## 1. 題目

開始前先寫下預測分數（`uv run check.py start 1-C1` 會問你：一共 10 題，你覺得會過幾題）。交卷時它會再問你一次。

**第一部分：追蹤（`trace.txt`，6 題）。** 三段程式，先不要跑，用眼睛從第一行往下追，在「答：」後面寫答案。建議在紙上畫追蹤表（1-2）。

**第二部分：修好（`fix.py`，2 題）。** 一支壞掉的程式，最上面的註解寫着它應該印出哪兩行。先跑，錯誤訊息從最下面一行看起，修好一個再跑一次；跑得起來以後，跟註解的兩行一行一行比，每一行的字都要一樣（多打的空格、空白的行不算錯）。

**第三部分：手寫（`write.py`，2 題）。** 照註解的題目，從零寫一支 10 行以內的程式。第一行程式碼（註解不算）一定要照題目寫 `total = 1730`：對答案的時候，check 會把 1730 換成別的金額再跑一次，所以要用 `total` 算，不能把答案的數字直接寫進 `print`。

## 2. 提示

- 追蹤：一行一行往下，`#` 開頭的註解不跑；等號右邊先算，算好再放進左邊的名字；沒有等號的那一行，算完就丟掉。
- `print` 逗號隔開的東西中間空一格；`sep` 換掉中間的空格，`end` 換掉最後面的換行；`print()` 印出空的一行。
- `/` 的答案一定是小數（float）；`//` 向下取整（兩邊都是整數時，結果是整數）、`%` 是除完剩多少；先乘除、後加減。
- 錯誤訊息從最下面一行看起：它說是哪一種錯（SyntaxError、NameError、TypeError…）？上面寫着第幾行？
- 不會的也要寫：空著的題目，check 不讓你交卷（真的寫不出來，加 `--submit` 照樣交卷）。

```bash
uv run lessons/1-C1/fix.py
uv run lessons/1-C1/write.py
```

## 5. 怎麼測

三部分都寫好，回到課程資料夾打 `uv run check.py 1-C1`，這就是**交卷**。一共 10 題：

- 第一部分：`trace.txt` 6 題（對答）
- 第二部分：`fix.py` 跑得起來，先印「一共……」、下一行印「平均……」；印出來的兩行跟題目一樣（多打的空格、空白的行不算錯）
- 第三部分：`write.py` 印出三行；把 `total = 1730` 換成 `total = 2026` 再跑一次，也算得對

**第一次交卷就過 8 題以上，這一站就過了。** 成績只照第一次交卷算：交卷以後再打 `uv run check.py 1-C1` 是訂正，可以看自己改對了沒（加 `--all` 看全部），但不改成績。還有題目空著，check 不算交卷，會告訴你哪幾題沒寫。

開始前猜的、交卷時猜的、實際過了幾題，都記進校準曲線（`uv run check.py status`）。猜的跟實際差太多，它會請你寫一句「下次我會怎麼估」。

**沒過：領矯正包，隔天以後考卷 B。** 交卷沒過，check 會把矯正包寫進帳本的 `lessons/1-C1/矯正包.md`：你錯了哪幾題、正確答案和為什麼、要回哪一課影片的哪個時間看、要做哪一個練習（練習檔複製到 `lessons/1-C1/practice/`）。練完，**隔天以後**打：

```bash
uv run check.py start 1-C1B
```

卷 B 的題目不一樣，考的東西一樣（作答檔在帳本的 `lessons/1-C1B/`，交卷打 `uv run check.py 1-C1B`）。卷 B 第一次交卷過 8 題以上，這一站一樣算過。卷 A 交卷的同一天打 `start 1-C1B`，它會請你明天再來。

不用交給任何人：交卷就是在課程資料夾打 `uv run check.py 1-C1`，成績記在你帳本的 `.check/` 裡。過了沒過，都可以接着上 1-5（矯正包和卷 B 可以跟 1-5 一起進行）。
