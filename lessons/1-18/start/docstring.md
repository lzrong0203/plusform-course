# 1-18 第③圈：docstring 檢核表（自評，check 不檢查）

寫完 by_category 的 docstring、貼給 AI 之前，對一遍（打勾）：

- [ ] 第一行一句話說它做什麼（例如「各分類的小計。」），第二行空一行
- [ ] 輸入：寫了交進來的是什麼、長什麼樣子（一串 (分類, 金額)），可不可以是空的
- [ ] 輸出：寫了交回什麼（dict：分類 → 合計），不是 print
- [ ] 例子：至少一個真的呼叫和它交回的值，別人照着打就能對答案
- [ ] 特別的情況（空的 list）寫在 docstring 裡，也寫成一條 assert
- [ ] 貼給 AI 時，說明 assert 不要改；AI 交回的程式，用 assert 跑過才收
