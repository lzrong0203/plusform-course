## Mac 的做法小抄（macOS 26 繁體中文）

- 選單在螢幕最上面，而且會跟著你最後點的視窗換。找不到下面這些選單，先點一下 Finder 的視窗，左上角出現「Finder」才對（在瀏覽器看影片時，那排是瀏覽器的選單）
- 打開 Finder：螢幕最下面那排圖示，最左邊那個藍色的笑臉
- 打開家目錄：前往 › 個人專屬（快速鍵 Shift＋Command＋H）。Finder 把家目錄叫做「個人專屬」，是同一個地方
- 新增資料夾：檔案 › 新增檔案夾（Shift＋Command＋N）。Finder 把資料夾叫做「檔案夾」，是同一個東西
- 幫資料夾取名字：打字前先把輸入法切成英文（通常按一下 Caps Lock；本來就是英文就不用按），打完按 Enter（鍵盤上寫 return）才算改好。名字用英文小寫、中間不要有空白
- 改名字：點一下選起來，按 Enter
- 打開資料夾：在它上面連按兩下
- 顯示路徑列：顯示方式 › 顯示路徑列（Option＋Command＋P）。打開以後，每個 Finder 視窗的最下面都會有路徑列
- 你現在在哪個資料夾：看 Finder 視窗最上面的名字。路徑列不一定準：你點一下選起某個資料夾時，路徑列會多寫到那個資料夾
- 拿到文字的地址：在路徑列的資料夾上按住 control 點一下 › 拷貝「資料夾名稱」作為路徑名稱，再到備忘錄按 Command＋V 貼上（備忘錄可以按 Command＋空白鍵，打「備忘錄」打開）
- 顯示副檔名：Finder › 設定 › 進階 › 勾選「顯示所有檔案副檔名」，勾好把設定視窗關掉
- 顯示隱藏檔：在 Finder 視窗裡按 Command＋Shift＋句號（.）。做作業時先讓隱藏檔保持顯示；想藏回去，再按一次

## Windows 的同學（Windows 11 檔案總管）

影片裡的 Windows 小卡只寫按法，完整做法在這裡。

- 打開檔案總管：工作列上的資料夾圖示
- 家目錄：本機 › 本機磁碟 (C:)（有的電腦寫 Windows (C:)）› 使用者 › 你的名字，在這裡建 code › ledger › data、notes、practice
- 新增資料夾：檔案總管左上角的「新增」› 資料夾（或 Ctrl＋Shift＋N）
- 幫資料夾取名字：微軟注音按一下 Shift 切成英文（打出注音就再按一次 Shift），打完按 Enter
- 改名字：點一下選起來，按 F2（按 Enter 會打開資料夾，不是改名字）
- 顯示副檔名和隱藏檔：上方的「檢視」› 顯示 › 勾選「副檔名」和「隱藏的項目」
- Windows 的隱藏檔跟 Mac 不一樣：Windows 不看名字前面有沒有點。之後的課，.git 會被藏起來（要勾「隱藏的項目」才看得到），.env、.venv 這類檔案本來就看得到
- 看完整地址：點一下上方的網址列（或按 Alt＋D），會變成 `C:\Users\你的名字\code\ledger`。換你做的時候，就用這個對 practice 的地址
- Git Bash 是 Windows 用的終端機，0-W 會帶你裝。同一個地方在 Git Bash 裡寫成 `/c/Users/你的名字/code/ledger`：開頭的 `C:` 變成 `/c`，反斜線 `\` 變成斜線 `/`，名字和順序都一樣
- 丟掉的東西會進「資源回收筒」，跟 Mac 的垃圾桶一樣救得回來

## 你的畫面跟影片不一樣？

- 影片的家目錄叫 bear（示範帳號，熊的名字），你的會是你自己的帳號名稱，常常是英文簡稱，跟登入畫面顯示的名字不一定一樣。地址裡的 bear，都換成你自己的名字。
- 點了選單卻找不到「前往」「新增檔案夾」「顯示路徑列」：螢幕最上面那排是別的程式的選單。先點一下 Finder 的視窗，左上角出現「Finder」再找。
- 幫資料夾取名字時打出注音：輸入法還是中文。按一下 Caps Lock（或 control＋空白鍵）切成英文再打；打錯了就點一下選起來，按 Enter 重打。本來就是英文輸入的人，照影片按了 Caps Lock 反而打出注音或大寫，也是同一個原因，再按一次就好。
- 你的 Mac 是英文介面的話，選單是 Go › Home、File › New Folder、View › Show Path Bar、Finder › Settings › Advanced › Show all filename extensions；路徑列上的「使用者」會寫成 Users。
- Finder 把 Downloads 顯示成「下載項目」，Users 顯示成「使用者」，它們真正的名字是英文的，地址裡也寫英文。
- 下載項目裡的檔名本來就看得到 .pdf、.jpg：有的檔案自己設定成顯示副檔名，很正常。
- 按了 Command＋Shift＋句號，看到的隱藏檔多寡跟影片不一樣，很正常，用越久的電腦越多。淡淡的「資源庫」名字前面沒有點，它也是平常藏起來的資料夾。看到了先不要動、不要刪。
- ledger 裡多一個淡淡的 .DS_Store：那是 Finder 自己放的檔案，不用理它。
- 硬碟名字不是 Macintosh HD：改過名字就會不一樣，路徑列最左邊那一格就是你的硬碟。

## 作業（大約 20 分鐘）

**作業一**：在你的家目錄蓋出這些資料夾，打開路徑列、副檔名和隱藏檔，再寫下 practice 的完整地址。剛剛在影片暫停時做好的，就算完成了。

```
bear/（你的家目錄）
└── code/
    └── ledger/
        ├── data/
        ├── notes/
        └── practice/
```

**作業二**：路徑填空六題（家目錄是 `/Users/bear`，資料夾照上面那棵樹）。先寫在紙上或備忘錄，再往下對答案。

1. ledger 的完整地址（絕對路徑）
2. data 的地址，用波浪號開頭寫
3. 你在 ledger 裡，practice 的相對路徑
4. 你在家目錄，notes 的相對路徑
5. 你在 data 裡，practice 的相對路徑
6. 你在 practice 裡，家目錄的相對路徑

**收尾**：作業對完以後，把 ledger 裡的 data、notes、practice 三個資料夾拖到垃圾桶（一個一個拖也可以）。code 和 ledger 本身留著，ledger 裡面空空的（看到淡淡的 .DS_Store 不用理它）。下一課要用打字，從空的帳本再蓋一次。（丟進垃圾桶的還救得回來。）

## 答案與解說（先做再看）

**作業一**：practice 的完整地址

- Mac：`/Users/你的帳號名稱/code/ledger/practice`（在路徑列的 practice 上按住 control 點一下，選「拷貝作為路徑名稱」，貼出來比一比）
- Windows：`C:\Users\你的名字\code\ledger\practice`（打開 practice，點一下網址列或按 Alt＋D，比一比）

**作業二**

1. `/Users/bear/code/ledger`（你的電腦上，bear 換成你的帳號名稱）
2. `~/code/ledger/data`
3. `practice`
4. `code/ledger/notes`
5. `../practice`（先上一層到 ledger，再走進 practice）
6. `../../..`（practice → ledger → code → 家目錄，往上三層）

錯的題目：第 1、2 題回到章節「看懂路徑列：路徑和絕對路徑」，第 3 到 6 題回到「相對路徑與兩個點」，在說明欄點一下章節時間就跳過去。相對路徑不用斜線開頭；斜線開頭的，一定是從最上面寫起的絕對路徑；波浪號開頭的也一樣，從家目錄算起，在哪裡寫都一樣。

**片中題目的答案**

- 思考站一，notes 的完整地址：`/Users/bear/code/ledger/notes`
- 思考站二，從家目錄出發，practice：`code/ledger/practice`（寫成 `/code/ledger/practice` 會從最上面那一層找 code，那裡沒有；寫成 `../code/ledger/practice` 會先走出家目錄）
- 思考站三（換你做）：practice 的完整地址是 `/Users/你的帳號名稱/code/ledger/practice`（Windows 的檔案總管是 `C:\Users\你的名字\code\ledger\practice`）
- 白海豹第一題，在 ledger 裡，data：`data`（data 就在 ledger 裡面，直接寫名字）
- 白海豹第二題，在 notes 裡，practice：`../practice`（practice 不在 notes 裡面，要先上一層到 ledger）
- 思考站四（白海豹第三題），在 data 裡，code：`../..`
- 思考站五，兩版資料夾樹：B 版畫錯了。B 的 ledger 跟 code 一樣靠左，是並排的，ledger 不在 code 裡面，三條地址照 B 唸都少了 code 這一層

## 名詞小抄

| 名詞 | 意思 |
|---|---|
| 檔案 | 一份一份的東西，像一張照片、一份文件 |
| 資料夾 | 放東西的抽屜；資料夾裡還可以放資料夾 |
| 家目錄 | 你自己的那個資料夾，桌面和下載項目都在裡面（Mac 是 `/Users/你的帳號名稱`；Finder 叫它「個人專屬」） |
| 波浪號 `~` | 家目錄的簡寫；終端機會把 `~` 換成 `/Users/你的帳號名稱` |
| 路徑 | 檔案或資料夾的地址，從大的一層寫到小的一層 |
| 絕對路徑 | 從最上面的斜線開始寫的完整地址，不管你在哪個資料夾，都是同一個地方 |
| 你在哪個資料夾 | Finder 視窗現在打開的那個資料夾；看視窗最上面的名字 |
| 相對路徑 | 從你現在的位置開始寫的地址，不用斜線開頭（波浪號 `~` 開頭的不是相對路徑，它從家目錄算起） |
| `..`（兩個點） | 上一層；`../..` 是上兩層 |
| 斜線 `/` | 最前面那條是最上面那一層；中間的斜線是「裡面的」（`code/ledger`＝code 裡面的 ledger） |
| 副檔名 | 檔名最後的點和英文字母（.jpg、.txt、.py），告訴電腦這是哪一種檔案。改檔名時不要動它；地址的最後一格是檔案時，副檔名也要寫上 |
| 隱藏檔 | 平常看不到的檔案。Mac 上名字前面有一個點的都會藏起來（之後會看到 .git）；Windows 不看點，.git 會另外被設成隱藏 |
| 資料夾樹 | 把資料夾一層一層往下畫的圖：往右縮一格，就是放在上一個的裡面；一樣靠左的，是並排的 |
| 驗收 | 看 AI 做得對不對；資料夾樹的驗收方法是把每個資料夾的地址唸出來，跟交出去的對一對 |

## 請 AI 家教出題考你

第二圈熊貼給 AI 的就是這一段；有 AI 帳號的話複製去用（AI 帳號 0-8 會帶你申請）。不要貼密碼或個人資料。

> 我剛學相對路徑，出三題考我，先不要給答案。一次出一題，等我回答再出下一題。我答錯的話，只給我提示，讓我自己改。我的資料夾是這樣放的：家目錄裡有 code，code 裡面有 ledger，ledger 裡面有 data、notes、practice。題目只用這幾個資料夾，斜線用 /，至少一題要用到兩個點（..），而且至少一題要往上走兩層。

同一段話問不同的 AI、或同一個 AI 問第二次，題目都可能不一樣，這很正常；照它的題目自己先答就好。

## 第二圈的 AI 家教（實際錄影）

用示範帳號在 Claude 網頁版貼上上面那一段（一般聊天，另開一個對話，沒有特別的設定），白海豹的題目和提示照 AI 的回答整理（字有縮短，意思沒改）。果凍兔答錯的那一題（第二題只打 practice），是我們故意打進去的錯答案，想看家教會怎麼回；其他題打的是正確答案。2026-11-13 錄，模型是網頁版預設的 Sonnet 5.5（Medium），只錄一次、沒有重錄。AI 的題目寫的是「cd 後面要接的路徑」，cd 是下一課才教的指令，片中先不講。

完整對話（照錄，程式碼字型和粗體去掉；AI 畫的資料夾樹改成文字描述）：

**AI**：好，我們開始！先確認一下你的資料夾結構（畫了一張家目錄 › code › ledger › data、notes、practice 的樹）。第 1 題：你現在人在 ~/code/ledger 這個資料夾裡。請用相對路徑寫出怎麼進入 data 資料夾（也就是寫出 cd 後面要接的路徑）。寫好答案回覆我，我再出下一題。

**熊**：data

**AI**：答對了！從 ledger 進到 data，直接寫資料夾名稱就可以，因為 data 就在你目前所在的資料夾裡面。第 2 題：這次你人在 ~/code/ledger/notes 裡面。請用相對路徑寫出怎麼切換到 practice 資料夾（寫出 cd 後面要接的路徑）。寫好答案回覆我，我再出最後一題。

**熊（打果凍兔的答案）**：practice

**AI**：這個還沒對，再想一下。提示：你現在人在 notes 裡面，但 practice 並不在 notes 裡面，它跟 notes 是並排的，兩個都在 ledger 底下。所以要先「往上走一層」回到 ledger，再進到 practice。想想看，往上一層要用哪個符號？再把它跟 practice 用 / 接起來，改一次再回覆我。

**熊**：../practice

**AI**：答對了！.. 代表上一層（回到 ledger），再用 / 接上 practice，就能走到並排的資料夾。第 3 題（最後一題）：這次你人在 ~/code/ledger/data 裡面。請用相對路徑寫出怎麼直接切換到 code 資料夾（寫出 cd 後面要接的路徑）。寫好答案回覆我，我再告訴你結果。

**熊**：../..

**AI**：答對了！從 data 往上一層是 ledger，再往上一層就是 code，所以是 ../..。三題都完成了：第 1 題，進入裡面的資料夾，直接寫名稱（data）；第 2 題，往上一層再進入並排的資料夾（../practice）；第 3 題，連續往上兩層（../..）。你第 2 題一提示就改對了，抓得很快。想再多練幾題，或是試試不同的情境（例如從 practice 走到 data/ 底下），隨時跟我說。
